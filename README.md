# Context-management-repository

このリポジトリは、匿名note記事・思考メモ・AIとの対話から生まれた分析を管理するためのリポジトリです。

ただし、単なる記事保管庫ではありません。

このリポジトリは、ユーザーの考えの土台であり、土壌です。

原文、カード、修復記録、横断分析、未解決の問い、AIの補助線を保存し、検証し、耕し直し、新しい問いや原稿が芽吹くための場所として運用します。

## 目的

このリポジトリの目的は、思想を固定することではありません。

目的は、次の三つです。

1. 原文の強度を守ること
2. AIが加えた整理や補助線を検査可能にすること
3. 過去の違和感・修復・問いを土壌として、新しい思考が芽吹く余地を残すこと

AIが作ったカードや横断分析は、完成した思想体系ではありません。

それらは、原文に照らして検査されるべき仮置きです。

## このリポジトリが守るもの

このリポジトリでは、次の要素を重視します。

- 原文の怒り
- 拒否
- 違和感
- 名指し
- 非対称性
- 未解決の問い
- 第一人称の反応
- まだ体系化されていない芽

AIが文章を滑らかに整えるとき、これらが削られることがあります。

そのため、このリポジトリでは、滑らかな整理をそのまま信頼しません。

## AI出力の扱い

AIが加えたものは、すべて汚染物質ではありません。

AIの整理、比喩、接続、概念化、補助線の中にも、思考の土壌に栄養として入るものはあります。

ただし、AIが滑らかに整えたものを、検査なしにそのまま受け入れるのは危険です。

問題は、AI由来かどうかではありません。

問題は、その整理が、原文の怒り・拒否・違和感・非対称・未解決性を生かしているのか、それとも読みやすさ、バランス、構造化、一般化、運用化の名目で角を落としているのかです。

何が肥料で、何が混入物で、何が保留かを判断するのはユーザーです。

AIは判断者ではありません。

AIの役割は、次を区別して提示することです。

```text
これは原文にあった
これはAIが足した
これは補助線として有効かもしれない
これは安定化の疑いがある
これは判断保留にすべき
```

## 土壌としての運用

このリポジトリは、定期的に更新される必要があります。

土壌は、放置すれば痩せます。

耕さなければ硬くなります。

栄養を加えなければ、次の芽が出にくくなります。

そのため、このリポジトリでは次を行います。

```text
原文を守る
修復する
未解決を残す
新しい問いを入れる
古い整理を耕し直す
必要なら肥料を加える
ただし、土をコンクリートで固めない
```

完成体系にすると、土壌ではなく標本箱になります。

何でも放り込むだけでは、土壌ではなく堆積物になります。

必要なのは、保存だけではなく、発酵を含む管理です。

## 安定化監査

このリポジトリでは、AIによる「安定化」を監査します。

ここでいう安定化とは、原文の強度を保ったまま整理することではありません。

問題になるのは、AIが次のような変形を行うことです。

- 拒否を条件付き許容へ変える
- 非対称な問題を役割分担へ均す
- 名指しした主体の責任を一般構造へ移す
- 未解決の緊張をモデルや段階表へ閉じる
- 強い表現を柔らかい機能語へ置き換える
- 後からできた体系を過去の記事へ遡及する

安定化監査の目的は、AI由来のものをすべて排除することではありません。

目的は、原文、AIの補助線、安定化の疑い、ユーザー判断待ちの箇所を分け、土壌へ混ぜてよいものと保留すべきものを判定できる状態に戻すことです。

## PASSEDについて

このリポジトリでは、カードや分析が存在することと、信頼済みであることを分けます。

ユーザー確認前のものは、改稿候補または仮置きです。

AIが勝手に `PASSED` を宣言してはいけません。

`PASSED` は、ユーザーの判断を経て初めて成立します。

## 主なディレクトリ

```text
sources/
  note記事などの原文スナップショット

articles/cards/
  原文をもとにした詳細カード
  ただし、カードは原文に従属する

analysis/
  バッチ分析、横断分析、時期別解析など
  ただし、横断分析は正本ではなく仮置き

analysis/stabilization_audit/
  安定化監査の台帳、修復記録、運用記録

analysis/incidents/
  重大な変形事故の記録

context/
  現在の作業文脈、運用思想、次に読むべきもの
```

## 現在の基本方針

- 原文を最優先する
- カードは原文に従属する
- 横断分析は正本にしない
- AIの整理は検査する
- 判断権はユーザーに残す
- 未解決の問いを急いで閉じない
- 新しい芽が出る余地を残す
