# B群再判定4――犠牲を設計しない

更新日：2026-06-24

## 対象

- `ndcca526034cf`　犠牲を設計しないという選択

## 再判定の結論

**詳細カードへ昇格する。**

理由は、この文章が後期の継続・責任配置モデルに先立ち、次の拒否線を明示しているからである。

> 誰かが壊れ、消耗し、退出できず、回復も補償もされないことを、制度や世界の安定条件として最初から組み込まない。

一方、本文の宗教・科学に関する記述は、そのまま歴史的・理論的説明として採用しない。

```text
残す
→ 犠牲を制度の作動条件へしないという規範

修正する
→ 宗教と科学を一括して犠牲構造へ還元する一般化

押し広げる
→ 負担が犠牲化へ変わる判定条件
```

## 1．負担と犠牲を分ける

社会的な選択には、費用、危険、待機、労働、機会損失が発生しうる。

```text
負担が発生する
≠ 犠牲が正当化される
```

本稿でいう犠牲化は、負担の存在ではなく、特定者への負担が次の状態へ変わることを指す。

- 不可視である
- 本人が決定へ参加できない
- 拒否・停止・退出ができない
- 上限と期限がない
- 交代できない
- 補償・回復・修復がない
- 英雄、使命、最適解、必要悪として神聖化・合理化される
- 全体利益によって個別損失が無効化される

## 2．例外引受け役

制度はしばしば、通常手順では処理できないものを特定の人へ集中させる。

```text
例外
→ 誰かが引き受ける
→ その人の技能・善意・使命感へ依存する
→ 引受けが恒常化する
→ 制度上の欠陥が見えなくなる
```

この引受け役は、英雄、聖者、責任者、現場中核層、管理者、家族、ケア担当者など、異なる名前を持ちうる。

問題は名称ではなく、制度が例外処理をその人の自己消耗へ外部化しているかである。

## 3．崇高化と合理化

負担集中は二つの語りで見えにくくなる。

### 崇高化

- 尊い使命
- 自己犠牲
- 愛情
- 忠誠
- 献身
- 英雄性

### 合理化

- 効率
- 確率
- 最適化
- 全体利益
- コスト削減
- やむを得ない例外

崇高化と合理化は対立するとは限らない。使命感で引き受けさせ、数字で継続を正当化することもある。

## 4．宗教・科学の扱い

本文は宗教を意味づけ、科学を理解・制御として対置し、双方が「誰が引き受けるのか」という問いへ到達すると述べる。

この対置は、制度批評のための思考装置としては有効だが、次の一般命題を証明しない。

- 宗教は必ず犠牲を要求する
- 科学は必ず人を数値化して切り捨てる
- 宗教と科学は本質的に同一である
- 意味づけや数値化はそれ自体が非倫理的である

残すべき問いは次である。

```text
意味を与える語りが、負担者の拒否を封じていないか
数値化が、個別損失と分配を消していないか
```

## 5．犠牲を設計しないことは、負担を消すことではない

負担を完全に消せないからこそ、次を設計する。

- 負担者の可視化
- 決定参加
- 同意と拒否
- 負担上限
- 期限
- 交代
- 停止
- 退出
- 補償
- 回復
- 修復
- 再発防止

負担が必要だと判断した側は、負担者の善意や使命感ではなく、これらの条件を整える責任を持つ。

## 6．自発性をそのまま同意とみなさない

本人が引き受けたことだけでは、犠牲化していないとは言えない。

```text
断れば所属を失う
他に生活手段がない
周囲が期待している
役割上、拒否しにくい
情報が不足している
損害が後から判明する
```

場合、自発的に見える引受けが事実上の強制である可能性がある。

確認すべきもの：

- 代替選択肢
- 情報の十分性
- 撤回可能性
- 拒否による不利益
- 権力差
- 負担後の回復経路

## 7．遠位目的による現在の資源化

人類、国家、文明、組織、未来世代などの大きな目的は、現在の個人へ無制限な負担を要求する根拠になりうる。

```text
目的が大きい
→ 現在の損失が小さく見える
→ 負担者の拒否が利己的とされる
→ 犠牲が不可視化される
```

遠位目的が大きいほど、現在負担の説明責任は軽くならず重くなる。

必要な制約：

- 現在負担の明示
- 負担上限
- 負担者の意思決定参加
- 異議申立て
- 退出可能性
- 補償
- 停止条件
- 見直し時期
- 目的自体の再検討

## 8．責任配置モデルとの接続

責任配置モデルは、決定、実装、説明、監査、負担、停止、修復、継承を分ける。

本記事はその手前で、次を要求する。

```text
負担者を責任者と呼んで正当化しない
引き受けた人を制度欠陥の穴埋めにしない
負担の存在を全体利益で消さない
```

責任配置が明確でも、同じ人を使い潰すなら犠牲化は残る。

## 9．継続モデルとの接続

継続モデルでは、担い手の自己消耗で外形を残す状態を延命と呼ぶ。

```text
同じ人が穴を埋め続ける
＋ 交代者が育たない
＋ 退出すると損をする
＋ 負担が記録されない
＝ 犠牲による延命
```

本記事は、継続のために現在の個人を燃料へ変えないという禁止線を提供する。

## 10．Security・帰還可能性との接続

犠牲化を止めるには、拒否した人が生きられる必要がある。

- 所得
- 住居
- 医療
- 学習
- 移動
- 経歴
- 関係・所属

が切れれば、形式上の拒否権は実質的に使えない。

したがって、犠牲を設計しないことは、道徳的呼びかけではなく、停止・退出・帰還・再参加の基盤設計を含む。

## 11．判断を外注しない

本文は、犠牲を前提にしない世界では迷い・失敗・説明不足が残り、判断を外注できないとする。

これは専門知や制度を拒むことではない。

```text
専門知を使う
しかし
目的・負担・停止の判断を管理者へ丸投げしない
```

完全な救済や最適解を求めるほど、誰が負担を引き受けているかが見えなくなる可能性がある。

## 12．犠牲化の判定質問

1. 誰が負担しているか。
2. その人は決定へ参加したか。
3. 拒否・停止・退出できるか。
4. 負担に上限と期限があるか。
5. 交代可能か。
6. 補償・回復・修復があるか。
7. 拒否による不利益は何か。
8. 負担は記録されているか。
9. 崇高な言葉や数字が個別損失を隠していないか。
10. 全体目的そのものを見直せるか。

## 13．残った未解決問題

1. 負担と犠牲化の境界を制度上どの指標で判定するか。
2. 自発的献身と事実上の強制をどう区別するか。
3. 緊急時の一時的負担集中へ、どの期限・補償・交代条件を置くか。
4. 将来世代を代表する決定で、現在負担者へどの拒否権を与えるか。
5. 公共サービス維持に必要な負担を、誰がどの順序で引き受けるか。
6. 負担拒否が連鎖したとき、制度機能をどう維持するか。
7. 数値化が必要な判断で、少数者の重大損失をどう表示するか。
8. 英雄化・使命化を、本人の尊厳を傷つけず監査できるか。
