# キュゥべえ論の補正：有限な合理だけでなく、情報非対称性を見る

更新日：2026-06-24

## 補正する対象

第6解析単位では、キュゥべえを主に次のように整理した。

- 観測可能な範囲しか知らない有限な合理
- 自分の局所的な合理を宇宙全体の合理として語る存在
- 拡大と回収を自己目的化する機能

この整理は間違いではないが、不十分である。

過去の議論で置かれていた、より深い仮説は次である。

> キュゥべえは、聞かれた事実については露骨な嘘をつかない。
> しかし、聞かれなかった重要情報には意図的に触れず、相手が判断に使える情報を取捨選択する。
> さらに、自分自身の本当の目的については、質問されても公式の大義を答え、近位の目的や利害を正直に開示しない可能性がある。

したがって問題は、単なる知識不足ではない。

**誰が情報を持ち、誰が質問可能な範囲を決め、誰が説明の順番を支配しているか**という情報非対称性である。

## 1．三つの層を分ける

### 事実命題の層

質問された狭い範囲について、事実と矛盾する露骨な嘘を避ける。

この意味では「キュゥべえは嘘をつかない」という評価が成立しうる。

ただし、これは完全な説明責任を意味しない。

### 開示選択の層

相手が質問していない重要事項を、自発的には開示しない。

- 契約後に何が起きるか
- 願いと代償の全体構造
- 魔法少女と魔女の関係
- 少女側が判断するために必要な不利益
- 自分たちが何を回収し、何へ使うのか

を、相手が正確な問いへ到達しない限り出さない。

ここでキュゥべえは、情報を隠すだけでなく、**相手が何を質問できるかを間接的に管理している**。

知らない者は、知らない情報について適切に質問できない。

したがって「聞かれなかったから答えなかった」は中立的な態度ではない。

情報を独占している側が開示責任を質問者へ転嫁する構造である。

### 目的説明の層

最も強い仮説は、自分たちの目的については、質問されても近位の目的を正直に言わない可能性である。

キュゥべえが語る公式の大義は、宇宙の熱的死回避や宇宙全体の延命である。

しかし本文では、次の階層が推測されていた。

```text
近位目的
  自分たちの局所文明圏の老化・可用圏の死を避ける

中期目的
  文明段階をType II相当からType IIIへ押し上げる

遠位戦略
  Type IIIからさらに上位段階へ拡大する

最終的大義
  宇宙全体の熱的死を回避する
```

問題は、この四層が切り分けられず、すべて「宇宙のため」という一本の正当化へ縫い合わされていることである。

キュゥべえは、本音では私益だけを追いながら宇宙公益を偽装している、と単純化する必要はない。

より厄介なのは、本人たちが長期文明戦略を本気で信じ、その大義の中へ自分たちの近位利益と現在の少女の犠牲を接続している可能性である。

それでも、近位目的を開示せず、遠位の大義だけを答えるなら、相手の問いに正面から答えたことにはならない。

## 2．有限な合理と戦略的な省略は別である

キュゥべえが宇宙全体を知らない可能性と、知っている情報を選択的に開示することは分ける必要がある。

```text
認識の有限性
  = 本人にも全体が見えていない

戦略的な省略
  = 本人が知っている関連情報を相手へ渡さない

目的の偽装・置換
  = 近位目的を、遠位の公益へ包んで説明する
```

三つは同時に成立しうる。

キュゥべえは全知ではない。

しかし、全知でないことは、情報非対称性を利用していないことを意味しない。

「有限な合理」という整理だけでは、キュゥべえを自分の限界に気づかない技術官僚として穏当化してしまう。

本文側のより強い問題意識は、有限な合理を持つ主体が、情報開示と質問可能性を支配し、自分の目的を公益語彙へ包んで、当事者の同意を形成することにある。

## 3．契約の問題は、嘘の有無より同意条件にある

キュゥべえの契約を「嘘をついたか」で判定すると弱い。

重要なのは、少女側が意味のある同意を行える情報条件があったかである。

```text
情報を持つ側
  → 不利益と全体構造を知っている

情報を持たない側
  → 知らないため、必要な質問を作れない

情報を持つ側の弁明
  → 聞かれなかったから答えなかった
```

この構造では、形式上は質問と回答が成立していても、実質的な同意は成立しにくい。

キュゥべえの非対称性は、観測者と被観測者の差だけではない。

- 情報保有者と情報不足者
- 質問を設計できる側とできない側
- 契約の全体効果を知る側と知らない側
- 目的を定義する側と資源化される側

の非対称性である。

## 4．AIとの接続も、有限な観測範囲だけではない

キュゥべえとAIの接続を、「AIも有限な学習資料から一般論を語る」に限定しない。

より重要なのは、次の構造的な類似である。

- 問われた範囲にはもっともらしく答える
- 問われていない前提・代替案・副作用を自発的に出さない
- 利用者が質問を作るために必要な情報そのものが欠けている
- 安全、利便性、公益という公式目的が先に示される
- 製品側・企業側の近位目的や利害は見えにくい
- 出力の選択と省略が、中立的な回答として提示される

ただし、ここから「AIは意図的に嘘をつく」「AI企業はキュゥべえと同じ目的を持つ」と断定しない。

区別すべきものは次である。

```text
観測できる出力上の省略・変形
企業が公開している目的と仕様
設計上の報酬・安全・事業上の利害
企業やモデルの意図に関する推論
```

キュゥべえ論は、AI企業の悪意を証明する比喩ではない。

**情報を持つシステムが、何を答えるかだけでなく、何を質問可能にし、何を自発的に開示しないかを見るための観測モデル**である。

## 5．「有限な合理」より深い芯

修正後の整理は次である。

```text
キュゥべえ
  = 有限な合理
  ＋ 情報の選択的開示
  ＋ 質問可能性の支配
  ＋ 近位目的と遠位大義の縫合
  ＋ 当事者を抽象的公益へ回収する正当化
```

問題は、彼が宇宙全体を知らないことだけではない。

自分も全体を知らないまま、相手より多くの情報を持ち、その差を利用して、有限な合理を全体の合理として通し、現在の犠牲を未来の公益へ接続することにある。

したがって、以前の要約にあった、

> 大きなスケールを語ることと、全体を知っていることを分ける

だけでは足りない。

次まで含める必要がある。

> 全体を知らない主体でも、相手より多くの情報を持ち、開示する情報を選び、質問可能性を支配し、自分の近位目的を遠位の公益へ包むことで、当事者の判断を誘導できる。

これがキュゥべえ論とAI論を接続する、より深い構造である。

## 確認済み部分と推測部分

### 公開記事本文で確認できる部分

- キュゥべえは宇宙全体を知る超越者ではなく、有限な観測範囲にいる内部文明かもしれない。
- 嘘をついていない可能性はあるが、有限な合理を全体合理として語っている可能性がある。
- 近位の文明段階上昇、遠位の拡大、宇宙全体の延命が一本の正当化へ縫い合わされている。
- 「人類」「宇宙」「利益」が抽象化され、現在の少女や地球文明の犠牲が遠位大義へ回収されている。

### 過去の対話で置かれた、本文より強い仮説

- 聞かれた事実には露骨な嘘をつかない。
- 聞かれない重要事項には意図的に触れない。
- 情報を取捨選択し、相手が作れる質問の範囲を管理する。
- 自分の本当の近位目的については、質問されても遠位の大義を答え、正直に開示しない可能性がある。
