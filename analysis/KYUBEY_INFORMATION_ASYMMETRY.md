## 戻すべき芯

この文書は、キュゥべえ論を情報非対称性モデルへ完成させる場所ではない。

この文書は、次の五つを分けるための仮索引である。

```text
1. 作品本文・記事本文から確認できること
2. 本文側が置いた解釈・推測
3. 情報非対称性として有効な補助線
4. 情報非対称性へ落とすと弱くなる拒否
5. ユーザー判断がなければ作品読解の肥料か混入物か決められない接続
```

キュゥべえ論の中心は、嘘をついたかどうかだけではない。

しかし、情報を開示したかどうかだけでもない。

中心に残すべきなのは、**当事者を抽象的公益へ回収し、現在の個人を遠位大義の資源にする構造への拒否**である。

## 1．情報非対称性は補助線であり、中心ではない

キュゥべえの問題を、情報非対称性として読むことは有効である。

聞かれた範囲では露骨な嘘を避ける。

聞かれない重要情報は自発的に出さない。

知らない相手は、必要な質問を作れない。

近位目的を問われても、遠位の大義を答える。

この構造は、同意条件、質問可能性、判断環境の設計を見るうえで強い。

ただし、ここで止めると、問題は「ちゃんと説明すればよかった」に寄る。

それでは弱い。

キュゥべえ論の芯は、説明不足ではなく、**説明されたとしてもなお、人を遠位大義の資源として扱う世界そのものをどう見るか**にある。

## 2．同意条件の欠如は重要だが、同意があれば済むとは限らない

旧ファイルは、契約の問題を「嘘の有無」ではなく「意味のある同意を行える情報条件」の問題として見ていた。

これは有効である。

しかし、同意条件だけに寄ると、次のように弱まる危険がある。

```text
十分に説明する
不利益を開示する
質問可能性を確保する
同意条件を整える
```

これで問題が解けるように見えてしまう。

しかし、元の拒否はもっと強い。

仮に説明が尽くされても、現在の個人を遠位大義のための燃料、資源、回収対象として扱う設計そのものを選ばない、という拒否が残る。

同意条件は必要である。

しかし、同意条件が整えば、個人の資源化が許容されるとは限らない。

## 3．近位目的と遠位大義の縫合は、説明のズレだけではない

旧ファイルは、近位目的、中期目的、遠位戦略、最終的大義を分けていた。

この分解は有効である。

```text
近位目的
  自分たちの局所文明圏の老化・可用圏の死を避ける

中期目的
  文明段階をType II相当からType IIIへ押し上げる

遠位戦略
  Type IIIからさらに上位段階へ拡大する

最終的大義
  宇宙全体の熱的死を回避する
```

ただし、これを目的説明の問題だけにすると弱い。

問題は、近位目的を遠位大義へ包んで説明することだけではない。

その包み込みによって、現在の少女の身体、人生、選択、苦痛、地球文明の側の現在が、遠位大義の材料として扱われることである。

目的階層の整理は肥料候補である。

しかし、資源化への拒否を目的階層の監査へ吸収してはならない。

## 4．有限な合理と戦略的省略を分けることは有効だが、作品固有性を残す

有限な合理、戦略的な省略、目的の偽装・置換を分けることは有効である。

しかし、作品内のキュゥべえを、一般的な情報管理主体の例に落とし切ってはならない。

キュゥべえには、作品上の怖さがある。

感情のズレ、言葉の通じなさ、契約の軽さ、少女たちの切実さ、視聴者が後から理解する構造、物語上の絶望がある。

これらを、情報非対称性の一般モデルへ落とすと、作品固有の圧が薄くなる。

作品読解として確認できる部分、本文側の文明論的な押し広げ、AI・メディアへの接続を分ける。

## 5．AIとの接続は有効だが、AI企業批判を比喩で証明しない

旧ファイルは、キュゥべえ論とAI論を接続していた。

この接続は有効である。

AIは、問われた範囲にもっともらしく答え、問われていない前提・代替案・副作用を出さず、利用者が質問を作るために必要な情報を欠かせることがある。

また、安全、利便性、公益という公式目的の陰で、製品側・企業側の近位目的や利害が見えにくくなることがある。

ただし、キュゥべえ論は、AI企業の悪意を証明する比喩ではない。

出力上の省略・変形、公開目的と仕様、設計上の報酬・安全・事業上の利害、企業やモデルの意図に関する推論を分ける。

同時に、分けることによって設計主体の責任を弱めない。

AIとの接続は、比喩による断罪ではなく、情報を持つシステムが何を質問可能にし、何を自発的に開示しないかを見るための補助線である。

## 6．「個人の資源化」を、監査項目ではなく拒否として残す

ここが最重要である。

旧ファイルでは、次のように整理していた。

```text
情報保有者と情報不足者
質問を設計できる側とできない側
契約の全体効果を知る側と知らない側
目的を定義する側と資源化される側
```

この整理は有効である。

しかし、「目的を定義する側と資源化される側」と書いた瞬間に、個人の資源化が監査項目になる危険がある。

本来は、もっと直接に残す必要がある。

```text
誰かの遠位大義のために、現在の個人を資源として扱うな。

説明責任を果たせばよい、という話ではない。

同意条件を整えればよい、という話でもない。

その世界そのものを選ぶのか、選ばないのかの問いである。
```

この拒否を、情報非対称性の一項目へ下げない。

## 7．確認済み部分と推測部分を分けるが、強度を消さない

旧ファイルは、公開記事本文で確認できる部分と、過去の対話で置かれた本文より強い仮説を分けていた。

これは必ず残す。

確認できる部分は次である。

```text
キュゥべえは宇宙全体を知る超越者ではなく、有限な観測範囲にいる内部文明かもしれない。
嘘をついていない可能性はあるが、有限な合理を全体合理として語っている可能性がある。
近位の文明段階上昇、遠位の拡大、宇宙全体の延命が一本の正当化へ縫い合わされている。
「人類」「宇宙」「利益」が抽象化され、現在の少女や地球文明の犠牲が遠位大義へ回収されている。
```

本文より強い仮説は次である。

```text
聞かれた事実には露骨な嘘をつかない。
聞かれない重要事項には意図的に触れない。
情報を取捨選択し、相手が作れる質問の範囲を管理する。
自分の本当の近位目的については、質問されても遠位の大義を答え、正直に開示しない可能性がある。
```

後者は、作品内で明示された設定としてではなく、作中行動と本文の文明段階仮説から置いた解釈・推測として保持する。

ただし、推測だと明示することは、拒否の強度を弱めることではない。

事実確認の階層と、規範的拒否の強度は別である。
