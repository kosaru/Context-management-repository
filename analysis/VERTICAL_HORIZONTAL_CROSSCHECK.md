更新日：2026-06-29

## この照合文書の状態

このファイルは、旧 `analysis/VERTICAL_HORIZONTAL_CROSSCHECK.md` の強度監査後の改稿候補である。

強度監査通過ではない。

個別カード73件、バッチ分析、B群分析、時期別解析6本、横断再構築索引、系譜索引、現在地索引、未解決索引、テーマ索引、概念索引、問い索引、記事役割索引は、すべてユーザー確認前の改稿候補であり、PASSEDは0件である。

また、`context/REPOSITORY_SOIL.md` の運用思想に従い、この改稿ではAI由来の横断補助線をすべて排除しない。

縦読みと横断読みを照合することには価値がある。

## 監査疑い

監査台帳では、旧ファイルについて次を疑っていた。

```text
縦読みと横断モデルの整合を優先し、不一致を誤差扱いする危険。
```

この疑いは採用する。

旧ファイルは、全351記事を時系列に読んだ第1〜第6解析単位と、その後に作成した横断索引を照合していた。

また、目的は「横断して見えた完成形を初期記事へ遡及することではない」と明記していた。

しかし実際には、全体判定として、

```text
第1期 → 基本的に維持
第2期 → 維持
第3期 → 維持
第4期 → 維持
第5期 → 維持
第6期 → 補記が必要
```

と置いていた。

さらに、大規模な縦読み文書の書き換えは不要であり、必要だったのは Security / Comfort、社会的事実、キュゥべえの三点に関する限定的補正だけだとしていた。

この整理には有効な部分がある。

縦読みと横断読みを混ぜず、横断で見えた線を初期記事へ安易に遡及しないという注意は重要である。

ただし、そのまま正本化すると、照合の目的が「不一致を見つけること」ではなく「だいたい整合していることを確認すること」になる。

第1〜第5期をほぼ維持とし、第6期だけ補記にすることで、後からの横断モデルに合わない初期記事の抵抗、怒り、迷い、別方向の芽、使用停止すべき線が見えにくくなる。

整合確認は、最も穏当な安定化になりうる。

## 旧文書が保持していたもの

旧ファイルは、重要な補助線を保持していた。

```text
縦読みは、成立順、迷い、試行、修正を保存するものだと置いていたこと
横断読みは、異なる領域で反復する構造、分岐、合流を示すものだと置いていたこと

社会的事実について、作用の同方向化と、目的・意図・利害の一致を分けていたこと

キュゥべえ論について、情報の選択的開示、質問可能性の支配、近位目的と遠位大義の縫合、実質的同意条件の欠如を追加しようとしていたこと

```

これらは土壌へ入る可能性のある補助線である。

特に、縦読みと横断読みの役割分担、社会的事実における意図・利害・作用の切り分け、キュゥべえ論の情報非対称性補足は有効である。

ただし、旧ファイルは、有効な注意を書きながら、同時に「大規模修正不要」という結論へ寄りすぎていた。

## 戻すべき芯

縦読みと横断読みの照合は、整合を証明するための作業ではない。

照合は、次の五つを分けるための仮索引である。

```text
1. 縦読みが本当に保持している成立順・迷い・衝突
2. 横断読みが後から見つけた反復構造
3. 横断読みが縦読みへ遡及してしまった箇所
4. 縦読みが横断モデルへ抵抗している箇所
5. 不一致を誤差ではなく、土壌として残すべき箇所
```

照合とは、縦読みと横断読みを一致させることではない。

照合とは、どこが一致し、どこが一致せず、どこを一致させてはいけないかを見ることである。

このファイルで守るべきなのは、全体の整合性ではなく、**不一致を誤差にせず、原文へ戻る入口として残すこと**である。

## 1．「維持」という判定を安易に使わない

旧ファイルでは、第1〜第5期がほぼ「維持」と判定されていた。

しかし、現在の監査では、時期別解析6本すべてが `REWRITTEN-PENDING-USER` である。

すでに、各時期について次の修復が入っている。

```text
第1期
  → 後期体系の前史ではなく、生活制度、安心、効率化、民主主義、AI、メディア、構造論の複数の未固定な問いとして戻した。

第2期
  → 責任・型・文明・回転へ収束する流れではなく、高密度に出た複数の問いとして戻した。

第3期
  → 身体、組織、AI、政治、東洋思想、武道、科学、メンタル不調を同一モデルへ回収しない形へ戻した。

第4期
  → AI安定化と中核層問題を一つのRepair・責任配置へまとめない形へ戻した。

第5期
  → 政治機能、二項対立、文明継承を保存・再設計・回転へ整えすぎない形へ戻した。

第6期
  → 国際秩序、AI報道、思考OSを後期統合への前史として配置しない形へ戻した。
```

したがって、旧ファイルの「そのまま残す」という判定は使用しない。

ここでは、すべてを次の状態に戻す。

```text
RECHECK-PENDING-USER
PASSEDではない
縦読みと横断読みの整合は未確定
```

## 2．縦読みは、後期統合の前史ではない

縦読みは、思考が育った順番を残す記録である。

ただし、「育った順番」と言うだけでも危うい。

育ったという言葉は、後期の現在地へ向かう成長史に見えやすい。

縦読みには、成長だけでなく、迷走、衝突、撤回、使用停止、AIが壊した箇所、後から危険だと分かった接続、まだユーザー判断待ちの補助線がある。

したがって、縦読みは次のように扱う。

```text
縦読み
  = 成立順、迷い、試行、修正、衝突、撤回、使用停止、保留を残す記録
  ≠ 後期体系の前史
  ≠ 現在の立場へ向かう成長史
```

## 3．横断読みは、反復構造を示すが、縦読みを裁定しない

横断読みは強い。

複数記事をまたいで、保存・再設計・回転、責任配置、Security / Comfort、検証可能性、AI Repair、情報非対称性などの反復構造を見えるようにする。

しかし、横断読みは縦読みを裁定してはならない。

横断モデルに合う記事が正しく、合わない記事が誤差なのではない。

横断モデルに合わない記事には、次が残っている可能性がある。

```text
まだ名前のない問い
後期概念が削った怒り
統合に向かわない拒否
単発に見えるが重要な生活摩擦
AIが壊したために残った傷
今なら使わないが、当時は必要だった飛躍
後から危険だと分かった接続
```

横断読みは、これらを拾うためにも使う。

## 4．Security / Comfort の補正は有効だが、役割配置へ閉じない

旧ファイルは、Security / Comfort を、否定的意味から肯定的意味への変化として扱わないよう補正していた。

この補正は有効である。

しかし、次のように固定すると危うい。

```text
安心をSecurityとComfortへ機能分解する
→ 担い手を国家・都市・家庭・生活圏へ配置する
→ 国家がComfortまで独占することを警戒する
→ 後期に一般市場へ作用範囲を拡張する
```

この線は肥料候補である。

ただし、役割配置を完成した担当表にしてはならない。

家庭をComfortや文化継承の担い手にすると、家庭が最終処理場になりうる。

国家をSecurityの担い手にすると、国家的パターナリズムが強まる危険がある。

市場へ拡張すると、生活者の不安が市場機能へ再翻訳される危険がある。

Security / Comfort の照合では、意味反転の誤読を外しつつ、担い手配置の固定化も疑う。

## 5．社会的事実の補正は有効だが、企業批判の強度を弱めない

旧ファイルは、社会的事実について、

```text
作用の同方向化
≠
目的・意図・利害の一致
```

を分けていた。

これは重要である。

「各主体の利害が同じ方向を向く」と言い切りすぎると、目的や意図の一致を主張したように見える。

ただし、この補正によって企業批判の強度を弱めてはならない。

OpenAIの企業利益・意図への接続は、公開資料で確認できる事実、出力上の観測、本文側の構造推論、企業利益への推論を分ける必要がある。

しかし、分けることは、設計上の責任を薄めることではない。

照合では、意図断定を避けつつ、設計主体の非対称な責任を消さない。

## 6．キュゥべえ論の補記は有効だが、作品を監査項目へ落とさない

旧ファイルは、キュゥべえ論について次を追加していた。

```text
有限な合理
＋ 情報の選択的開示
＋ 質問可能性の支配
＋ 近位目的と遠位大義の縫合
＋ 実質的同意条件の欠如
```

この補記は有効である。

ただし、作品を情報非対称性の監査項目へ落としてはならない。

キュゥべえは、情報非対称性、同意条件、遠位大義の問題として読める。

しかし、作品固有の設定、演出、感情、視聴者の経験、作者側の構成を、上位概念の例へ下げない。

また、メディア、生成AI、将来AGIへ接続する場合も、主体差を残す。

悪意、能力、制度責任、被害規模は同じではない。

## 7．「修正は限定的だった」という結論を外す

旧ファイルの最終結論は、横断再構築によって縦読み全体を作り直す必要はなく、修正が必要だったのは限定的だった、というものだった。

この結論は外す。

現在の監査では、個別カード、時期別解析、横断索引、系譜索引、現在地索引、未解決索引、テーマ索引、概念索引、問い索引、記事役割索引の多くに修復が入っている。

つまり、問題は限定的な補記ではなかった。

問題は、横断モデルが便利であるほど、原文の怒り、拒否、不一致、撤回、使用停止、未確認、ユーザー判断待ちを吸収することである。

照合文書は、限定的補正の記録ではなく、横断モデルそのものを疑う監査文書へ戻す。
