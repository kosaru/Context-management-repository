## 原文から保持した最強命題

> **陰謀は実在する。しかし、それは全能の強者が長期的・全体的に社会と歴史を所有する装置ではない。陰謀とは、その局面で正面から目的を通せない側が使う弱者の戦略であり、短期的に効くことがあっても、実行、影響範囲、代理人、反作用、長期的帰結を完全には所有できない。したがって、陰謀はあるが、陰謀論が描くような長期的・全体的・全能の陰謀は現実説明として存在しない。必要なのは陰謀分析である。**

## 三つの命題を分離せず保持

```text
陰謀はある
  → 秘密工作、欺瞞、内応、情報操作、隠蔽、分断は実在する

陰謀は弱者の戦略である
  → その局面で正面から目的を通せない側が使う奇手である

陰謀論はない
  → 長期的・全体的・全能の支配計画は現実説明として成立しない
```

「陰謀論はない」は、陰謀論という言葉や言説が存在しないという意味ではない。原文は、その言説が人を動員し、対立を固定し、社会の判断力を壊しうることを明記する。

## 「弱者」の限定

原文の弱者は、社会的弱者、被害者、道徳的に正しい側ではない。

```text
その局面で
  → 正面から命令できない
  → 制度で通せない
  → 公然と動けば責任を問われる
  → 相手の抵抗を突破できない
  → 正統性を失う
```

国家、軍、大企業、情報機関も特定局面ではこの位置に立ちうる。

したがって、弱者の戦略であることを、工作主体の免責や正当化へ使ってはならない。

## 統治技術と被支配者経験の非対称性

植民地支配について、原文は同じ操作を次のように分ける。

```text
支配者側
  → 少数で多数を統治する合理的技術
  → 現地エリート、分類、法、協力者、治安言語を使う

被支配者側
  → 社会関係を外部から操作される
  → 内部対立を利用される
  → 代表性を書き換えられる
  → 抵抗を反乱・無秩序として名づけ直される
```

これは主観差の紹介ではない。制度、分類、代表性、流通、治安言語を設計する側と、操作対象になる側の非対称性である。

## 奇手の効果と所有不能

原文は、陰謀が短期的に効くことを否定しない。

しかし、次を分ける。

```text
短期的効果
  → 政敵排除、分断、世論誘導、判断のずれ、制度変更、時間稼ぎ

実行過程
  → 代理人の利害、内応者の裏切り、現場の暴走、命令のずれ

影響範囲
  → 味方の誤認、自陣営の崩壊、敵の結束、情報の越境

長期的反作用
  → 不信、恨み、報復、革命、制度劣化、信用低下、内部腐敗
```

原文の結論は、「工作にはリスクもある」ではない。

> **陰謀は、短期の勝利を作ることはある。しかし、長期の歴史を所有することはできない。**

## 陰謀論の誤りとして保持したもの

陰謀論の誤りは、陰謀を疑うことではない。

- 局所的な奇手を長期的な全体支配へ拡張する
- 複数主体、対抗勢力、内部対立、偶然、制度反応を消す
- 失敗、対立、反証まで巨大計画の証拠へする
- 自分が採用した裏説明を疑わない

このため、歴史上の陰謀の実在は陰謀論を正当化せず、陰謀論の不成立は現実の工作を否定しない。
