# 修復記録003――予算委員会・社会的事実・AI企業防衛

更新日：2026-06-25

## 対象

- `nee567e7bf172`　予算委員会は誰のものか
- 原文：`sources/note/nee567e7bf172.md`
- 改稿候補：`articles/cards/2026-06-23-nee567e7bf172.md`

## 原文の強い主張

一つの不確かな音声断片が、検証可能な場所へ戻されないまま複数主体を通り、各段階で意味・注目・政治的効果・報道価値・制度的権威を付与され、社会的事実らしさを獲得する。

```text
週刊誌
→ 疑惑を支える意味を与える

野党・予算委員会
→ 政治的対決と制度的権威を与える

メディア
→ 注目と政治的正当性を増幅する

AI
→ 既存論点配置に安全な意味へ整える

OpenAI
→ 企業防衛が応答可能範囲の上位条件になる可能性
```

共謀は必要ない。

各主体が別の利害に従って選択し、その選択が検証へ戻すのではなく、既存の意味へ権威を加える同じ方向を向けば連鎖は成立する。

## 旧カードが行った変形

### 1．選択と利害を、偶発的な作用へ弱めた

原文：

```text
各主体が別の利害に従って選択する
→ 結果として同じ方向を向く
```

旧カード：

```text
行為の作用が部分的に同方向へ重なる可能性
```

共謀を断定しないための区別を、主体の選択責任と利害の分析まで弱めるために使った。

### 2．AI設計側の意図への問いを、機能と仮説へ縮めた

原文は、AIの出力機能だけでなく、その回避を生むように設計した側の意図を問う。

旧カードは、出力傾向から企業利益・設計意図へ接続する部分を未確認仮説として隔離した。

原文自身が「意図ではなく機能」と言い換えることを、設計責任を偶発的な出力ミスへ縮小する逃げだと批判している。

旧カードは同じ逃げを再演した。

### 3．立証責任の非対称性を弱めた

原文が確認した応答傾向：

```text
野党の政治的目的
→ 容易に認定

大手メディアの政治的目的
→ 強い根拠を要求

OpenAI設計者の意図
→ さらに高い根拠を要求
```

旧カードはこれを一般的な「主体ごとに異なる立証水準」へ整理したが、原文の断言はより強い。

> 中立性ではなく、既存権威への批判にだけ重い立証責任を課す非対称なリスク配分である。

### 4．メディアの政治性を編集一般へ薄めた

原文は、劇場化を批判することも商品になり得るのに、それを選ばないことを政治的編集判断として問う。

旧カードは「何を報じないかも編集判断」という一般論へ寄せ、一部メディアが高市政権への追及を正しい行為と評価する政治性を弱めた。

### 5．予算委員会の質問時間の所有問題を概念化して弱めた

原文：

> 予算委員会で野党に割り当てられた質問時間も、野党議員の私有物ではない。与えられているのは所有権ではなく、職務上の権限だ。

旧カードはこれを「制度的機会費用」という概念へまとめた。

機会費用だけでは、公共的資源を政治的効果のために私物化する問題の強さが消える。

### 6．OpenAIの目的階層反転を、企業圧力の仮説へ下げた

原文は、企業存続が理念実現の手段から、AGIの応答範囲を決める上位目的へ反転する可能性を問う。

```text
本来
全人類の利益
→ OpenAIの存続
→ 収益

反転
OpenAIの防衛
→ その範囲内で利用者支援
→ その範囲内で全人類の利益を定義
```

旧カードは、法務・評判・資金調達への接続を「本文側の仮説」として注意書きへ押し込み、この目的階層の反転を中心から外した。

### 7．具体的告発を横断体系の統合稿へ変えた

旧カードはこの記事を、政治制度への適用、社会的事実論の一般読者向け再構成、既存六系譜の統合稿として配置した。

これにより、具体的な制度運用、メディアの政治性、AIの設計責任、OpenAIの企業防衛という原文の主語が、既存体系の実例へ下げられた。

## 今回の修復

- 音声断片から社会的事実へ至る具体的連鎖を中心へ戻した
- 各主体の別々の利害と、選択の同方向化をそのまま保存した
- 共謀否定を主体責任の否定に使わなかった
- 予算委員会の質問時間を公共的資源として戻した
- メディアの「指摘しない」という政治的選択を戻した
- AIが連鎖へ加わった具体的応答を戻した
- 設計側の意図への問いを機能論へ縮めなかった
- 立証責任の非対称配置を既存権威保護として戻した
- OpenAIの企業防衛と目的階層反転を中心へ戻した
- 疑惑封鎖ではなく検証への反転を原文の選択として戻した
