# 修復記録028――寛解は「心」ではなく「配置」で起こる

更新日：2026-06-25

## 対象

- `n76a3521b3b86`　寛解は「心」ではなく「配置」で起こる
- 原文：`sources/note/n76a3521b3b86.md`
- 改稿候補：`articles/cards/2026-03-06-n76a3521b3b86.md`

## 一次監査の疑いを修正する

監査台帳では、旧カードが、

```text
「心ではなく配置」という強い反転
↓
医学的慎重さ・複数要因の整理
```

によって原文を丸めた可能性を疑っていた。

しかし原文自身が、

```text
認知や考え方は無関係ではない
私の経験として言う
配置で起こることがある
少なくとも私のケースでは
```

と限定している。

したがって、普遍的な単一原因論へ強めることは原文の強度保持ではない。

保持すべき強さは、

```text
配置を固定したまま認知を完全に直させるのは筋が悪い
現実の圧力が残ったまま内面だけで勝たせると折れる
```

という判断順序への批判である。

## 原文の強い主張

メンタル不調は、すぐに認知、考え方、性格、自己理解の問題へ寄せられる。

原文はそれらを否定しない。

しかし自身のケースでは、症状が直属上司との接触時に集中していた。

```text
反芻
不眠
身体の緊張
休日にも会話を再生する
```

一方、それ以外では完全に何もできないわけではなかった。

そのため、原因を自分全体へ広げず、

```text
全部が壊れている
↓
壊れる条件がある
```

と切り分けた。

取れる手を、

```text
距離を取る
関わり方を変える
配置を変える
```

の優先順位で置く。

認知の完全修復ではなく、接触、返答、記録、境界を変え、少し乱れても戻れる運用を作る。

最終的に上司から離れ、配置が変わると症状が軽くなった。

原文はそれを、

> 治ったというより、無理が消えた

と表現する。

## 旧分析が保持していたもの

旧カードは次を概ね保持していた。

- メンタル不調を認知や性格へ一般化しないこと
- 特定上司との接触に症状が集中した経験
- 原因を本人全体ではなく壊れる条件へ限定すること
- 距離・関わり方・配置転換の優先順位
- 接触時間、返答、第三者、記録、引受け範囲の運用
- 認知行動療法の一部を有効と認めること
- 配置を固定した内面矯正への違和感
- 配置変更後の改善を、無理が消えた結果として捉えること
- 内面を否定せず、配置を先に疑う順序

したがって、旧カードを内容上の誤読とは扱わない。

## 旧分析が行った変形

### 1．後期の退出可能性・責任配置の根へ固定した

旧カードは本記事を、

```text
退出可能性
関係の運用
責任配置
```

の具体的な根と位置づけた。

接点はあるが、本記事は、自身の経験から内面矯正と環境変更の順序を反転させる独立した文章である。

### 2．同日二記事を線形発展へ配置した

旧カードは、本記事を本人の経験と判断順序、同日の上司要因記事を組織制度への変換とした。

二記事に接続はある。

しかし、個人経験が制度案へ発展し、さらに責任配置へ一般化した完成史へ固定しない。

### 3．責任分界から後期責任論への前史を作った

旧カードは、責任分界、配置、後期責任配置を一つの発展線へ並べた。

関連は探索に使えるが、本記事の「無理が消えた」という経験を体系の部品へ縮めない。

### 4．後発の制度監査を原文へ遡及した

旧カードは、

```text
壊れる条件の共同確認
複合要因の分離
配置転換による不利益排除
配置変更不能時の選択肢保障
内面支援と環境変更の主体分担
```

を残った問いへ置いた。

重要な後続課題だが、原文自身が列挙した問いではない。

### 5．原文外の棄却読みを追加した

旧カードには、環境だけが常に原因、認知行動療法は有害、誰でも離れれば寛解、本人側の認知は検討不要、配置転換できなければ治療不能などが置かれた。

一般化を避ける注意としては理解できるが、原文が実際に提示して退けた反論として確認できないものを本人の棄却読みへ置かない。

### 6．必要な医学的留保が社会的含意まで弱める余地を作った

原文は個人経験であり、診断・治療の普遍的指針ではない。

この注意は必要である。

しかし、その注意を使って、

```text
逃げられない配置を原因候補へ入れる
内面の完全修復より先に距離・運用・配置を検討する
```

という原文の順序まで、単なる一事例へ閉じない。

## 今回の修復

- メンタル不調がすぐ心の問題へされる出発点を戻した
- 認知や考え方が無関係ではないという原文自身の限定を保持した
- 配置を相性ではなく、逃げられない関係・権力差・評価と生存が結びつく接触として戻した
- 直属上司との接触時に症状が集中した経験を戻した
- 本人全体の欠陥ではなく、壊れる条件へ限定する切り分けを戻した
- 距離→関わり方→配置転換の優先順位を戻した
- 接触・返答・記録・境界を崩れない運用として戻した
- 完璧な思考より、少し乱れても戻れる仕組みを戻した
- 認知行動療法の有効部分を認めつつ、配置を固定した内面矯正を拒む位置を戻した
- 配置変更後の改善を「治った」ではなく「無理が消えた」とする経験を戻した
- 少なくとも自身のケースでは配置が主因だったという限定付きの確信を戻した
- 後期の退出可能性・責任配置・内部SLAへの前史化を外した
- 原文外の制度監査・棄却読みを本人の思想として表示しなかった
