## 一次監査の疑いを修正する

監査台帳では、旧カードが、「人が動ける」と「人を動かせる」の権力差を、流動性の条件整理へ均した可能性を疑っていた。

Security、Comfort、信用のポータビリティ、内部SLAは、旧カードが弱めるために後から入れた条件ではない。

原文自身が、働く人の自由としての流動性を成立させる条件として提示している。

したがって、条件整理そのものを安定化とは判定しない。

修復点は、次の原文の非対称を前面に戻すことだった。

```text
労働力の流動性は、政策の言葉では「人が動ける自由」に見える
しかし生活者には「企業が人を動かせる自由」に見えやすい
主語を曖昧にすると、働く人の自由のように見えて、企業の調達可能性だけが高まる
安心の土台がないまま流動性だけを高めれば、自由ではなく不安定化になる
```

## 原文の強い主張

労働力の流動性は、政策や経済の言葉としては前向きに語られる。

しかし、多くの生活者には、正社員でいられなくなる、会社に切られやすくなる、非正規や派遣に流される、社会的信用まで落ちる、会社が人を使い捨てしやすくなる、という不安として届きやすい。

人が動ける社会と、人を動かせる社会は違う。

人が動ける社会は、働く人が自分の意思で職場を選び直せる社会である。

人を動かせる社会は、企業が必要なときに人を集め、不要になれば外へ出せる社会である。

流動性そのものは悪ではない。

本来は、一つの会社に人生を預けず、合わない職場から離れ、子育てや介護に合わせて働き方を変え、失敗しても戻れる自由になりうる。

だが、現実には企業側の人材調達、固定費の変動費化、教育や待機や生活不安の外部化へ先に効きやすい。

働く人に必要なのは、市場に出されることではなく、動いても生活が壊れないこと、社会的信用を失わないこと、戻れる場所があることである。

## 旧分析が保持していたもの

- 人が動ける社会と、人を動かせる社会の区別
- 流動性そのものを否定しないこと
- 企業側へ先に効きやすい非対称性
- Security と Comfort を労働市場に置くこと
- 社会的信用のポータビリティ
- 流動性と生活予測性の接続
- 外部SLAだけが強くなると負荷が契約の弱い場所へ流れること
- 正社員だけを見ても足りないこと
- 人が動ける社会には戻れる場所が必要なこと
- 減速のイノベーションを、人を市場へ放り出す流動性ではなく、動ける自由と壊れない安心の両立として置くこと

したがって、旧カードを中心内容の誤読とは扱わない。

## 旧分析が行った変形

### 1．非対称性を条件整理へ均しやすくした

旧カードは Security、Comfort、信用、内部条件を整理した。

その結果、「働く人の自由のように見えて、企業の調達可能性だけが高まる」という批判がやや後ろに回った。

### 2．社会的信用の範囲が弱まった

原文は、雇用形態が変わると、企業だけでなく、社会、金融機関、住居市場、家族形成や将来設計に対しても弱くなると書く。

### 3．負荷移転の連鎖を穏当に置いた

正社員から非正規、派遣、下請け、委託、個人事業主へ負荷が流れる構造を、内部条件の問題としてではなく、契約の弱い場所へ移っただけという批判として戻す必要があった。

### 4．外国人労働者の論点を弱めた

原文は、外国人労働者が増えること自体ではなく、なぜ安い労働力が必要とされるのかを問う。

### 5．育成責任の文を弱めた

原文は「労働力の流動性は、企業の育成責任を消すための言葉であってはならない」と書く。

ここは中心へ戻す必要があった。

### 6．後続モデルへ固定しやすかった

本記事を減速のイノベーションの労働市場モデルへ固定しすぎると、原文末の「人が動ける社会と、人を動かせる社会は違う」という直接の警告が薄まる。

## 今回の修復

- 労働力の流動性が生活者には不安として届きやすいことを戻した
- 人が動ける社会と人を動かせる社会の主語差を戻した
- 働く人の自由のように見えて企業の調達可能性だけが高まる危険を戻した
- 流動性そのものを否定しないことを戻した
- 本来の流動性を一般市民に有利な自由として戻した
- 企業側へ先に効きやすい調達可能性、固定費の変動費化、教育・待機・生活不安の外部化を戻した
- Security と Comfort を戻した
- 社会的信用のポータビリティを戻した
- 流動性と生活予測性の接続を戻した
- 負荷が契約の弱い場所へ移っただけであることを戻した
- 正社員だけでなく労働の連鎖全体を見る必要を戻した
- 外国人労働者が増えること自体ではなく、なぜ安い労働力が必要とされるのかを問う位置を戻した
- 労働力の流動性は企業の育成責任を消す言葉であってはならないことを戻した
- 戻れる場所としての Security、戻った先で壊れず続ける Comfort を戻した
- 人が動ける自由と動いても壊れない安心を両立させる結論を戻した
