## 一次監査の疑いを修正する

監査台帳では、旧カードが、逃げ道を削る文明への批判を、伸縮性の構成要素へ整えすぎた可能性を疑っていた。

この疑いは半分だけ採用する。

文明の伸縮性、三条件、ゆとりを可動域として見ることは、旧カードの後付けではなく、原文自身の中心構造である。

ただし旧カードは、伸縮性の整理が前面に出たぶん、原文冒頭の切迫した問いを弱めやすかった。

```text
無駄を削ったつもりで、逃げ道を削っていないか
戻る場所、失敗を吸収する余白、場を心地よく保っていた暗黙の働きまで削っていないか
名前がついていないから、数字になりにくいから、説明しにくいから、無駄として切っていないか
```

## 原文の強い主張

無駄を削ることは必要である。

本当に無駄なものは削ってよい。

しかし、何を無駄と呼ぶのかを間違えると、人が戻る場所、失敗を吸収する余白、場を心地よく保っていた暗黙の働きまで削ってしまう。

短期効率だけで見ると、使われていないもの、余っているもの、待っている時間、重なっている役割、予備の人員、複数の手段、遠回り、雑談、練習、失敗、やり直しは無駄に見える。

しかし、災害時にも止まらないこと、失敗しても戻れること、人が倒れても誰かが支えられること、子どもや高齢者や障害のある人も役割を持てること、人口やエネルギーが下がっても文明が破れないことを目的にすると、それらは文明の伸縮性になる。

ゆとりとは、余りではなく可動域である。

伸縮性は、複数の選択肢、失敗してもやり直せること、複数人で役割を重ねることでできている。

ただし、マルチロール化だけを取り出すと人は壊れる。

それは、柔軟性という名の負荷移転である。

心地よさは飾りではなく、人がそこに居続けるための伸縮性である。

## 旧分析が保持していたもの

- 無駄を削ること自体は否定しないこと
- 逃げ道を削っていないかという問い
- ゆとりを余りではなく可動域として見ること
- 伸縮性を、複数の選択肢、やり直し、複数人で役割を重ねることとして見ること
- 選択肢を一つに絞るほど逃げ道が消えること
- やり直しを文明のエラー処理とすること
- マルチロールだけでは人が壊れること
- アジャイルのつまみ食いを、柔軟性ではなく圧縮管理とすること
- すでにある伸縮性を、無駄として切り捨てないこと
- 説明できない伸縮性が無駄として削られること
- 心地よさを、人が居続けるための伸縮性とすること

したがって、旧カードを中心内容の誤読とは扱わない。

## 旧分析が行った変形

### 1．切迫した問いを構成要素へ寄せた

旧カードは、文明の伸縮性の構成をうまく整理していた。

その結果、「無駄を削ったつもりで、逃げ道を削っていないか」という冒頭の問いが、やや概念整理の中へ収まりやすかった。

### 2．逃げ道の具体が薄まった

原文での逃げ道は、単なる代替手段ではない。

戻る場所、失敗を吸収する余白、場を心地よく保っていた暗黙の働き、説明できない手順や関係、参加し続けられる空気まで含む。

### 3．マルチロール批判を弱めた

原文は、複数の役割を持つことを肯定しながら、みんなが何でもやれ、できる人がやれ、へ滑る危険を強く拒否する。

### 4．名前のない伸縮性を後景化した

家庭、職場、地域、道場、趣味の場にすでにある暗黙の支え合いを、名前がない、数字にならない、説明しにくいという理由で切る危険を戻す必要があった。

### 5．心地よさを後続 Comfort 論へ吸収しやすかった

原文の心地よさは、ここでは人が場に居続けるための伸縮性である。

後続の Security / Comfort 論へ回収しきらず、この記事自身の位置で戻す必要がある。

### 6．原文外の残問を置きすぎた

判定方法、制度化、費用負担、評価指標などは重要な後続課題だが、原文自身が直接答えたものとしては区別する。

## 今回の修復

- 無駄を削ること自体は否定しないことを戻した
- 「無駄を削ったつもりで、逃げ道を削っていないか」を中心へ戻した
- 戻る場所、失敗を吸収する余白、暗黙の働きを戻した
- ゆとりを余りではなく可動域として戻した
- 文明の伸縮性を三条件として戻した
- 一つに絞るほど逃げ道が消えることを戻した
- やり直しを文明のエラー処理として戻した
- マルチロールだけを取り出すと人が壊れることを戻した
- 柔軟性の名を借りた圧縮管理への批判を戻した
- すでにある伸縮性を、無駄として切り捨てないことを戻した
- 名前のついていない伸縮性、説明できない伸縮性を戻した
- 心地よさを、人がそこに居続けるための伸縮性として戻した
- 減速のイノベーションは、文明をだぶだぶにすることではないと戻した
- 無駄を削る前に、何を削っているのかを見る結論を戻した
