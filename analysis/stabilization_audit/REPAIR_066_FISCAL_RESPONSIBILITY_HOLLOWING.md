# 修復記録066――財政を守る主体はいる。だが、財政を生む景気を誰が守るのか

- `ne93c5cbf00aa`　財政を守る主体はいる。だが、財政を生む景気を誰が守るのかーー国の帳簿ではなく、税源を生む生活循環から考える

## 一次監査の疑いを修正する

監査台帳では、旧カードが、財政を生む生活循環を誰も守らないという告発を、主体間の役割配置へ均した可能性を疑っていた。

この疑いは、一部だけ採用する。

旧カードは、日銀、財務省、各省庁、政府の機能差を大きく消してはいなかった。

しかし、「政府の統合責任」「主体間の役割配置」といった語が前に出ると、原文の告発の鋭さが制度設計語に寄りやすい。

修復の中心は、次を戻すことだった。

```text
財政の話が生活から切り離され、政府の帳簿の問題へ縮む危険
帳簿を整えることと、財政を支える力を太くすることは同じではないという区別
景気を壊した財政再建は、財政再建ではなく、税源を削る政策になるという強い言い切り
制度側では分解されるが、生活側では分解されない非対称
担当は多すぎるほどあるのに、生活側に落ちてくる景気全体を引き受ける主体が見えないという告発
景気責任が空洞化すると、負担だけが生活側に落ちてくるという結論
```

## 原文の強い主張

国の財政は、政府の帳簿の中から湧いてくるわけではない。

税収は、国民の所得から生まれる。

企業の利益から生まれる。

消費から生まれる。

投資から生まれる。

雇用から生まれる。

税収の土台は、民間経済の活動である。

つまり、財政の根本には景気がある。

財政を守るとは、帳簿を守ることではない。

税収を生む景気循環を守ることである。

景気を壊した財政再建は、財政の土台を壊す。

税源を痩せさせる財政再建は、財政再建ではない。

帳簿を守るふりをした、財政基盤の破壊である。

制度側では分解される。

生活側では分解されない。

政策がまったくないわけではない。

担当が存在しないわけでもない。

むしろ、担当は多すぎるほどある。

しかし、生活側に落ちてくる景気全体を、誰が一つの循環として引き受けているのかが見えない。

財政を守る主体はいる。

だが、財政を生む景気を守る主体が見えない。

その空洞のツケを支払わされるのは、結局、家計であり、国民である。

## 旧分析が保持していたもの

- 財政は政府の帳簿から生まれないこと
- 税収を生む国民生活と企業活動の循環から財政が生まれること
- 帳簿を整えることと、税源を太くすることは同じではないこと
- 景気を壊した財政再建は、財政再建ではなく税源を削る政策になること
- 日銀は円という社会共通の物差しを守ること
- 日銀は景気循環そのものを作る主体ではないこと
- 財務省は財政管理主体だが、財政を生む景気循環を太くする主体ではないこと
- 制度側では分解される一方、生活側では一体の重さとして現れること
- 景気をGDPや株価ではなく、円で生活と投資が成り立つ循環として見ること
- 財政責任の空洞化は、景気責任の空洞化から始まること

したがって、旧カードを中心内容の誤読とは扱わない。

## 旧分析が行った変形

### 1．政府の統合責任という語に寄りやすかった

政府の責任は原文にもある。

しかし、「統合責任」と整理すると、原文の「誰が守るのか」という告発が制度設計語に寄りやすい。

### 2．主体間の役割配置へ見えやすかった

日銀、財務省、各省庁、政府の機能差は原文自身にある。

ただし、原文の中心は役割整理ではなく、財政を生む景気循環を生活側から引き受ける主体が見えないことへの告発である。

### 3．生活側の重さが弱まりやすかった

原文は、物価高、手取り、税と社会保険料、住宅費、消費余力、将来不安が、生活側には一体として来ると書く。

この一体の重さを戻す必要があった。

### 4．帳簿責任への批判が弱まりやすかった

原文は、財政責任が帳簿責任へ縮むことを強く批判している。

ここを制度間の調整問題にしてはいけない。

### 5．原文外の後続課題を置きすぎた

政府の景気統合責任をどの会議体・指標・組織へ具体化するかは重要な後続課題だが、原文自身が直接答えたものとしては区別する。

## 今回の修復

- 財政は政府の帳簿から生まれないことを戻した
- 財政は、国民生活と企業活動の循環から生まれることを戻した

- 財政を守るとは、帳簿を守ることではなく、税収を生む景気循環を守ることだと戻した
- 景気を壊した財政再建は、財政再建ではなく税源を削る政策になることを戻した
- 税源を痩せさせる財政再建は、帳簿を守るふりをした財政基盤の破壊であることを戻した
- 日銀は円という社会の物差しを守る主体だが、景気循環そのものを作る主体ではないことを戻した
- 財務省は財政を管理する主体だが、景気循環を太くする主体ではないことを戻した
- 制度側では分解されるが、生活側では分解されないことを戻した
- 担当は多すぎるほどあるが、生活側に落ちてくる景気全体を引き受ける主体が見えないことを戻した
- 景気をGDPや株価ではなく、円で生活と投資が成り立つ循環として戻した
- 財政を守るために生活を削る発想は根本で矛盾していることを戻した
