## 一次監査の疑い

監査台帳では、旧ファイルについて次を疑っていた。

```text
異なる記事の権限差と怒りを、責任・決定・退出の一つの連鎖へ整える。
```

この疑いは採用する。

旧ファイルは、7本の記事を、

```text
責任分界
→ 決定時間
→ 決定ログ
→ 退出可能性
→ 配置
→ 修復と継承
→ 批判者の設計責任
```

という完成度の高い連鎖へ整えすぎていた。

ただし、旧ファイルを全否定するわけではない。

責任を人格へ降ろさないこと、決定を真理化しないこと、判断の鎖を残すこと、逃げられない配置を変えること、責任のない権限と権限のない責任を分けること、批判者の位置も負担配分から免除しないことは、複数の記事に実際にある。

問題は、接続することではない。

問題は、その接続を正本化し、各記事の怒り、局所性、宛先、留保、第一人称、非対称を、ひとつの責任配置モデルへ吸収することである。

## 修復の中心

修復の中心は、バッチ2を「責任・決定・退出の統合モデル」ではなく、次のように読み替えることだった。

```text
責任が人格・弱い側・生活側・現場側へ落ちる場面を、
それぞれ別の入口から押し返した記事群。
```

保持した横断仮説は、次である。

```text
責任は、きれいに設計されていない場面では、しばしば弱い場所へ落ちる。
```

ただし、この共通語で全記事を同じ話にしない。

落ち方が違う。

```text
正しさや主体性の要求が、個人の人格負担へ落ちる。
決定の時間が設計されないことで、議論の永続化か永久固定へ落ちる。
直属上司との逃げられない接触が、弱った本人の説明責任へ落ちる。
配置の圧力が残ったまま、認知や心の修正責任が本人へ落ちる。
決定過程が残らないことで、利害・代償・撤回条件が見えず、責任が浮く。
権限と負担が切れることで、ツケが弱い側へ落ちる。
批判者が土台を定義しないことで、負担配分を出さないまま道徳的正統性を維持できる。
```
