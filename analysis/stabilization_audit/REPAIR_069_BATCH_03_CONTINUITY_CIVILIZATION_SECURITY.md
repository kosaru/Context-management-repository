## 一次監査の疑い

監査台帳では、旧ファイルについて次を疑っていた。

```text
人類継続、文明保存、Securityの別々の賭けを一つの継続モデルへ統合する。
```

この疑いは採用する。

旧ファイルは、6本の記事を、

```text
Security
→ 人類継続
→ 文明保存
→ 形式知と暗黙知の循環
→ 倫理生成
→ 担い手再生産
→ 継続能力モデル
```

という完成度の高い連鎖へ整えすぎていた。

ただし、旧ファイルを全否定するわけではない。

消費税＋BIと医療リスク、人類主語、文明保存、継続構造、倫理生成、責任の最終処理装置には確かに接続がある。

問題は、接続することではない。

問題は、その接続を正本化し、各記事の未完成の違和感、短い呼びかけ、大きな賭け、第一人称の仮説、強い断定、名指しの警告を、ひとつの継続能力モデルへ吸収することである。

## 修復の中心

修復の中心は、バッチ3を「継続・文明・Securityの統合モデル」ではなく、次のように読み替えることだった。

```text
続くとは何かを別々の場所から問い、
見かけ上の継続に抵抗した記事群。
```

保持した横断仮説は、次である。

```text
継続には、見かけ上の継続と、食い潰しによる延命がある。
```

ただし、この共通語で全記事を同じ話にしない。

記事ごとの抵抗は違う。

```text
消費税＋BIの基礎保障だけでは、医療の最悪ケースが個人へ戻る。
国家を主語にすると、政策が何のためなのかが見えなくなる。
人類へ主語を上げすぎると、文明差や適応知が消える。
制度が残っていても、形式知と暗黙知の循環が切れれば継続とは言いにくい。
倫理を個人徳として語ると、倫理を経験する構造の消失が見えなくなる。
多様化と標準化を進めながら翻訳・調整コストを制度化しなければ、現場中核層の身体を食い潰して延命する。
```

## 個別記事ごとの戻し

### `n74618456f88f`

消費税＋BIの記事は、単一保障から機能別保障へ進む転換点としてではなく、消費税＋BIの前提を維持しながら、医療だけがなぜ最後まで残るのかという未完成の違和感へ戻した。

### `n32c7f9ce8053`

主語を思い出す記事は、完成した最上位命題としてではなく、国家を主語にした現実的議論から、何のための政策なのかという人類の主語を静かに戻す短い呼びかけへ戻した。

### `n4e507bf79125`

文明保存の記事は、適応知・冗長性モデルへの分解ではなく、文明多様性を残すことが、不確実な未来への合理的な賭けではないかという線へ戻した。

### `n1f714c925910`

継続構造の記事は、完成した継続能力モデルではなく、過去の継続と未来の保証を切り離し、形式知と暗黙知の循環という仮説で、共有前提の不在を問う文章へ戻した。

### `n2fcfc6a36e04`

倫理の記事は、Securityから関係倫理が生成される一般モデルではなく、仁義を学ぶ装置が消え、仁義なしで面子だけが残ると責任回避へ変わるという反転へ戻した。

### `ncf9a54061f4f`

責任の最終処理装置の記事は、担い手再生産モデルの反例ではなく、経団連と政府、企業上部、顧客・社会の要求の間で、現場の日本人中核層が翻訳機・緩衝材・責任の最終処理装置になるという名指しの警告へ戻した。
