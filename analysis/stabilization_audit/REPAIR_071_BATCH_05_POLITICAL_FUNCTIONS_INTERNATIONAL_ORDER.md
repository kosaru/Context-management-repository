## 一次監査の疑い

監査台帳では、旧ファイルについて次を疑っていた。

```text
政治陣営、国連、ドル、基地の非対称な問題を、保存・再設計・再交渉へ均す。
```

この疑いは採用する。

旧ファイルは、5本の記事を、

```text
政治ラベルを機能へ移す
→ 保存・再設計・回転条件を分ける
→ 修正可能性を制度価値へ置く
→ 文明保存型国連へ接続する
→ ドルの外周担保を読む
→ 基地用途の反転を見る
→ 用途変更時の停止・退出・再交渉モデルへ進む
```

という完成度の高い秩序再交渉モデルへ整えすぎていた。

ただし、旧ファイルを全否定するわけではない。

政治語彙を機能として読むこと、修正可能性を見ること、外周負担を可視化すること、用途変更時の再同意を問うことは、土壌へ入る可能性のある補助線である。

問題は、補助線を作ったことではない。

問題は、その補助線を正本化し、政治語彙の記事の不完全さ、文明保存型国連の記事の西洋普遍主義批判、ドル記事のトランプへの政策的判断、基地記事のホルムズ・イラン・米国・イスラエル・湾岸という具体の名指しを、一般的な保存・再設計・再交渉モデルへ吸収することである。

## 修復の中心

修復の中心は、バッチ5を「政治機能と国際秩序の再交渉モデル」ではなく、次のように読み替えることだった。

```text
ラベル・制度・通貨・基地が、
何を保存し、誰を負担へ固定し、どの非対称を隠すのかを、
別々の入口から問う記事群。
```

保持した横断仮説は、次である。

```text
秩序は、中心ではなく用途と負担で見る。
```

ただし、この共通語で全記事を同じ話にしない。

記事ごとの問いは違う。

```text
政治ラベルは、観察を助ける道具にも、観察停止の札にもなる。
修正可能性は、制度価値として有効だが、完成した制度設計図ではない。
文明保存型国連は、理念的一致ではなく、文明条件の揺らぎに対する制度的賭けである。
ドルは、単なる通貨制度ではなく、外周を守る交換条件の上にあった。
基地は、受入れ国を守る保険にも、報復圏へ固定する巻き込まれ装置にもなる。
```

## 個別記事ごとの戻し

### `n92914e74d15f`

政治語彙の記事は、完成した三機能モデルの基礎としてではなく、ラベルが構造観察を止めることへの拒否へ戻した。

保存・再設計・回転条件という整理自体は原文由来の補助線だが、その整理へ居付くと再び観察停止の札になる。

### `n78132143c93f`

未来像の記事は、制度設計図としてではなく、社会が自分を壊しすぎずに更新できる未来へ戻した。

修正可能性は重要だが、完成した制度モデルへ固定しない。

### `n93854c948132`

文明保存型国連の記事は、導入可能性だけではなく、地理的圧力の再編によって文明条件そのものが揺らいでいるため、国連を「査定・後始末」から「壊しすぎない最低線」へ移す制度的な賭けへ戻した。

また、西洋が普遍を持つ側として他文明を査定するという名指しの非対称を、一般的な査定者・被査定者の構造へ薄めすぎないように戻した。

### `n017615f6812a`

ドルの記事は、複数回廊モデルではなく、アメリカが外周を守ることとドル・米国債の中心性が、別々に値上げできる部品ではなく、同じ秩序の再生産条件だったという判断へ戻した。

トランプの読み違いは、安全保障とドルの結びつきを見ていないことではなく、安全保障の傘とドルの核を、価格を上げられる二つの部品として扱っていることとして戻した。

### `nec0c450f182e`

基地の記事は、用途変更時の再交渉一般ではなく、ホルムズを守らないまま基地を残し、米国・イスラエルの対イラン作戦に使うことで、基地が保険から受入れ国をイランの報復圏へ固定する巻き込まれ装置へ反転するという中心へ戻した。

基地とドル還流が、別々の契約ではなく同じ交換条件の二つの表面だったことも戻した。

## 土壌へ入る可能性のある補助線

旧ファイルから、次は保留付きで残す。

```text
政治語彙を人物属性ではなく作動観測の道具として読むこと
保存・再設計・回転条件という三機能
修正可能性を、勝敗ではなく未来の核として見ること
文明保存型国連を、理念一致ではなく利用可能性から導入する視点
外周負担が中心秩序を再生産するという視点
基地の用途反転を見ること
用途変更時の停止・退出・再交渉を問うこと
複数回廊化が自動的な自立ではなく、新しい依存を生みうるという視点
```

これらは有効な肥料候補である。

ただし、これらが個別記事の意味を決めてはならない。

保存・再設計・再交渉は、原文の名指しや非対称へ戻るための道具であって、原文の具体的な判断を置き換える正本ではない。
