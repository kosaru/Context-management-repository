## 一次監査の疑い

監査台帳では、旧分析について次を疑っていた。

```text
政治的対立とAI応答を同一の三機能へまとめ、提供者側の責任を運用項目へ変える。
```

この疑いは部分的に採用する。

旧分析は、3本の記事を、

```text
二項対立はなくならない
→ 仮の補助線と動員的固定化を分ける
→ 語る場と決める場を分ける
→ 保存・再設計・回転でAI応答を設計する
→ 政治機能論・AI Repairモデルへ接続する
→ 訓練・メモリ・UI・評価・利用者運用へ展開する
```

という完成度の高い三機能モデルへ整えすぎていた。

ただし、旧分析に含まれるすべての補助線を捨てるわけではない。

二項対立を仮の補助線として見ること、語る場と決める場を分けること、AI応答を保存・再設計・回転という三機能で見ることは、土壌へ入る可能性のある補助線である。

問題は、それらを一つの完成モデルにし、政治的動員、場の制度分離、AI応答の設計責任を同じ運用語へ均したことである。

## 修復の中心

修復の中心は、B群2を「二項対立・場の分離・AI三機能の統合モデル」ではなく、次のように読み替えることだった。

```text
切断・場・AI応答が、
それぞれ別の場所で固定化を生む危険を問う記事群。
```

保持した横断仮説は、次である。

```text
切ることは必要だが、切断はすぐ所属線になる。
```

ただし、この共通語で3本を同じ話にしない。

```text
政治的二項対立は、社会的な動員技術の問題である。
語る場と決める場は、観測と決定の条件が違うという制度的な場の問題である。
AIの三機能は、利用者の会話術ではなく、問いを運ぶ作動条件の設計問題である。
```

## 個別記事ごとの戻し

### `nd77d3ea83d56`

二項対立の記事は、三機能モデルの前段ではなく、二項対立が危険な思想だからではなく、危険な動員技術として機能しやすいという警告へ戻した。

二項対立はなくならない。

止めるべきなのは、仮の補助線が人を配属する線へ変わり、動員技術として固定化されることである。

### `n360b7b29f068`

語る場と決める場の記事は、責任配置や決定ログへ向かう制度設計図ではなく、観測の精度を守る場と、暫定的に線を引いて責任を引き受ける場を混ぜないという提案へ戻した。

役割は分けるが、回路はつなぐ。

決めた後も、語る場へ戻せる未完成な往復を保持する。

### `necfb29c22f74`

AI三機能の記事は、AI Repairモデルの接続点ではなく、利用者の会話術でもなく、AIをどう設計し、訓練し、評価するかを見るための仮説へ戻した。

保存機能は会話の重心を壊さないこと。

再設計機能は、いまの論理を内側から押し広げること。

回転機能は、保存と再設計が往復可能であり続ける条件を保つこと。

回転は中道でも両論併記でもない。

固定化した瞬間に死ぬ。

## 外したもの

旧分析から、次の扱いを外した。

```text
3本を、二項対立からAI三機能へ進む単線的な発展史として読むこと
二項対立の記事を、語る場・AI三機能の前段として固定すること
語る場と決める場の記事を、責任配置・決定ログ・停止権の制度設計図へ進めすぎること
AI三機能の記事を、AI Repairモデルの接続点として固定すること
AI側の作動条件の設計問題を、利用者の設定・見抜き・運用補正へ移すこと
政治的動員、制度的な場、AI応答設計を、同じ三機能で説明しきること
```

## 土壌へ入る可能性のある補助線

旧分析から、次は保留付きで残す。

```text
二項対立を、なくすものではなく仮の補助線として見ること
仮の補助線が、人を配属する線・動員技術・固定化へ変わる回路
二項対立の否定も新しい二項対立を作るという視点
語る場と決める場を分けること
役割は分けるが回路はつなぐこと
決定後に再び語る場へ戻すこと
AI応答を保存・再設計・回転という三機能で見ること
AIの均衡化を回転の偽物として排除すること
```

これらは有効な肥料候補である。

ただし、これらが個別記事の意味を決めてはならない。

特に、AI三機能は、利用者側の運用責任へ移すための道具ではない。

AIの設計、訓練、評価、UI、メモリ、応答方針を検査するための仮説である。

## 現在の判定

```text
REWRITTEN-PENDING-USER
PASSEDではない
二項対立・場の分離・AI三機能モデルの正本ではない
個別記事の強度を確認するための仮の横断メモである
```

この横断分析は正本ではない。

AI由来の補助線は、肥料候補であっても、ユーザー判断前に土壌へ混ぜ切ってはならない。
