## 一次監査の疑い

監査台帳では、旧分析について次を疑っていた。

```text
相反する二つの「安心」を一つの連続経路へ統合する。
```

この疑いは採用する。

旧分析は、2本の記事を、

```text
主観的安心
→ 制度上の非崩壊保障
→ 行動可能性としての安心の床
→ 停止
→ 退出
→ 回復
→ 再評価
→ 別の選択
→ 再参加
```

という完成度の高い帰還可能性モデルへ整えすぎていた。

ただし、旧分析に含まれるすべての補助線を捨てるわけではない。

安心の意味を分けること、国家基盤の有限性を見ること、やり直せる床を社会の強さとして見ることは、土壌へ入る可能性のある補助線である。

問題は、その補助線を正本化し、2本の記事の緊張を一つの経路へ溶かしたことである。

## 修復の中心

修復の中心は、B群3を「Security・退出・帰還・再参加モデル」ではなく、次のように読み替えることだった。

```text
国家基盤の有限性を隠さない安心と、
個人が一度で終わらないための安心の床を、
接続しつつも別の問いとして残す横断メモ。
```

保持した横断仮説は、次である。

```text
安心とは、不安や失敗が消えることではなく、有限性の中で動けること。
```

ただし、この共通語で2本を同じ話にしない。

```text
国家基盤の安心
→ 万能な安心を約束せず、有限性・優先順位・止め時を共有すること

個人の安心の床
→ 一つの場所で役に立てなかった人を、一度で無能と決めず、立ち止まり、別の場所を試せること
```

## 個別記事ごとの戻し

### `n2f379dd24aa9`

国家基盤の記事は、Securityモデルの上位概念ではなく、国家基盤の有限性を隠さず、万能な安心を約束せず、複雑な現実を民主主義が引き受けるという短い政治命題へ戻した。

国家基盤は、不安を消し去る装置ではない。

想定外が起きたときに、社会が致命的に壊れることを防ぐための設計である。

安心を約束しないとは、国家が何も保障しないという意味ではない。

拒否しているのは、全てを守れる、想定外を消せる、コストも犠牲も生じない、正しい方向なら止める必要がない、かのような約束である。

### `n5968f6dee1ef`

やり直せる余地の記事は、退出・帰還・再参加の制度階層ではなく、自分の経験から、一つの場所で役に立てなかった人を一度で無能と決めず、立ち止まり、別の場所を試せる余地を社会が持つかを問う文章へ戻した。

安心は成功保証ではない。

一度立ち止まれる、別の場所を試せる、失敗しても直ちに全てを失わないための足場である。

ベーシックインカムは、七層保障の一部ではなく、原文が自分の経験と社会への問いをつなぐ具体的な制度として選んだものとして戻した。

AIとの対話は制度保障の代替ではないが、安心して考えを試せる相手が思考を動かすという経験上の接続として戻した。

## 外したもの

旧分析から、次の扱いを外した。

```text
2本を、Securityから帰還可能性へ進む単線的な発展史として読むこと
安心を、主観的安心・非崩壊保障・行動可能性の床へ整理し、それを完成分類として扱うこと
国家基盤の記事を、Securityモデルの前段として固定すること
やり直せる余地の記事を、停止・退出・帰還・再参加モデルへ回収すること
ベーシックインカムを、七層保障の一部へ薄めること
AIとの対話経験を、制度保障の代替可否の話へ寄せすぎること
二つの記事の緊張を、国家が保証すべき最低線一覧へ閉じること
```

## 土壌へ入る可能性のある補助線

旧分析から、次は保留付きで残す。

```text
安心には複数の意味があるという整理
国家基盤を主観的不安の消去ではなく、致命的崩壊を防ぐ設計として見ること
専門知と民主的制御点を分けること
行き過ぎを止められる状態を、民主主義の条件として見ること
能力を固定属性ではなく、環境との相性として見ること
安心を成功保証ではなく、動ける足場として見ること
安心をコストではなく循環の起点として見ること
AIとの対話を、安心して考えを試せる相手という経験として見ること
```

これらは有効な肥料候補である。

ただし、これらが個別記事の意味を決めてはならない。

特に、Security、帰還可能性、停止・退出・再参加という後期語彙は、原文へ戻るための補助線であって、原文の問いを置き換える正本ではない。

## 現在の判定

```text
REWRITTEN-PENDING-USER
PASSEDではない
Security・帰還可能性モデルの正本ではない
個別記事の強度を確認するための仮の横断メモである
```

この横断分析は正本ではない。

AI由来の補助線は、肥料候補であっても、ユーザー判断前に土壌へ混ぜ切ってはならない。
