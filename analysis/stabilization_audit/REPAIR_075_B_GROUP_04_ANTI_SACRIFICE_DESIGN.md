## 一次監査の疑い

監査台帳では、旧分析について次を疑っていた。

```text
元文章の拒否を、負担と犠牲化の区別・判定質問へ置き換えた。
```

この疑いは採用する。

旧分析は、原文の、

```text
引き受ける者を必要とする世界そのものを選ばない。
```

という拒否を、

```text
負担者を見えるようにする
決定へ参加させる
上限を設ける
交代可能にする
停止・退出を可能にする
補償・回復・修復を置く
```

ことで管理できる制度問題へ変えた。

これは原文の補助ではなく、原文の思想内容の変更である。

## 使用停止の中心理由

旧分析は、犠牲を次のように定義した。

```text
負担が見えない
決定参加がない
拒否・停止・退出ができない
上限がない
補償・回復・交代がない
正当化の物語がある
```

この定義によって、反対に、

```text
負担が見える
決定参加がある
拒否・停止・退出ができる
上限がある
補償・回復・交代がある
```

ならば、犠牲を伴う設計を許容できるという読みを作った。

しかし、原文はその条件付き許容を提示していない。

原文が拒否しているのは、犠牲をより適切に管理する条件ではない。

```text
引き受ける者を必要とする安定そのもの
```

である。

## 原文側へ戻したもの

### 1．拒否は制度改善ではない

原文が選んでいるのは、犠牲を減らす制度でも、犠牲を公平に配分する制度でもない。

```text
犠牲を前提に世界を設計しない、という態度を選ぶこと。
```

ここで拒否されているのは、誰かが例外を引き受けることによって世界の安定を成立させる設計そのものである。

### 2．宗教と科学の接続を弱めない

原文は、宗教と科学を歴史学的に同一視しているのではない。

宗教と科学を、人間が不確実さへ耐え、世界を理解可能なものへ変えようとする二つの方法として置いている。

方法は違う。

しかし、どちらも次の地点で同じ問いへ到達する。

```text
誰が引き受けるのか。
```

旧分析は、これを「意味づけや最適化が負担者を隠す場合がある」という弱い監査質問へ縮めた。

これは原文の文明構造上の抽象化を弱めた。

### 3．合理性は悪意なしに切り捨てを成立させうる

原文は、合理性を単純に否定していない。

しかし、犠牲を確率・効率・最適化へ変換したとき、切り捨ては悪意なしに進む。

```text
そこに悪意はない。合理性があるだけだ。
```

この一文は、合理性を擁護しているのではない。

悪人がいなくても、人を切り捨てる構造が成立することを示している。

### 4．後期モデルが原文を修正してはならない

旧分析は、本文の区別が粗く、後期の責任配置・継続・Securityモデルによって具体化されると置いた。

これは、後期体系を上位へ置き、この記事を未成熟な前史へ下げた。

現在は逆に扱う。

```text
後期モデルのほうが、この原文の拒否を保持できているか監査される。
```

### 5．未解決の緊張を実務課題へ閉じない

原文は、次の緊張を残している。

```text
世界を安定させたい
／
引き受ける者を必要とする安定は選びたくない

判断を外注したくない
／
人間の判断は迷い、失敗する

救済と制御を完成させたくない
／
不安定な世界に耐えなければならない
```

旧分析は、これを、

```text
負担上限
交代
補償
退出
監査
停止条件
再発防止
```

という実務項目へ変えた。

後者には制度論としての価値がありうる。

しかし、前者を解いたことにはならない。

## 残す補助線

旧分析から、次はかなり強い保留付きで残してよい。

```text
負担と犠牲化を分けて考えること
負担者が見えるかどうかを見ること
決定参加、上限、交代、停止、退出、補償、修復を制度論として検討すること
合理性が悪意なしに切り捨てを成立させうることを見ること
後続モデルが初期記事の拒否を弱めていないかを測ること
```

これらは、土壌に入る可能性のある肥料候補である。

ただし、これらが原文の意味を決めてはならない。

特に、

```text
上限・交代・補償・退出があれば許容できる
```

という読みを作ってはならない。

## 使用停止として外すもの

旧分析から、次の扱いは外す。

```text
拒否を条件付き許容へ変えること
犠牲を、管理可能な制度問題へ置き換えること
負担と犠牲化の判定質問を、原文の中心命題として扱うこと
後期モデルを原文の修正者として置くこと
宗教と科学の接続を、負担者を隠す場合があるという弱い注意へ縮めること
誰も負担してはならない、危険な職務を否定する、専門家へ頼ってはならない、といった原文にない反対読みを追加すること
未解決の緊張を、上限・交代・補償・退出・監査・停止条件へ閉じること
```

## 現在の判定

```text
USE-STOP-CONFIRMED
PASSEDではない
正本ではない
B群分析として使用しない
関連する負担・犠牲化モデルも使用停止
```

この文書は、反犠牲設計の正本ではない。

使うなら、停止理由の記録としてのみ使う。

犠牲を設計しないという主題について考える場合は、個別カードと原文へ戻る。
