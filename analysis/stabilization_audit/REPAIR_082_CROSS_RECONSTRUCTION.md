# 修復記録082――横断再構築インデックス

更新日：2026-06-28

## 対象

- 改稿候補：`indexes/CROSS_RECONSTRUCTION.md`
- 監査台帳：`analysis/stabilization_audit/BATCHES_AND_CROSS.md`
- 運用思想：`context/REPOSITORY_SOIL.md`

## 一次監査の疑い

```text
全記事を六系譜へ統合し、抵抗する記事を消す可能性。
```

この疑いは採用する。

旧ファイルは、351記事を時期から切り離して横断構造を取り出そうとしていた。

縦読みと横断読みを分け、後から見えた体系を初期記事へ遡及しないという注意も置いていた。

しかし実際には、最上位目的、思考の基本運動、保存・再設計・回転、生活階層、故障構造、Repair、記事役割、概念変化、未解決の緊張、10系譜候補へ強く再編していた。

この再編は有効な補助線を含む。

ただし、そのまま正本化すると、抵抗する記事、別の発展方向、途中で捨てた可能性、未整理の矛盾、怒り、拒否、個別記事の固有性が、横断モデルの中へ吸収される。

## 修復の中心

横断再構築を、全記事を一つの体系へ統合する正本として扱わない。

次のように仮置きした。

```text
横断再構築は、全記事を一つの体系へ統合する正本ではない。

最上位目的、思考運動、保存・再設計・回転、生活階層、故障構造、Repair、記事役割、概念変化、未解決の緊張は、たしかに複数記事をまたいで反復する。

しかし、それらは全記事の意味を決める上位分類ではない。

横断索引の役割は、
反復する補助線を見つけること、
その補助線に抵抗する記事を見つけること、
現在の体系へ回収すると消える別方向の芽を残すこと、
後期統合稿を正本化しないために原文への帰還路を作ることである。

接続できる。
しかし、統合してよいとは限らない。
```

## 戻したもの

```text
人類継続を全記事の支配原理にしないこと
思考の基本運動を全記事の本質にしないこと
保存・再設計・回転を万能構造にしないこと
家庭・都市・国家・国際秩序の役割配置を完成担当表にしないこと
故障構造名で原文の怒りや拒否を置き換えないこと
修復構造を万能解にしないこと
スケール対応を証明として扱わないこと
記事役割を格付けにしないこと
概念変化に、撤回・使用停止・別方向の芽・AI由来の肥料候補を入れること
未解決の緊張を一覧化して問いの重さを均さないこと
```

## 外したもの

```text
351記事を一つの横断体系へきれいに統合できるという前提
人類継続を全記事の支配原理として扱うこと
思考の基本運動を、全記事に共通する本質として扱うこと
保存・再設計・回転を、政治・AI・文明・家庭・国家・国際秩序の万能構造として扱うこと
家庭・都市・国家・国際秩序の役割配置を、完成した担当表として扱うこと
故障構造名で、原文の怒り・拒否・非対称性を置き換えること
修復・帰還・再開の構造を、どんな損傷にも適用できる万能解として扱うこと
スケール対応を、同じ構造が証明されたものとして扱うこと
記事役割を、後期統合稿を上位に置く格付けとして扱うこと
概念変化を発展史としてだけ書くこと
未解決の緊張を一覧化し、問いの重さを均すこと
既存索引の更新候補を、そのまま新しい正本候補として扱うこと
```

## 土壌へ入る可能性のある補助線

```text
縦読みと横断読みを分けること
最高命題自身も監査対象にすること
具体的違和感を入口にし、既存説明が何を消したかを見ること
主語・条件・時間・作用範囲・負担・責任主体を戻すこと
抽象化を、共通部分ではなく、別具象で検査する上位構造として見ること
帰還可能性を残すこと
保存・再設計・回転を、陣営固定を外す補助線として使うこと
責任を、権限・情報・影響力に応じて非対称に置くこと
故障構造を横断的に記録すること
検証可能な場所、決定ログ、Repair、退出可能性、担保の多層化を修復候補として残すこと
スケールをまたぐ対応関係を、検証方法の違いとセットで使うこと
記事役割を、格付けではなく原文へ戻る案内札として使うこと
概念変化に、撤回・使用停止・保留・AI由来の肥料候補を入れること
未解決の緊張を、問いの重さと原文への接続込みで残すこと
```
