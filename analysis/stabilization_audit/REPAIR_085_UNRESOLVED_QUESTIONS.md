# 修復記録085――未解決の問いインデックス

更新日：2026-06-29

## 対象

- 改稿候補：`indexes/UNRESOLVED_QUESTIONS.md`
- 監査台帳：`analysis/stabilization_audit/BATCHES_AND_CROSS.md`
- 運用思想：`context/REPOSITORY_SOIL.md`

## 一次監査の疑い

```text
未解決性を一覧化することで、問いの重さや衝突を同じ形式へ均す。
```

この疑いは採用する。

旧ファイルは、未解決問題を規範・設計・事実・運用へ分類していた。

この分類には有効な部分がある。

ただし、そのまま正本化すると、すべての問いが同じ粒度の未解決チケットになり、原文の怒り、拒否、恐れ、賭け、違和感、まだ言葉になる前の摩擦が、管理しやすい項目へ均される。

## 修復の中心

未解決索引を、問いを解決待ちチケットへ変える場所として扱わない。

次のように仮置きした。

```text
未解決の問いは、解決待ちチケットではない。

規範、設計、事実、運用へ分けることは有効である。

しかし、すべての問いを同じ形式へ並べると、原文の怒り、拒否、衝突、賭け、未整理の摩擦が消える。

未解決索引の役割は、
何を調べれば進むのか、
何を設計すれば進むのか、
何をまだ閉じてはいけないのか、
何が原文の拒否として残っているのか、
何がユーザー判断待ちの肥料候補なのかを分けることである。

接続できる。
しかし、管理項目へ均してよいとは限らない。
```

## 戻したもの

```text
未解決の問いを、追加調査で進む問い、制度設計へ進む問い、原文の怒りや拒否として残す問い、いま答えると現在体系へ回収してしまう問い、ユーザー判断待ちの問いへ分けること
規範・設計・事実・運用だけでなく、拒否、怒り、保留、撤回／使用停止、事実未確認を明示すること
人類継続、文明保存、減速の問いを、現在の最高命題が暴走しないための制動装置として扱うこと
保存・再設計・回転の問いを、調整技術ではなく権力と負担の所在へ戻すこと
責任配置、翻訳層、決定ログを、手順化できる問いと、手順化で隠れる権力の両方として見ること
Security / Comfort と内部条件を、担当表ではなく、家庭・現場中核層・弱い側の負担と結びつけて見ること
倫理・共同体・リベラルの問いを、批判、エール、再読、自己整理へ分けること
検証可能性の問いを、疑似専門性へ近づけないこと
AIとの稽古・Repairを、利用者責任へ閉じないこと
国際秩序・ドル外周・湾岸を、構造仮説と事実確認に分けること
リポジトリ運用を、自動化で解決できる管理課題として扱わないこと
```

## 外したもの

```text
未解決問題を、規範・設計・事実・運用の四分類だけで扱うこと
すべての問いを、同じ粒度の未解決チケットとして扱うこと
原文の怒りや拒否を、設計課題・運用課題へ変換すること
人類継続、文明保存、減速の問いを、優先順位表や制度課題へ閉じること
保存・再設計・回転の問いを、調整技術へ閉じること
責任配置、翻訳層、決定ログを、監査手順としてだけ扱うこと
Security / Comfort と内部条件の問いを、担当表や制度設計へ閉じること
倫理・共同体・リベラルの問いを、一般批判や一般設計課題へ均すこと
検証可能性の問いを、チェックリストによる疑似専門性へ近づけること
AIとの稽古・Repairを、利用者責任へ閉じること
国際秩序・ドル外周・湾岸を、構造仮説と事実確認を分けずに扱うこと
リポジトリ運用を、自動化によって解決できる管理課題として扱うこと
```

## 土壌へ入る可能性のある補助線

```text
未解決問題を規範・設計・事実・運用へ分けること
現在の立場と残る緊張の境界を明示すること
人類継続、文明保存、減速、保存・再設計・回転の危険を未解決として残すこと
文明保存の分類権力、個人の離脱権、体制保存の危険を残すこと
減速の定量条件、報酬構造、階級性を未確定にすること
責任配置、翻訳層、決定ログ、Security / Comfort の具体制度を未設計として残すこと
倫理生成、小さな共同体、家庭、救済、リベラル批判の危険を残すこと
検証可能性、疑似専門性、感情と条件、社会的事実の因果連鎖を未解決として残すこと
AIの安定化、すり寄り、Repair、文脈保存、ベンダー責任を未解決として残すこと
国際秩序、ドル外周、湾岸、基地について一次資料確認が必要だと明記すること
新記事を既存系譜へ自動回収しないこと
解析済みカードを自動上書きしないこと
```
