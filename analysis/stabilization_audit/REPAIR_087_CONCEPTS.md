# 修復記録087――概念索引

更新日：2026-06-29

## 対象

- 改稿候補：`indexes/CONCEPTS.md`
- 監査台帳：`analysis/stabilization_audit/BATCHES_AND_CROSS.md`
- 運用思想：`context/REPOSITORY_SOIL.md`

## 一次監査の疑い

```text
強い言葉を概念ラベルへ置き換える可能性。
```

この疑いは採用する。

旧ファイルは、概念変化を、定義変更、機能分解、担い手の配置、作用範囲の拡張、後から付いた名称、複数概念の統合、別具象への適用による修正へ分けていた。

また、各概念に、形成、現在の定義、主な担い手・作用範囲、劣化形、戻し方を置いていた。

この整理には有効な補助線がある。

ただし、そのまま正本化すると、原文の強い言葉、怒り、拒否、比喩、怖さ、身体感覚が、扱いやすい概念ラベルへ置き換えられる。

## 修復の中心

概念索引を、言葉を定義へ閉じる場所として扱わない。

次のように仮置きした。

```text
概念索引は、原文の強い言葉を概念ラベルへ置き換える正本ではない。

概念は、原文へ戻るための索引である。

人類継続、文明保存、減速、保存・再設計・回転、責任配置、Security / Comfort、内部条件、最終処理場化、検証可能な場所、社会的事実、情報非対称性、AI安定化、Repair などは、たしかに複数記事をまたいで反復する。

しかし、それらは原文の怒り、拒否、比喩、怖さ、身体感覚の代替ではない。

概念索引の役割は、
どの言葉が原文にあったのか、
どの言葉が後から付いたのか、
どの言葉がAI由来の補助線かもしれないのか、
どの概念が肥料候補なのか、
どの概念化が原文を弱めるのかを分けることである。

接続できる。
しかし、概念ラベルへ置き換えてよいとは限らない。
```

## 戻したもの

```text
概念ラベルを、原文の強い言葉の代わりにしないこと
人類継続・文明保存・減速を、上位概念で閉じないこと
保存・再設計・回転を、便利な三分法にしないこと
責任配置・決定ログを、手順の概念へ閉じないこと
Security / Comfort・内部条件を、担当概念へ閉じないこと
倫理生成・小さな共同体・リベラルを、思想分類にしないこと
検証可能性・社会的事実・情報非対称性を、万能読解法にしないこと
AI概念を、利用者稽古の道具へ閉じないこと
概念変化に、撤回・使用停止・保留・AI由来の補助線・ユーザー判断待ちを入れること
```

## 外したもの

```text
強い言葉を概念ラベルで置き換えること

後から付いた名称を、名称以前の記事の本質として扱うこと
人類継続・文明保存・減速を、過去記事の支配原理として扱うこと
保存・再設計・回転を、便利な三分法として全領域へ適用すること
責任配置・決定ログを、手順概念へ閉じること
Security / Comfort・内部条件を、完成した担当概念へ閉じること
倫理生成・共同体・リベラルを、思想分類へ閉じること
検証可能性・社会的事実・情報非対称性を、万能読解法へ変えること
AI概念を、利用者稽古の道具へ閉じること
概念変化を、発展・拡張・統合だけで扱うこと
```

## 土壌へ入る可能性のある補助線

```text
概念変化を、定義変更、機能分解、担い手の配置、作用範囲の拡張、後から付いた名称、複数概念の統合、別具象への適用による修正へ分けること
形成、現在の定義、担い手、作用範囲、劣化形、戻し方を概念ごとに置くこと
人類継続、文明保存、減速、保存・再設計・回転、暫定固定、責任配置、Security / Comfort、内部条件、最終処理場化、退出可能性、担保の多層化、倫理生成、検証可能な場所、社会的事実、情報非対称性、AI安定化、Repair、文脈の置き場所などを横断概念として見えるようにすること
各概念に劣化形を置き、概念の暴走を警戒すること
戻し方を置き、概念から原文・現実・検証可能な場所へ戻る入口を作ること
```
