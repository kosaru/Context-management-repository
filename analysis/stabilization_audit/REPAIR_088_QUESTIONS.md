# 修復記録088――問い索引

更新日：2026-06-29

## 対象

- 改稿候補：`indexes/QUESTIONS.md`
- 監査台帳：`analysis/stabilization_audit/BATCHES_AND_CROSS.md`
- 運用思想：`context/REPOSITORY_SOIL.md`

## 一次監査の疑い

```text
問いを検索可能にする一方、問い同士の非対称性を平板化する可能性。
```

この疑いは採用する。

旧ファイルは、記事タイトル由来の個別質問ではなく、全351記事を動かしている横断的な問いを70個並べていた。

この整理には有効な補助線がある。

ただし、そのまま正本化すると、最高命題に近い問い、実務的な問い、拒否から出た問い、怒りから出た問いが、同じ見出し階層に並び、問い同士の重さの違いが消える。

## 修復の中心

問い索引を、問いを解決待ちリストへ変える場所として扱わない。

次のように仮置きした。

```text
問い索引は、問いを同じ粒度へ並べる正本ではない。

問いは、原文へ戻るための入口である。

人類継続、文明保存、減速、保存・再設計・回転、責任配置、内部条件、倫理、抽象化、検証可能性、情報非対称性、AI Repair、国際秩序、文脈管理は、たしかに複数記事をまたいで反復する。

しかし、それらの問いは同じ重さではない。

問い索引の役割は、
どの問いが調査で進むのか、
どの問いが制度設計へ進むのか、
どの問いが原文の拒否や怒りとしてまだ閉じられないのか、
どの問いが現在の体系へ回収すると弱くなるのか、
どの問いがユーザー判断待ちなのかを分けることである。

接続できる。
しかし、同じ検索項目へ平板化してよいとは限らない。
```

## 戻したもの

```text
問いを、調査で進む問い、制度設計で進む問い、原文の拒否や怒りから出てまだ閉じてはいけない問い、現在の体系へ回収すると弱くなる問い、ユーザー判断待ちの問いへ分けること
問いを同じ見出し階層へ均さないこと
人類継続・文明保存・減速の問いを、解決待ちではなく制動装置としても扱うこと
保存・再設計・回転の問いを、調整課題ではなく権力と負担の問いへ戻すこと
責任配置・翻訳層・決定ログの問いを、手順化できる問いと、手順化すると消える怒りの両方として扱うこと
生活・内部条件・退出可能性の問いを、誰の負担から出た問いかと結びつけること
倫理・共同体・リベラルの問いを、批判・エール・再読・自己整理へ分けること
単線・複線・抽象化の問いを、思考法の美化へ回収しないこと
科学・報道・検証の問いを、確認順の万能化にしないこと
情報非対称性・メディア・AGIの問いを、同型性で閉じないこと
AI Repairの問いを、利用者訓練へ閉じないこと
国際秩序・ドル外周の問いを、構造仮説と事実確認に分けること
執筆・研究・文脈管理の問いを、自動上書きへ進めないこと
```

単線・複線・抽象化の問いを、思考法の優秀さへ回収すること
科学・報道・検証の問いを、確認順の万能化へ進めること

AI Repairの問いを、利用者訓練へ閉じること

## 土壌へ入る可能性のある補助線

```text
結論ではなく問いの移動を重視すること
記事タイトル由来の個別質問ではなく、横断的な問いを抽出すること
現在維持している立場、問いが育った系譜、まだ閉じない問題への参照を分けること
人類継続、文明保存、減速、保存・再設計・回転、責任配置、内部条件、倫理、単線・複線、科学報道、情報非対称性、AI Repair、国際秩序、文脈管理の入口を作ること
各問いを短く保ち、次の調査や原稿化へ使いやすくすること
```

## 現在の判定

```text
REWRITTEN-PENDING-USER
PASSEDではない
問いを同じ粒度へ平板化する正本ではない
原文へ戻る問いの入口を作りつつ、問いの重さ・拒否・怒り・解決待ちにしてはいけないものを分けるための仮索引である
```
