# 修復記録089――記事役割索引

更新日：2026-06-29

## 対象

- 改稿候補：`articles/CROSS_ROLES.md`
- 監査台帳：`analysis/stabilization_audit/BATCHES_AND_CROSS.md`
- 運用思想：`context/REPOSITORY_SOIL.md`

## 一次監査の疑い

```text
個別記事へ統合稿・修正稿などの役割を与え、後期体系へ配置する。
```

この疑いは採用する。

旧ファイルは、初回に個別解析した25記事を、全351記事の横断再構築から見直し、記事の役割、接続する六系譜、主な前史、統合・再構成した範囲、初出ではないもの、現在残る差分・緊張を置いていた。

この整理には有効な補助線がある。

ただし、そのまま正本化すると、25記事は後期体系の中で役割を与えられた部品になる。

「統合稿」「適用稿」「方法論化」「一般読者向け再構成」というラベルは便利だが、同時に危険である。

初出、衝突記録、怒り、拒否、使用停止、AIが壊した箇所、まだ肥料か混入物か判断していない補助線が、後期記事の前史や材料へ下げられるからである。

## 修復の中心

役割索引を、記事を後期体系の部品へ配置する表として扱わない。

次のように仮置きした。

```text
記事役割は、個別記事を後期体系へ配置するための正本ではない。

初出、衝突記録、修正、自己整理、統合稿、一般読者向け再構成、適用稿、方法論化、運用設計という区別は有効である。

しかし、それらは記事の価値や上下を決めるものではない。

役割索引の役割は、
どの記事が読みやすく再構成されたのか、
どの記事が衝突や怒りを残しているのか、
どの記事が上位概念を別具象へ当てているのか、
どの記事が後から方法論名を与えられたのか、
どの記事で何が削られた可能性があるのかを分けることである。

接続できる。
しかし、後期体系へ配置してよいとは限らない。
```

## 戻したもの

```text
統合稿を上位にしないこと
適用稿を、上位概念の勝利にしないこと
方法論化を、思考法の自己神話にしないこと
初出ではないものを、前史の従属化にしないこと
現在残る差分を、後期記事を正本化しないための制動装置として扱うこと
25記事を、読みやすい統合稿が初出や衝突記録を下位化する危険、適用稿が上位概念の耐久性を証明したように見える危険、方法論化記事が過去の迷走や怒りを自己の一貫性へ回収する危険から読むこと
役割ラベルを、原文へ戻るための注意札として使うこと
```

## 外したもの

```text
25記事を後期体系の役割表として扱うこと
統合稿を初出や衝突記録より上位に置くこと
適用稿を上位概念の成功例として扱うこと
方法論化記事を、過去の思考が最初から一貫していた証拠として扱うこと
初出ではないものを、後期記事の前史として従属させること
現在残る差分を、記事役割の補足として扱うこと
六系譜への接続を、記事の本質として扱うこと
記事カードへ役割要約を自動追記すること
CURRENT_POSITIONSやTHEMESなどを、この記事役割に合わせて自動更新すること
```

## 土壌へ入る可能性のある補助線

```text
初回25記事の大半は問いの初出ではなく、1〜4月の思考ログ、衝突記録、自己整理を一般読者が追える論理へ組み直した記事であること
記事ごとに、初出、試行、衝突記録、修正、自己整理、統合稿、一般読者向け再構成、適用稿、方法論化、運用設計を分けること
各記事について、主な前史と、初出ではないものを明記すること
各記事について、現在残る差分・緊張を置くこと
AI稽古、文脈の置き場所、複数文献読解、複雑さを知る、型と技、話が飛んでいるようで飛んでいないを、先行する実践を後から言語化した方法論化記事として見ること
活性酸素、異常気象、予算委員会、山田玲司、ドル外周を、上位概念を別領域へ当て耐久性を試した適用稿として見ること
```
