# 修復記録090――縦読みと横断再構築の照合

更新日：2026-06-29

## 対象

- 改稿候補：`analysis/VERTICAL_HORIZONTAL_CROSSCHECK.md`
- 監査台帳：`analysis/stabilization_audit/BATCHES_AND_CROSS.md`
- 運用思想：`context/REPOSITORY_SOIL.md`

## 一次監査の疑い

```text
縦読みと横断モデルの整合を優先し、不一致を誤差扱いする危険。
```

この疑いは採用する。

旧ファイルは、全351記事を時系列に読んだ第1〜第6解析単位と、その後に作成した横断索引を照合していた。

また、目的は横断して見えた完成形を初期記事へ遡及することではないと明記していた。

しかし実際には、第1〜第5期をほぼ維持、第6期だけ補記が必要と判定し、大規模な縦読み文書の書き換えは不要だったと結論していた。

この結論は、縦読みと横断読みの整合を優先し、不一致や抵抗を誤差・補記・限定修正へ変える危険がある。

## 修復の中心

照合文書を、整合を証明するための作業として扱わない。

次のように仮置きした。

```text
縦読みと横断読みの照合は、整合を確認するための正本ではない。

縦読みは、成立順、迷い、試行、修正、衝突、撤回、使用停止、保留を残す。

横断読みは、異なる領域で反復する構造、分岐、合流を見えるようにする。

しかし、横断読みは縦読みを裁定しない。

照合の役割は、
どこが本当に誤読なのか、
どこが横断で見えた肥料候補なのか、
どこが後期体系の遡及なのか、
どこが縦読み側の抵抗なのか、
どこを一致させてはいけないのかを分けることである。

接続できる。
しかし、整合させてよいとは限らない。
```

## 戻したもの

```text
維持という判定を安易に使わないこと
縦読みを、後期統合の前史ではなく、成立順、迷い、試行、修正、衝突、撤回、使用停止、保留を残す記録として扱うこと
横断読みを、反復構造を示すが、縦読みを裁定しないものとして扱うこと
Security / Comfort の補正は有効だが、役割配置へ閉じないこと
社会的事実の補正は有効だが、企業批判の強度を弱めないこと
キュゥべえ論の補記は有効だが、作品を監査項目へ落とさないこと
修正は限定的だったという結論を外すこと
```

## 外したもの

```text
第1〜第5期を、そのまま維持と判定すること
第6期だけ補記が必要と扱うこと
大規模な縦読み文書の書き換えは不要だったと結論すること
修正が必要だったのは、Security / Comfort、社会的事実、キュゥべえの三点に限られると扱うこと
縦読みを、思考が育った順番としてだけ扱うこと
横断読みを、縦読みの上位照合モデルとして扱うこと
横断モデルに合わない記事を、不足・補記・誤差として処理すること
Security / Comfort の補正を、国家・都市・家庭・生活圏の役割配置へ固定すること
社会的事実の補正によって、設計主体の非対称な責任を弱めること
キュゥべえ論を、情報非対称性・質問可能性・同意条件の監査項目へ落とし切ること
```

## 土壌へ入る可能性のある補助線

```text
縦読みは、成立順、迷い、試行、修正を保存するものだと置くこと
横断読みは、異なる領域で反復する構造、分岐、合流を示すものだと置くこと
照合は、誤読だけを修正し、後期体系を初期へ遡及しないものだと置くこと
Security / Comfort の意味反転という誤読を修正すること
社会的事実について、作用の同方向化と、目的・意図・利害の一致を分けること
OpenAIの企業利益・意図への接続を本文側の仮説として明示すること
キュゥべえ論について、情報の選択的開示、質問可能性の支配、近位目的と遠位大義の縫合、実質的同意条件の欠如を追加すること
解析済みカードを自動上書きせず、役割インデックスへ接続する方針を置くこと
```
