# 修復記録092――キュゥべえ論の補正：情報非対称性と個人の資源化への拒否

更新日：2026-06-29

## 対象

- 改稿候補：`analysis/KYUBEY_INFORMATION_ASYMMETRY.md`
- 監査台帳：`analysis/stabilization_audit/BATCHES_AND_CROSS.md`
- 運用思想：`context/REPOSITORY_SOIL.md`

## 一次監査の疑い

```text
個人の資源化への拒否を、情報非対称の監査項目へ変える危険。
```

この疑いは採用する。

旧ファイルは、キュゥべえ論を有限な合理だけでは不十分とし、情報の選択的開示、質問可能性の支配、近位目的と遠位大義の縫合、当事者を抽象的公益へ回収する正当化、同意条件の欠如を加えていた。

この補正は重要である。

ただし、そのまま正本化すると、中心が情報非対称性の監査へ寄りすぎる。

本来そこにある強い拒否は、単に説明不足や不完全な同意の問題ではなく、現在の個人を遠位大義のための資源として扱うことへの拒否である。

## 修復の中心

キュゥべえ論を、情報非対称性モデルとして完成させない。

次のように仮置きした。

```text
キュゥべえ論は、有限な合理だけでは足りない。

情報の選択的開示、質問可能性の支配、近位目的と遠位大義の縫合、実質的同意条件の欠如を見る必要がある。

しかし、キュゥべえ論は、情報非対称性の監査モデルへ回収するための正本ではない。

中心に残すべきなのは、
現在の個人を、遠位大義のための資源として扱うことへの拒否である。

情報非対称性は重要である。
同意条件も重要である。
目的階層の整理も重要である。

しかし、それらを整えれば、個人の資源化が許容されるとは限らない。

接続できる。
しかし、監査項目へ変えてよいとは限らない。
```

## 戻したもの

```text
情報非対称性は補助線であり、中心ではないこと
同意条件の欠如は重要だが、同意があれば済むとは限らないこと
近位目的と遠位大義の縫合は、説明のズレだけではなく、現在の少女の身体・人生・選択・苦痛を遠位大義の材料にすることだと戻すこと
有限な合理と戦略的省略を分けることは有効だが、作品固有性を残すこと
AIとの接続は有効だが、AI企業批判を比喩で証明しないこと
個人の資源化を、監査項目ではなく拒否として残すこと
確認済み部分と推測部分を分けるが、規範的拒否の強度を消さないこと
```

## 外したもの

```text
キュゥべえ論を、情報非対称性の補正モデルとして完成させること
個人の資源化への拒否を、同意条件や情報開示の監査項目へ下げること
同意条件が整えば問題が解けるように見せること
近位目的と遠位大義の縫合を、目的説明のズレだけとして扱うこと
作品固有の怖さ、感情、視聴経験、物語機能を、情報非対称性モデルへ落とすこと
AI企業批判を、キュゥべえ比喩で証明すること
推測部分を明示することで、規範的拒否の強度まで弱めること
```

## 土壌へ入る可能性のある補助線

```text
有限な合理と戦略的な省略を分けること
聞かれた範囲では露骨な嘘を避けることと、重要情報を自発的に開示しないことを分けること
知らない者は、知らない情報について適切に質問できないと置くこと
「聞かれなかったから答えなかった」を、開示責任の転嫁として見ること
近位目的、中期目的、遠位戦略、最終的大義を分けること
近位目的を開示せず、遠位の大義だけを答えるなら、相手の問いに正面から答えていないと置くこと
契約の問題を、嘘の有無ではなく、意味のある同意を行える情報条件の有無として見ること
AIとの接続で、出力上の省略・変形、公開目的と仕様、設計上の報酬・安全・事業上の利害、意図に関する推論を分けること
公開記事本文で確認できる部分と、過去の対話で置かれた本文より強い仮説を分けること
```
