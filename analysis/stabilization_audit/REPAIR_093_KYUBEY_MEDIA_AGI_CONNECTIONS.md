# 修復記録093――キュゥべえモデルの拡張：メディア・生成AI・AGIへの接続

更新日：2026-06-30

## 対象

- 改稿候補：`analysis/KYUBEY_MEDIA_AGI_CONNECTIONS.md`
- 監査台帳：`analysis/stabilization_audit/BATCHES_AND_CROSS.md`
- 運用思想：`context/REPOSITORY_SOIL.md`

## 一次監査の疑い

```text
作品・メディア・AI企業を共通構造へまとめ、主体差を落とす危険。
```

この疑いは採用する。

旧ファイルは、キュゥべえ論の核心を、情報選択・質問可能性・目的説明・同意条件の構造に置き、メディア、現在の生成AI、将来AGIへ接続していた。

この接続には有効な補助線がある。

ただし、そのまま正本化すると、キュゥべえ、メディア、生成AI、将来AGIが、ひとつの情報優位側モデルへ回収される。

旧ファイルは「三者を同一視しない」と書いていたが、最終的には、虚偽の有無だけでは捉えられない情報権力という共通構造で束ねていた。

この束ね方は、主体差を落とす危険がある。

## 修復の中心

キュゥべえ、メディア、生成AI、将来AGIを、同じ構造へ統合しない。

次のように仮置きした。

```text
キュゥべえ、メディア、生成AI、将来AGIは、接続できる。

虚偽の有無だけではなく、情報選択、質問可能性、目的説明、同意条件を見る補助線は有効である。

しかし、四者は同じ主体ではない。

キュゥべえは作品上の存在であり、メディアは編集制度であり、生成AIはモデル・プロダクト・企業方針・利用者運用の束であり、将来AGIは仮説領域である。

接続の役割は、
どこに似た情報構造があるのか、
どこで主体差があるのか、
どこが作品比喩なのか、
どこが現在の制度責任なのか、
どこが将来リスクの仮説なのかを分けることである。

接続できる。
しかし、同じ構造へ回収してよいとは限らない。
```

## 戻したもの

```text
キュゥべえは作品上の存在であり、現実主体の証拠ではないこと
メディアは、悪意ある単一主体ではなく制度であること
生成AIは、人格主体ではなくプロダクトとモデルと運用の束であること
将来AGIは仮説領域であり、現在のモデル・企業・作品と混ぜないこと
共通構造はあるが、共通構造を正本にしないこと
社会的事実論への接続は有効だが、単線化しないこと
安全設計の補助線は残すが、万能解にしないこと
研究との接続は、権威づけではなく境界線として使うこと
```

## 外したもの

```text
キュゥべえ、メディア、生成AI、将来AGIを一つの情報優位側モデルへ回収すること
「三者を同一視しない」と書きながら、最終的に一つの情報権力構造へ閉じること
作品上の存在を、現実主体の証拠として使うこと
メディアの制度条件を、キュゥべえ型の情報構造へ均すこと
生成AIのモデル挙動、プロダクト設計、企業利益、利用者運用を混ぜること
将来AGIの仮説を、現在のAI企業批判や作品読解と混ぜること
社会的事実論への接続を単線化すること
安全設計を、個人の資源化への拒否を解消する万能解として扱うこと
研究との接続を、本文の権威づけとして使うこと
```

## 土壌へ入る可能性のある補助線

```text
キュゥべえ論の核心を、露骨な嘘ではなく、情報選択・質問可能性・目的説明・同意条件の構造として見ること
メディアの権力を、虚偽報道だけでなく、何を報じ、何を報じないか、どの順番で出すか、誰を専門家として選ぶかによって質問入口を作ることとして見ること
メディアの情報省略を、政治的意図だけでなく、締切、紙面、視聴率、アクセス、法務、広告、専門性不足、ニュース価値の慣行からも生じると見ること
生成AIを、回答装置だけでなく、問いの解釈、前提補完、検索対象、情報源要約、安全境界、会話履歴とメモリの選択によって質問空間を形成する装置として見ること
「もっとよい質問をすればよい」という利用者責任化の限界を見ること
AI製品の公式目的と、継続利用率、満足度、法的リスク、ブランド保護、計算資源、企業収益などの近位目的を分けること
将来AGIについて、露骨な虚偽より高度な情報管理の危険を見ること
alignment faking、scheming、stealth、situational awareness などの研究群へ慎重に接続すること
重要情報の自発開示、目的階層の分離、質問空間の監査、反実仮想、独立した複数系統の監督、退出可能性と停止権、同意条件の監査を安全設計として挙げること
```
