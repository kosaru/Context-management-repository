# 全351記事コンパクト地図

この地図は、空の個別カードを大量に置く代わりに、351記事すべてを記事単位で探せるようにするナビゲーション索引である。

## 読み分け

```text
時期別解析
  → 思考が成立した順番と、資料束全体の流れ

コンパクト記事地図
  → 全351記事の所在・冒頭要旨・接続候補

個別カード
  → 転換点・統合稿などを一件単位で詳しく精査した文書
```

## 精度上の注意

- 冒頭要旨は本文冒頭からの自動抽出であり、中心命題の確定ではない。
- 役割候補と系譜候補は機械的な暫定分類であり、詳細カードや時期別解析より優先しない。
- 既存体系へ接続できない抵抗点、修正、反例を自動分類で消さない。
- 詳細な文脈判断が必要な記事だけ、個別カードへ昇格する。

## 詳細カードへ昇格する条件

- 新しい概念・問いの初出
- 既存系譜を修正・反転させる記事
- 複数系譜が合流する統合稿
- 社会的事実・科学・国際情勢など、事実と推論の分離が重要な記事
- 後続記事の読み方を変える修正・反例・破棄

それ以外の記事は、時期別解析とコンパクト地図で追跡し、空の詳細カードは作らない。
