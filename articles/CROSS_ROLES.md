## 戻すべき芯

役割索引は、記事を後期体系の部品へ配置する表ではない。

役割索引は、次の五つを分けるための仮索引である。

```text
1. その記事で本当に初めて出たもの
2. その記事が後から読みやすく組み直したもの
3. 統合によって読みやすくなったもの
4. 統合によって弱くなったもの
5. 原文・カード・修復記録へ戻らないと判断できないもの
```

記事役割とは、格付けではない。

「統合稿」は上位ではない。

「初出」「衝突記録」「使用停止」は未成熟ではない。

むしろ、後期統合稿が削った怒り、拒否、飛躍、危険な接続、AIによる破壊は、初出や衝突記録の側に残る場合がある。

このファイルで守るべきなのは、役割分類の整合性ではなく、**役割ラベルによって個別記事の強度を後期体系へ従属させないこと**である。

## 1．「統合稿」を上位にしない

旧ファイルでは、多くの記事に「統合稿」が付いていた。

これは一定程度正しい。

後期記事の多くは、過去の短い思考ログや衝突記録を、一般読者が読める形へ組み直している。

しかし、統合稿というラベルは上位化しやすい。

統合稿は読みやすい。

統合稿は論理が通っている。

統合稿は公開原稿として使いやすい。

そのため、初出や衝突記録が、未完成な前史に見えやすい。

役割索引では、統合稿を次のように扱う。

```text
統合稿
  = 読者へ渡しやすくした再構成
  ≠ 原文より上位
  ≠ 初出の代替
  ≠ 衝突記録の強度を保存している保証
```

## 2．「適用稿」を、上位概念の勝利にしない

活性酸素、異常気象、予算委員会、山田玲司、ドル外周のような記事は、上位概念を別領域へ当てた適用稿として読める。

しかし、適用稿というラベルも危険である。

上位概念が別領域でうまく使えたように見えると、具象の抵抗が弱くなる。

活性酸素には医学的確認の境界がある。

異常気象には気候科学と個別気象の検証差がある。

予算委員会には実際の政治過程、報道、AI出力、企業設計責任の切り分けがある。

山田玲司の記事は、一般リベラル批判ではなくエールでもある。

ドル外周は、現在の一次資料で再検証が必要な構造仮説である。

適用稿は、上位概念の勝利ではない。

適用稿は、上位概念が別具象で壊れるかどうかを試した記録である。

## 3．「方法論化」を、思考法の自己神話にしない

AI稽古、文脈の置き場所、複数文献読解、複雑さを知る、型と技、話が飛んでいるようで飛んでいない、という記事は方法論化として読める。

しかし、方法論化は自己神話化しやすい。

後から方法名を付けると、過去の迷走、偶然、読み違い、AIによる破壊、ユーザーの怒りが、最初から一貫した方法の実演だったように見える。

思考法は強い。

しかし、思考法は壊れる。

抽象化は具象差を削る。

複線は決定回避になる。

読解忠実性は生産的な押し広げまで止める。

Repairは会話規範の押しつけになる。

方法論化記事は、方法の証明ではなく、方法の危険を検査する入口として扱う。

## 4．「初出ではないもの」を、前史の従属化にしない

旧ファイルは、各記事に「初出ではないもの」を置いていた。

これは重要である。

後期記事を初出と誤認しないために必要だからである。

ただし、「初出ではない」と書くと、初出側が後期記事の前史に見えやすい。

前史は材料ではない。

前史には、後期記事に入らなかった怒り、拒否、未整理の強度、危険な接続、撤回すべき線が残る。

役割索引では、前史を次のように扱う。

```text
前史
  = 後期記事の材料
  ではなく
  = 後期記事を検査する原文側の足場
```

## 5．「現在残る差分」を付録にしない

旧ファイルでは、記事ごとに「現在残る差分」を置いていた。

これは有効である。

しかし、各記事の末尾に置かれると、本文役割の補足に見えやすい。

実際には、差分こそ重要である。

人類継続には、個人の離脱権と現在世代の資源化の危険が残る。

減速には、階級性と報酬設計が残る。

AI稽古には、ベンダー責任の代替になる危険が残る。

社会的事実論には、AI企業の利益・設計思想への推論と出力現象の分離が残る。

ドル外周には、現在資料による再検証が残る。

山田玲司の記事には、エールを一般リベラル批判へ回収しないという差分が残る。

役割索引では、差分を付録ではなく、後期記事を正本化しないための制動装置として扱う。

## 6．25記事を、三つの危険に分けて読む

旧ファイルの25記事は、役割として読むより、次の三つの危険から読むほうがよい。

```text
A．読みやすい統合稿が、初出や衝突記録を下位化する危険
B．適用稿が、上位概念の耐久性を証明したように見える危険
C．方法論化記事が、過去の迷走や怒りを自己の一貫性へ回収する危険
```

この三つを見れば、記事役割の整理を捨てずに、安定化を検査できる。

## 7．役割ラベルは、原文へ戻るための注意札にする

今後、記事役割を使う場合は、次のように使う。

```text
初出
  → ここに原文の摩擦が残っている可能性が高い。

衝突記録
  → AIや他者との摩擦によって、後期統合稿では薄まる強度が残る。

使用停止
  → 失敗した分析だが、なぜ失敗したかが土壌として重要である。

統合稿
  → 読みやすいが、何を削ったか確認する必要がある。

一般読者向け再構成
  → 公開に向くが、危険な飛躍や怒りを薄めている可能性がある。

適用稿
  → 上位概念の実験であり、成功例ではなく耐久試験である。

方法論化
  → 自己神話化と背中合わせである。
```

役割ラベルは、記事の価値を決めるものではない。

役割ラベルは、どこへ戻って検査すべきかを示す注意札である。
