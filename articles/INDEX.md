# 今後の追加方針

新しい記事が追加されたときは、直ちに既存六系譜へ回収しない。

1. note IDで新着・更新を判定する。
2. 本文の正本はnote公開ページとする。
3. 初出、試行、修正、統合、適用の役割を判定する。
4. 既存系譜の継承だけでなく、反例、分岐、破棄の可能性を見る。
5. 現在地と横断索引を更新する。
