# コンパクト地図の精度

コンパクト地図の次の項目は暫定である。

- 本文冒頭から自動抽出した要旨
- タイトル形態から判定した役割候補
- 語彙から抽出した六系譜への接続候補

これらは記事を見つける入口であり、中心命題・役割・系譜を確定するものではない。

詳細な判断では、時期別解析、公開本文、個別カードを優先する。

# 詳細カードへ昇格する条件

- 新しい概念・問いの初出
- 既存系譜を修正・反転させる記事
- 複数系譜の接続点
- 後続記事の読み方を変える修正・反例・破棄
- 事実と推論の厳密な分離が必要な記事
- コンパクト地図では記事固有の差異が消える記事
- 現在の体系へ素直に回収できない記事

新着記事も既存六系譜へ自動的に回収しない。

1. note IDで新着・更新を判定する。
2. 本文の正本はnote公開ページとする。
3. 初出、試行、修正、統合、適用、反例、分岐、破棄を判定する。
4. 既存系譜へ接続できる部分と、接続すると消える抵抗点を分ける。
5. 必要な記事だけ詳細カードへ昇格する。
