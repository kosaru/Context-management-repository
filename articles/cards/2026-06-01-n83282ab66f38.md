# 第8回：人が動ける社会と、人を動かせる社会は違う――労働力の流動性を、安心の土台から考える

## このカードの状態

旧カードは、原文の中心構造をかなり保持していた。

```text
労働力の流動性は、政策の言葉としては前向きだが、生活者には自由より不安として届きやすい
人が動ける社会と、人を動かせる社会は違う
流動性そのものは悪ではなく、本来は一般市民に有利な概念であるべきだった
現実には企業側の人材調達、固定費の変動費化、教育・待機・生活不安の外部化へ先に効きやすい
働く人にとっての流動性には Security と Comfort が必要である
雇用形態が変わっても社会的信用を持ち運べる必要がある
流動性は生活予測性とセットでなければならない
外部SLAだけが強くなり内部SLAがないと、負荷は契約の弱い場所へ移る
正社員だけを見ても足りない
人が動ける社会には戻れる場所が必要である
減速のイノベーションは、人を市場に放り出す流動性ではなく、動ける自由と壊れない安心を両立させる労働市場を目指す
```

これらは原文自身にある。

したがって、一次監査にあった、

```text
「人が動ける」と「人を動かせる」の権力差
↓
流動性の条件整理
↓
非対称性の均し
```

という疑いは、半分だけ採用する。

Security、Comfort、信用のポータビリティ、内部SLAは、旧カードが弱めるために後から入れた条件ではない。

原文自身が、働く人の自由としての流動性を成立させる条件として提示している。

ただし旧カードには修復すべき点がある。

- 「条件整理」として整うことで、原文の強い非対称である「働く人の自由のように見えて、実際には企業の調達可能性だけが高まる」がやや弱くなった
- 「企業が人を動かせる自由」という表現の危険さを、企業合理性と生活者側条件の整理へ均しやすかった
- 雇用形態が変わると、企業だけでなく社会・金融機関・住居市場・家族形成に対しても弱くなるという範囲が後景化した
- 正社員が抱えきれない負荷が非正規、派遣、下請け、委託、個人事業主へ流れるという負荷移転の連鎖を、内部条件の問題として穏当に置きすぎた
- 外国人労働者をめぐる問いでは、外国人が増えること自体ではなく、なぜ安い労働力が必要とされるのかを問うている点を前に出す必要がある
- 「労働力の流動性は、企業の育成責任を消すための言葉であってはならない」という強い文を中心へ戻す必要がある
- 本記事を減速のイノベーションの労働市場モデルへ固定しすぎると、原文末の「人が動ける社会と、人を動かせる社会は違う」という直接の警告が薄まる

この改稿は、労働力の流動性そのものを否定しない。

一方で、**同じ流動性という言葉でも、主語が働く人なのか企業なのかで中身は変わり、安心の土台がないまま流動性だけを高めれば、それは自由ではなく不安定化になる**という原文の非対称を中心へ戻す。

ユーザー確認前のため、強度監査通過とは扱わない。

## 労働力の流動性は、自由より不安として届いている

労働力の流動性という言葉は、政策や経済の言葉としては前向きに語られやすい。

人が一つの会社に縛られず、必要に応じて働く場所を変えられる。

技能を持った人が、より合う場所へ移れる。

企業も必要な人材を外から採れる。

社会全体として、人材が硬直せずに動く。

そう説明される。

しかし、一般市民の実感はそれほど明るくない。

```text
正社員でいられなくなるのではないか
会社に切られやすくなるのではないか
非正規や派遣に流されるのではないか
収入が不安定になるのではないか
住宅ローンや賃貸契約で不利になるのではないか
社会的信用まで落ちるのではないか
会社が人を使い捨てしやすくなるだけではないか
```

労働力の流動性は、政策の言葉としては「人が動ける自由」に見える。

しかし、生活者の実感としては「企業が人を動かせる自由」に見えやすい。

ここを分けなければならない。

> **人が動ける社会と、人を動かせる社会は違う。**

人が動ける社会とは、働く人が自分の意思で職場を選び直せる社会である。

人を動かせる社会とは、企業が必要なときに人を集め、不要になれば外へ出せる社会である。

同じ流動性でも、主語が違えば中身は変わる。

この主語を曖昧にしたまま労働市場を語ると、働く人の自由のように見えて、実際には企業の調達可能性だけが高まることになる。

## 本来、流動性は一般市民に有利であるべきだった

原文は、労働力の流動性そのものを否定しない。

本来、流動性は一般市民に有利な概念であるべきだった。

```text
一つの会社に人生を預けなくてよい
合わない職場から離れられる
技能を持って別の場所へ移れる
子育てや介護に合わせて働き方を変えられる
地域を移っても働ける
学び直して再参入できる
失敗しても戻れる
会社に依存しすぎずに生活できる
```

こういう流動性なら、働く人にとって大きな意味がある。

会社に閉じ込められない。

上司や組織に人生を握られすぎない。

ブラックな職場から逃げられる。

自分に合う場所を探せる。

家庭や地域生活と働き方を調整できる。

これは減速のイノベーションとも相性がよい。

なぜなら、考えたいのは企業を速く回すことではなく、人が壊れず、生活を続けながら選び直せる社会だからである。

人が動けることは大事である。

だが、それは人が市場に放り出されることではない。

```text
動いても生活が壊れないこと
動いた先で働き続けられること
動いたことで社会的信用を失わないこと
動いた後にも戻れる場所があること
```

そこまで含めて、初めて労働力の流動性は一般市民にとっての自由になる。

## 現在の流動性は、企業側に先に効きやすい

現実には、労働力の流動性の利点は企業側に先に現れやすい。

```text
必要なときに人を採る
不要になれば契約を終える
即戦力を市場から買う
教育コストを外部化する
固定費を変動費化する
下請け、委託、派遣、外注で不足を埋める
繁忙期だけ人を増やす
専門人材だけを短期で使う
```

これは企業にとっては合理的である。

市場、技術、需要、競争環境は変わる。

企業が人員配置を柔軟にしたいと考えるのは自然である。

しかし、企業にとって合理的な流動性が、そのまま働く人にとっての自由になるとは限らない。

企業にとっての流動性は、しばしば人材の調達しやすさである。

固定費を変動費に変えることでもある。

教育や待機や生活不安のコストを、企業の外へ逃がすことでもある。

働く人にとって必要なのは、単に市場に出されることではない。

動いても生活が壊れないこと。

移っても技能が活かせること。

働きながら学び直せること。

家庭や地域生活を失わないこと。

次の仕事に移るまでの不安が大きすぎないこと。

年齢や契約形態によって、いきなり市場から弾かれないこと。

安心の土台がないまま流動性だけを高めれば、それは自由ではなく不安定化になる。

## Security と Comfort を労働市場に置く

原文は、安心を Security と Comfort に分ける。

Security は、生活が壊れないための安心である。

Comfort は、心地よく続けるための安心である。

労働における Security とは、

```text
仕事を失っても、すぐに生活が壊れないこと
次の仕事へ移るまでの生活が支えられること
病気や介護や子育てで働き方を変えても、人生が破綻しないこと
契約が弱い人ほど一方的に負荷を背負わされないこと
最低限の賃金、休息、安全、相談先があること
雇用形態が変わっても、社会的信用が急落しないこと
```

である。

これは甘えではない。

働く人が市場の中で動くための基礎防衛である。

労働における Comfort とは、

```text
働き続けても心身が削られすぎないこと
現場に余白があること
教育や引き継ぎが行われること
人間関係が壊れきっていないこと
働く場所や時間に、ある程度の選択肢があること
家庭や地域生活と両立できること
自分の仕事に意味や手応えを感じられること
```

である。

これは贅沢ではない。

人が長く働き、学び、移り、戻り、支え合うための生活感覚である。

Security がなければ、人は守りに入る。

Comfort がなければ、人は長く続けられない。

この二つがないまま流動性を高めても、人は自由に動けない。

ただ、不安定な状態で動かされるだけになる。

## 流動性には、信用のポータビリティが必要である

労働力の流動性を考えるとき、見落とされやすいものがある。

社会的信用である。

日本社会では、雇用形態が社会的信用に大きく関わっている。

正社員であることは、単に雇用が安定しているというだけではない。

```text
住宅ローン
賃貸契約
クレジットカード
自動車ローン
結婚
子育て
家族形成
親族からの見られ方
社会的評価
```

で、正社員属性は強い信用として扱われやすい。

一方、非正規、派遣、委託、個人事業主、フリーランスは、収入があっても信用が低く見られやすい。

これは労働市場の中だけの問題ではない。

雇用形態が変わると、企業に対して弱くなるだけではない。

社会、金融機関、住居市場、家族形成や将来設計に対しても弱くなる。

正社員を離れた瞬間に社会的信用まで落ちる。

派遣になれば信用が下がる。

非正規になれば将来設計が難しくなる。

委託や個人事業主になれば、収入があっても不安定に見られる。

これでは、人は動けない。

動くたびに信用を失うなら、それは自由な移動ではない。

労働力の流動性を本当に働く人の自由にするなら、技能のポータビリティだけでは足りない。

社会的信用のポータビリティが必要である。

## 流動性は、生活予測性とセットでなければならない

労働力の流動性を高めるなら、生活予測性も同時に高めなければならない。

```text
転職しやすくするなら、転職中の生活をどう支えるのか
学び直しを求めるなら、学ぶ時間と費用を誰が持つのか
副業や独立を促すなら、社会保障や税務や契約リスクをどう支えるのか
派遣や委託を増やすなら、現場の安全や教育や休息をどう守るのか
個人事業主を増やすなら、交渉力の弱さをどう補うのか
非正規でも社会的信用をどう持てるようにするのか
```

ここを見ずに「流動性が大事だ」と言うと、働く人にだけ不確実性が移る。

企業は柔軟になる。

だが、働く人の生活は不安定になる。

企業は固定費を減らせる。

だが、働く人は収入、訓練、健康、契約リスクを個人で抱える。

企業は必要な時だけ人を使える。

だが、人は必要とされない時期を自分で耐えなければならない。

これは、社会全体として本当に効率的なのか。

働く人の生活予測性が壊れれば、一般市場に円は回りにくくなる。

労働力の流動性は、景気の外側の話ではない。

働く人が将来をどう見通せるかは、一般市場そのものに関わっている。

## 負荷は、契約の弱い場所へ移っただけである

外部に対して、早く届ける、安く提供する、いつでも対応する、高品質にする、柔軟に応じると約束する。

その裏側で働く人の条件も見なければならない。

```text
人員は足りているのか
休息はあるのか
教育はあるのか
安全は守られているのか
無理な納期や価格が現場に押し込まれていないか
正社員以外の人に負荷が逃げていないか
```

外部SLAだけが強くなり、内部SLAがないままになると、現場は壊れる。

そして労働力の流動性だけが高まると、その負荷はさらに見えにくくなる。

```text
正社員が抱えきれない負荷は、非正規へ流れる
非正規が抱えきれない負荷は、派遣へ流れる
派遣が抱えきれない負荷は、下請けへ流れる
下請けが抱えきれない負荷は、委託へ流れる
委託が抱えきれない負荷は、個人事業主へ流れる
```

すると、企業の中からは負荷が消えたように見える。

だが、社会から消えたわけではない。

契約の弱い場所へ移っただけである。

これでは、流動性が高まったのではない。

> **余白のなさが、弱い場所へ流れただけである。**

## 正社員だけを見ても足りない

労働市場は正社員だけでできていない。

```text
非正規
派遣
下請け
委託
フリーランス
個人事業主
ギグワーカー
副業人材
```

こうした人たちが、物流、介護、教育、IT、建設、清掃、警備、制作、配達、事務、販売、保育、地域サービスを支えている。

ここを見ずに、企業と正社員だけで労働市場を語ると、現実を見誤る。

働く人の Security と Comfort を考えるなら、契約形態を越えて見る必要がある。

正社員だけ守られても、非正規に負荷が逃げるなら意味がない。

非正規だけ見ても、派遣や下請けに逃げるなら意味がない。

下請けだけ見ても、委託や個人事業主へ逃げるなら意味がない。

社会全体として、誰がどの負荷を引き受けているのか。

ここを見なければならない。

内部SLAとは、企業の中だけの話ではない。

サービスを支える労働の連鎖全体に対して、どこまでの条件を守るのかという問いである。

## 人手不足を、安い労働力で埋めてよいのか

原文は、人手不足と外国人労働者にも触れる。

問題は、外国人労働者が増えること自体ではない。

問題は、なぜ安い労働力が必要とされるのかである。

価格を上げられない。

賃金も上げられない。

それでも仕事量は維持しなければならない。

この状況に置かれた企業に残される選択肢は多くない。

ここを見ずに、安い労働力を追加するだけなら、問題は解けない。

負荷が別の弱い場所へ移るだけである。

外国人労働者を調整弁にしてはいけない。

安い労働力が必要になる価格、サービス水準、発注構造、内部条件を見なければならない。

## 育成責任を消すための言葉にしてはいけない

流動性が高まると、企業は即戦力を求めやすくなる。

人材市場から、今すぐ使える人を採る。

教育コストをかけずに済む。

必要なときだけ採る。

合わなければ契約を終える。

これは企業にとって合理的である。

しかし、社会全体で見れば、誰かが人を育てなければならない。

```text
新人を育てる
未経験者に機会を与える
中堅を鍛える
熟練者の技術を継承する
失敗を吸収する
現場で学ぶ時間を作る
```

これらはコストである。

だが、社会にとっては投資でもある。

企業が人材育成を外部化し続けると、短期的には効率的に見える。

しかし、長期的には技能の土台が痩せる。

どこかで誰かが育てた人材を奪い合うだけになる。

未経験者は入りにくくなる。

若い人は育たない。

中高年は更新の機会を失う。

現場の継承が細る。

これは一般市場を弱くする。

企業が長期で人を育てられない社会では、働く人も長期で生活を組み立てにくい。

> **労働力の流動性は、企業の育成責任を消すための言葉であってはならない。**

## 人が動ける社会には、戻れる場所がいる

人が動ける社会には、戻れる場所が必要である。

転職できる、学び直せる、独立できる、副業できる、地域を移れる、働き方を変えられる。

これは大事である。

だが、動けることと、戻れないことは違う。

```text
失敗したら終わり
病気になったら終わり
介護が始まったら終わり
子育てで離れたら戻れない
年齢を重ねたら市場から外れる
一度非正規になったら戻れない
一度個人事業主になったら保障が薄い
一度社会的信用を落としたら回復しにくい
```

これでは、人は動けない。

本当に人が動ける社会には、戻れる場所がいる。

失敗しても戻れる。

学び直して戻れる。

育児や介護の後に戻れる。

病気の後に戻れる。

地域を変えても戻れる。

違う働き方から戻れる。

一度雇用形態が変わっても、社会的信用を取り戻せる。

この戻れる場所は Security である。

戻った先で壊れずに続けられる条件は Comfort である。

人を動かすだけなら簡単である。

人が動けるようにするには、社会の側に受け止める設計が必要である。

## 結論――流動性を、安心の土台から考える

労働力の流動性は必要である。

一つの会社に縛られすぎる社会は息苦しい。

合わない職場から離れられることは大事である。

技能を持って別の場所へ移れることも大事である。

企業が新しい事業に必要な人材を集めることも必要である。

だが、流動性には主語がある。

```text
人が動ける社会なのか
人を動かせる社会なのか
```

ここを分けなければならない。

企業にとっての流動性だけを高めれば、労働力は調達しやすくなる。

固定費を変動費化できる。

教育や待機のコストも外へ逃がせる。

人手不足も、より安い労働力の追加で処理しやすくなる。

しかし、それでは働く人の生活予測性は壊れる。

非正規、派遣、委託、個人事業主、外国人労働者に負荷が流れる。

雇用形態が変われば社会的信用も落ちる。

学び直しは不安処理になる。

子育てや地域生活は難しくなる。

企業も国内需要を信じにくくなる。

だから、労働力の流動性は、安心の土台から考えなければならない。

```text
仕事を失ってもすぐに生活が壊れない Security
働き続けても心身が削られすぎない Comfort
雇用形態が変わっても失われない社会的信用
学び直しや転職を選べる余白
家庭や地域生活を壊さずに働ける条件
契約形態を越えて、負荷が弱い場所へ逃げない設計
```

## 主張の種類

### 原文自身の労働流動性批判

- 労働力の流動性は、政策の言葉では「人が動ける自由」に見えるが、生活者には「企業が人を動かせる自由」に見えやすい。
- 人が動ける社会と、人を動かせる社会は違う。
- 主語を曖昧にすると、働く人の自由のように見えて、企業の調達可能性だけが高まる。

### 原文自身の安心条件

- 働く人の流動性には Security と Comfort が必要である。
- 雇用形態が変わっても、社会的信用を持ち運べる必要がある。
- 流動性は、生活予測性とセットでなければならない。
- 人が動ける社会には、戻れる場所が必要である。

### 原文自身の負荷移転批判

- 外部SLAだけが強くなり、内部SLAがないと現場は壊れる。
- 労働力の流動性だけが高まると、負荷は契約の弱い場所へ移る。
- 正社員だけでなく、サービスを支える労働の連鎖全体を見なければならない。
- 安い労働力がなぜ必要とされるのかを問う必要がある。
- 労働力の流動性は、企業の育成責任を消すための言葉であってはならない。

本記事は、労働力の流動性を条件付きで肯定するだけの整理ではない。同じ流動性という言葉が、働く人の自由にも、企業の調達可能性にもなりうることを切り分け、安心の土台がない流動性は、自由ではなく不安定化であると批判している。
