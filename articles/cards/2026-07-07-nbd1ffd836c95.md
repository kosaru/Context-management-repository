## 原文の最も強い主張

原文の中心は、皇室典範改正への賛否を直接決めることではない。

> **リベラルが制度変更を主張するなら、男女平等、多様性、個人の尊重、時代への適合という正義を先に置くのではなく、その制度が何を支え、誰に負担をかけ、どの歴史的機能を持ち、変更によって何を改善し何を失うのかを分析しなければならない。天皇制についてそれをせず、保守側が守ろうとしている祈り、皇統、正統性、国民統合の回路を見ないまま正義の言葉で押し切るなら、それはリベラルではなく、正義による制度の上書きである。**

これは「保守の説明に同意せよ」という要求ではない。

```text
保守側が提示する制度理解を確認する
  → 同意する必要はない
  → 批判してよい
  → 別の分析を出してよい

しかし
  → 見なかったことにはできない
  → 「古い」「非民主的」「差別的」だけで退場させてはいけない
```

原文が名指ししているのは、抽象的な「社会」ではなく、自称を含むリベラル側である。

## 原文が置いた「リベラル」の基準

原文におけるリベラルは、旧制度を反射的に壊す立場ではない。

制度について、少なくとも次を問う立場として定義される。

- その制度は何を支えているのか
- 誰に負担をかけているのか
- どのような歴史的役割を持ってきたのか
- 現代に残る機能と歪んだ機能は何か
- 変えることで何が改善されるのか
- 変えることで何が失われるのか
- 同じ目的を達成する別の補修方法はないのか
- 一般原理を特殊な制度へ適用できる根拠は何か

マルクスが資本主義の内部構造を分析したことを例に、原文は「批判の前に分析がある」という順序を置く。

この順序を使い、皇室典範改正の最初の問いを次へ戻す。

```text
男系男子限定は古いか
女性天皇を認めるべきか
女系天皇を認めるべきか
    ↓ その前に
天皇制は現代日本で何をしている制度か
皇室は日本にとって何を支えているか
```

## 正義の言葉への批判

原文は、男女平等、差別解消、多様性、個人尊重を否定していない。

否定しているのは、重要な価値を強いラベルとして使い、制度分析の前に反対者を道徳的に裁くことである。

```text
男系継承への慎重論
  → 女性差別と先に分類される

制度分析を求める発言
  → 古い制度の擁護と先に分類される

天皇制の機能を分析する発言
  → 特権制度の擁護と先に分類される
```

原文はこれを、単なる議論のマナー違反ではなく、リベラルが自分の分析能力を捨てる問題として扱う。

正義を掲げることと、制度を分析することは同じではない。原文が守ろうとしているリベラルの強みは後者である。

## 保守側の分析として原文が立てたもの

ここは、原文自身の立場と、原文が再構成した「保守側の分析」を混ぜてはならない。

原文が保守側の回答として立てるのは、次の構造である。

```text
天皇
  → 政策を決めない
  → 選挙で争わない
  → 国民へ命令しない
  → 国民の安寧を祈る祭祀的中心

武家政権
  → 軍事、行政、裁判、土地支配を担う
  → 統治する
  → しかし、祈りと正統性の根拠を自分だけでは持てない

天皇家・朝廷
  → 祭祀、儀礼、官位、年号、国家の時間秩序を担う
  → 武家政権が接続する祈りと正統性の古層として残る
```

原文はこれを「天皇は祈る。将軍は統治する」と表現する。

さらに、東照大権現を天皇制の代替王朝ではなく、天皇・朝廷の秩序に接続された徳川側の祈りの体系として位置づける。

ここから、原文は次の強い歴史解釈を出す。

> 武家政権が天皇家を消さなかったのは、政治的に便利だっただけではなく、統治する側にも祈りと正統性の根拠が必要だったからである。

この命題は本文の中心的な押し広げである。ただし、個別研究の確認済み結論としてカード側が強めてはならない。

## 保守側の分析と、リベラル側へ求める分析

原文は両者を同じ内容としていない。

### 保守側の分析

- 天皇は国民の安寧を祈る祭祀的中心である
- 権威と政治的実権が歴史的に分かれてきた
- 武家政権は祈りと正統性の根拠として天皇家を必要とした
- 東照大権現も天皇・朝廷の秩序を否定せず、その上へ徳川の祈りの体系を接続した
- 戦後象徴天皇制でも、政治権力から切り離された祈りと国家連続性の機能が残った

### リベラル側へ求める分析

- 男系継承は本当に皇統の同一性を支えるのか
- 祭祀的権威は現代国家に必要なのか
- 天皇の祈りを国家制度の中へ置くことはどこまで許されるのか
- 宮中祭祀と象徴・国民統合はどう関係するのか
- 女系・双系化しても象徴性や国民統合の機能は維持できるのか
- そもそも、その機能を維持すべきなのか

原文の要求は、保守側の分析を正解として受け入れることではない。

**保守側が何を守ろうとしているかを把握し、その機能理解へ対抗する分析をリベラル自身が出せ**という要求である。

## 明治維新と戦後象徴天皇制の位置づけ

原文は、鎌倉以降の「祈る天皇／統治する武家政権」の分離が、明治維新で組み替えられたとする。

```text
鎌倉以降
  → 祭祀的権威と政治的実権が長く分離

明治維新
  → 近代国民国家形成のため再接続
  → 天皇を国家統合の中心へ再配置

戦後
  → 象徴天皇制によって政治権力から再び切り離す
  → 国民の安寧を祈る機能までは消えない
```

原文は、この複雑さを見ず、祭祀王という説明を政教分離違反の一語だけで処理することを拒否する。

ただし、この歴史図式と憲法・宗教制度上の評価は、本文の構造把握であり、カード側で確定した日本史の単一説明へしてはならない。

## 皇室典範改正を分ける軸

原文は「皇室典範改正」を一つの改革名へまとめない。

```text
皇族数減少への対応
  → 現行の皇統判定原理を維持する制度補修か

男系から女系・双系への変更
  → 皇統を何によって同一と判定するかを変える制度転換か
```

原文の比喩では、次を区別する。

- 制度補修
- 制度転換
- リファクタリング
- 仕様変更
- アーキテクチャ変更

この比喩を、客観的に確立した制度分類として固定してはならない。

原文が要求しているのは、改革の名前ではなく、何を維持し、何を変更するのかを国民へ見せることである。

## 名指しと非対称性

### リベラル側

原文の主要な批判対象である。正義の言葉を持つこと自体ではなく、その強さを使って制度分析の前に相手を道徳的に裁き、自分の方法を捨てることが批判される。

### 保守側

原文が無条件に正しいと認定する側ではない。天皇を祭祀的中心、皇統を継承の同一性、天皇家を祈りと正統性の根拠として見る分析を提示する側であり、リベラルが反論すべき対象として立てられる。

### 皇室・天皇

制度分析の対象であると同時に、国民の安寧を祈る務め、象徴機能、皇位継承の負担を実際に担う当事者である。抽象的な制度原理だけで、個人へかかる負担を消してはならない。

### 国民

制度変更の判断主体とされるが、女性天皇と女系天皇、制度補修と制度転換の違いが示されなければ、何へ賛成しているのか判断できない側である。

### 政治・メディア・有識者

本記事では前記事ほど直接に名指しされないが、比較可能な論点を国民へ示す制度的責任の位置にある。カード側で共謀や意図的隠蔽を補ってはならない。

- 東照大権現と天皇・朝廷秩序の接続を、徳川期全体の単一説明にできるか
