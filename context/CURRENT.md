## 最上位の問い

> 人類は、どうすれば滅びずに続くのか。

この問いは後期連載で突然生まれたものではない。

```text
生活が壊れる条件への関心
→ 人を壊さない制度と組織
→ 国家より上位の主語として人類を置く
→ 文明を適応知の集合として保存する
→ 継続を形式知と暗黙知の循環として捉える
→ 担い手の再生産と修復能力を継続条件へ含める
→ 減速のイノベーションとして再編する
```

ただし、人類継続を理由に現在の個人を資源化してはならない。

現在の自由、尊厳、生活、文明多様性、異議、退出、修復可能性を、継続の内容へ含める。

## バッチ3――継続・文明・Security

### 継続と延命を分ける

制度、組織、文化、サービスの外形が残っていても、同じ人が穴を埋め続け、次の担い手が育たず、修復できないなら継続ではない。

```text
外形が残る
− 担い手の再生産
− 知識循環
− 修復能力
− 退出可能性
＝ 延命
```

現在の継続の仮定義：

```text
生活が破綻しない
＋ 多様な適応知が残る
＋ 担い手が再生産される
＋ 形式知と暗黙知が往復する
＋ 失敗から修復できる
＋ 異議・退出・変更が可能である
```

参照：`indexes/CONTINUITY_MODEL.md`

### Security

Securityは一つの所得保障ではない。

- 日常の生活の底
- 医療・事故・災害などの破滅的リスク
- 移動後も切れない保障
- 失敗後の再出発
- 接触・配置を変えられる退出可能性
- 重大な害を止められる停止権

を機能別に支える。

複数担保を持つほど、制度間の隙間と最終責任空白を同時に点検する。

### 文明保存

文明を博物館的に凍結しない。

食、住、ケア、協力、危機対応、意味づけなどの適応知と、それを内部から批判・更新できる回路を未来へ残す。

文明多様性は、不確実な未来へ一つの適応方式だけを残さないための冗長性になりうる。

ただし、文明の名で抑圧、差別、離脱禁止、特定層の無償労働まで保存してはならない。

### 倫理生成構造

倫理や信頼を個人徳だけで説明しない。

```text
Security
→ 余裕
→ 長期思考
→ 信頼
→ 関係倫理
```

という生成経路を見る。

一方で、構造説明によって個々の加害・怠慢・判断責任を消さない。

### 現場中核層

制度改革、多文化化、流動化、標準化に伴う翻訳・教育・例外処理・非常時対応を計上しないと、暗黙知を持つ現場中核層へ集中する。

日本的な先回りや引受け能力が制度に支えられないとき、文化は共有財産ではなく、上からの圧力を個人へ通す媒体へ反転する。

問題は外国人材や多様化そのものではない。

運用コストと責任コストを誰へ置くかである。

## Security・Comfort・文明保存の役割配置

```text
国家・制度
  → 生活破綻を防ぐSecurity

都市・家庭・地域・生活圏・市場
  → 生活を無理なく回す複数のComfort

国際制度
  → 衝突抑制と文明継承条件の保全

```

国家がComfortを一つの正しい生活として定義しない。

家庭と現場中核層を、制度不足の最終処理場にしない。
