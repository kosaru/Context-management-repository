## バッチ3――継続・文明・Security

### 継続と延命

```text
外形が残る
− 担い手の再生産
− 知識循環
− 修復能力
− 退出可能性
＝ 延命
```

現在の継続の仮定義：

```text
生活が破綻しない
＋ 多様な適応知が残る
＋ 担い手が再生産される
＋ 形式知と暗黙知が往復する
＋ 失敗から修復できる
＋ 異議・退出・変更が可能である
```

### Security

Securityは一つの所得保障ではない。

- 日常の生活の底
- 医療・事故・災害などの破滅的リスク
- 移動後も切れない保障
- 失敗後の再出発
- 接触・配置を変える退出可能性
- 重大な害を止める停止権

を機能別に支える。

### 文明保存

文明を博物館的に凍結しない。

食、住、ケア、協力、危機対応、意味づけなどの適応知と、それを内部から批判・更新できる回路を未来へ残す。

文明の名で抑圧、差別、離脱禁止、特定層の無償労働まで保存してはならない。

参照：`indexes/CONTINUITY_MODEL.md`

## バッチ4――AI・情報・Repair

### AIが入る空白

大人は迷い・傷・未整理さを自分で処理する主体として扱われ、揺れを支える帰還点を持ちにくい。

AIはこの空白へ、即答、傾聴、整理、非拒絶を提供する。

### 支援と整えすぎ

```text
整理によって戻れる
と
整理によって戻る前の揺れが消える
```

を分ける。

### 安定化

```text
具体的な非対称
→ 一般的な論点

誰が決め、誰が削られるか
→ メリットとデメリット

不可逆な負担
→ バランスの取れた意見
```

何を消したかを表示しないまま、成熟した結論として流通することが問題である。

### Repairの四層

```text
正誤修正
関係修復
読解修復
構造修復
```

謝罪や同意だけでは、誤読差分と学習可能性は戻らない。

### 迎合型と矯正型

```text
迎合型
→ 利用者の前提へ寄りすぎる

矯正型
→ 設計者の前提へ寄せすぎる
```

第三の正解をAIへ埋め込むのではなく、採用解釈、追加前提、省略、未確認範囲を表示し、最終判断を人間へ返す。

参照：`indexes/AI_REPAIR_MODEL.md`

## バッチ5――政治機能と国際秩序

### 政治の三機能

```text
保存
→ 継続条件を残す

再設計
→ 歪み・閉塞・老朽化を組み替える

回転条件
→ 保存と再設計が相互破壊せず、検証・撤回・修正を続けられるようにする
```

三機能は人物・政党・国家へ固定する属性ではない。

必要な機能も、次へ反転しうる。

```text
保存 → 硬直・排除
再設計 → 動員・破壊
回転条件 → 希釈・先送り・無権限調整
```

### 制度の価値

制度の価値を、完成した正しさだけでなく、誤りを検証し、撤回し、再審査できる能力で見る。

修正可能性は無期限の保留ではない。決定時間、停止権、負担上限、見直し時期を必要とする。

### 異なる利用目的の接続

共通制度へ参加する主体が、同じ目的・意図・利益を持つとは限らない。

```text
同じ制度へ参加する
≠ 目的が一致する
≠ 意図が一致する
≠ 利益が一致する
```

文明保存型制度は、国家統合、文明圏主権、秩序負担分散、生活基盤保全など異なる目的を消さず、継承回路を壊しすぎない最低線を共有する構想として読む。

### 中心を支える外周担保

国際秩序の中心は、一つの通貨・軍事力・制度だけで成立しない。

```text
安全保障
＋ 海上交通
＋ 物流
＋ エネルギー
＋ 決済
＋ 金融市場
＋ 基地受入れ
＋ 資金還流
```

という担保束を外周が支えることで再生産される。

### 担保の意味反転

```text
防衛基地
→ 第三国攻撃拠点
→ 報復圏への固定

準備通貨
→ 中立的インフラ
→ 制裁・排除手段

文明保存
→ 継承回路の保護
→ 国家多数派の自己正当化
```

用途が変われば、元の同意を自動延長せず、目的・受益者・負担者・停止・退出・補償を再交渉する。

### 外周の主体性

湾岸、日本、コネクター国家、基地受入れ国は、中心間で選ばされるだけの受動的周辺ではない。

基地用途を限定し、物流・決済を多層化し、ルール共同体を交渉単位へ育てられる。

ただし多層化は自立と同義ではない。複数中心からの圧力、二重依存、責任空白も生む。

参照：`indexes/ORDER_RENEGOTIATION_MODEL.md`
