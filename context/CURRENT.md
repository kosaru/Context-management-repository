## 現在の主要モデル

### 責任配置

```text

→ 制度を腐らせる

```

参照：`indexes/RESPONSIBILITY_MODEL.md`

### 継続

```text
生活が破綻しない
＋ 多様な適応知が残る
＋ 担い手が再生産される
＋ 形式知と暗黙知が往復する
＋ 失敗から修復できる
＋ 異議・退出・変更が可能である
```

参照：`indexes/CONTINUITY_MODEL.md`

### Security・帰還可能性

```text
非崩壊
→ 停止
→ 退出
→ 帰還・回復
→ 再参加
```

制度は主観的安心を完全には約束できない。約束すべきなのは、危機時の非崩壊と、失敗後も別の選択を試せる床である。

帰還は元の場所への復帰だけではなく、別の仕事、地域、関係、役割へ再接続できることを含む。

参照：`indexes/SECURITY_RETURNABILITY_MODEL.md`

### AI Repair

```text
正誤修正
関係修復
読解修復
構造修復
```

謝罪や同意だけでは、誤読差分と学習可能性は戻らない。

参照：`indexes/AI_REPAIR_MODEL.md`

### AI製品統治

```text
観測されたAI出力
→ 公開された製品変更
→ 推定される設計評価指標
→ 市場・事業上の報酬
→ 企業利益・組織制約
→ 企業・設計者の意図
```

出力から企業意図へ直接飛ばない。意図が未確認でも、予見可能で変更可能な反復効果への設計責任は残る。

参照：`indexes/AI_PRODUCT_GOVERNANCE_MODEL.md`

### 二項対立・回転

```text
仮の補助線
→ 論点を立てる

配属線
→ 発言より所属を先に読む

動員的固定
→ 怒り・恐怖・正義へ接続し、修正不能化する
```

止めるべきなのは二項対立そのものではなく、仮の切断が配属・動員・固定化へ変わる回路である。

回転は中間化・両論併記・均衡ではない。

参照：`indexes/BINARY_OPPOSITION_ROTATION_MODEL.md`

国際秩序の中心は、安全保障、海上交通、物流、エネルギー、決済、金融市場、基地受入れ、資金還流という外周担保で再生産される。

用途変更時には、目的、受益者、負担者、停止、退出、補償を再交渉する。

参照：`indexes/ORDER_RENEGOTIATION_MODEL.md`

### 固定した緊張

```text
国家は安心を約束しすぎてはいけない
しかし
個人にはやり直すための安心の床が必要である
```

これは矛盾ではない。

国家が保証すべきなのは、成功・無事故・無不安ではなく、破局を防ぐ最低線、保障限界、停止権、退出後の生活維持、再参加の入口である。

### 能力の見方

```text
能力の現れ方
＝ 個人の技能
× 環境
× 役割
× 時期
× 支援
× 関係
```

環境要因を認めることは本人の責任を消すことではない。一度の不適合を人格全体へ拡張せず、変更可能な条件を分ける。

参照：`analysis/B_GROUP_03_SECURITY_AND_RETURNABILITY.md`
