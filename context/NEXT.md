## 現在の中心課題

> 残る316記事を順番に埋めるのではなく、現在の六系譜・現在地・未解決問題を成立させた重要記事と、現在の体系へ抵抗する記事を選び、必要なものだけ詳細カードへ昇格する。

## 現在の正本

- 選定フェーズ：`roadmaps/PHASE_B2_KEY_ARTICLE_SELECTION.md`
- 選定台帳：`analysis/KEY_ARTICLE_SELECTION.md`（次に作成）
- 全記事の所在：`articles/COMPACT_MAP.md`
- 時期別成立順：`analysis/PHASE_01_...`〜`analysis/PHASE_06_...`
- 横断構造：`indexes/CROSS_RECONSTRUCTION.md`
- 六系譜：`indexes/LINEAGES.md`
- 現在の立場：`indexes/CURRENT_POSITIONS.md`
- 未解決問題：`indexes/UNRESOLVED_QUESTIONS.md`

## 選定の順序

```text
現在の立場を成立させた転換点
→ 以前の立場を修正した記事
→ 複数系譜の接続点
→ 現在の体系へ抵抗する記事
→ 未解決問題を進めるために必要な記事
```

記事を公開日順に一件ずつ処理しない。

連載、直接応答、修正前後、初出・試行・統合のまとまりを優先する。

## 優先度

### 優先度A

必ず詳細化する。

- 概念・問いの初出
- 主要な転換点
- 明示的または実質的な修正
- 複数系譜の接続点
- 現在の体系へ抵抗する記事
- 事実と推論の分離が重要な記事

### 優先度B

記事群または資料束単位で詳細化を検討する。

- 後期統合稿の前史
- 同じ構造を異なる領域へ適用した記事
- 未解決問題へ直接つながる記事

### 優先度C

時期別解析とコンパクト地図で維持する。

- 既出概念の反復
- 一般読者向け再構成
- 文脈差分の小さい適用稿

## 直近の作業

`analysis/KEY_ARTICLE_SELECTION.md`を作成する。

記事または資料束ごとに次を記録する。

- note ID・期間
- タイトルまたは資料束名
- 対応する系譜
- 現在の役割候補
- 選定理由
- 優先度
- 詳細カード化の要否
- 関連する未解決問題
- 既存詳細カードとの関係
- 判定上の不確実性

## 第D段階との関係

次期研究プログラムと継続設計の核は、将来の準備稿として残す。

- `roadmaps/PHASE_D_CONTINUITY_WITHOUT_SACRIFICE.md`
- `research/CONTINUITY_DESIGN_KERNEL.md`

ただし、現在の作業ではない。

```text
重要記事を選ぶ
→ 記事単位で根拠・修正・抵抗点を確認する
→ 必要な詳細カードを増やす
→ 六系譜・現在地・未解決問題を必要に応じて修正する
→ 第D段階へ進む
```

## 完了条件

- 六系譜の主要な初出・転換・修正が記事単位で確認されている。
- 後期統合稿の前史が追える。
- 現在の体系へ抵抗する記事が選ばれている。
- 未解決問題に必要な記事が詳細化されている。
- 詳細化しない記事をコンパクト地図へ残す理由を説明できる。
- 第D段階の前提に、記事単位の根拠と反例がある。
