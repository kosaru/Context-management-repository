## 完了したB群再判定3――Security・帰還可能性

対象：

- `n2f379dd24aa9`　安心を約束しないという選択
- `n5968f6dee1ef`　やり直せる余地が、社会を強くする

判定：2件とも詳細カードへ昇格。

### 安心の分離

```text
主観的な安心感
≠ 制度上の非崩壊保障
≠ 失敗後に選択を試せる安心の床
```

### 国家基盤

```text
不安を消す
ではなく
致命的崩壊を防ぐ
＋ 保障の限界を示す
＋ 行き過ぎを止められるようにする
```

専門家は手段を設計するが、目的・優先順位・負担・停止点まで白紙委任しない。

### 帰還可能性

```text
停止
→ 退出
→ 生活維持
→ 回復・再評価
→ 別の選択を試す
→ 再参加
```

帰還は元の場所へ戻ることだけではない。別の仕事、地域、関係、役割、学習経路へ再接続できることを含む。

### 帰還を支える層

- 所得
- 住居
- 医療・ケア
- 学習
- 移動
- 経歴・資格
- 関係・所属

一つの給付制度だけでは成立しない。
