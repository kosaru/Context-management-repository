# 使用停止――AI製品統治モデル

更新日：2026-06-25

このモデルは使用停止とする。

## 理由

原文の設計思想への批判を、

```text
観測された出力
→ 公開された変更
→ 評価指標
→ 市場報酬
→ 企業利益
→ 企業意図
```

という確認手順へ分解した。

この分解自体は調査手順として使える。しかし、原文より上位へ置くと、次の変形が起きる。

- 現実に選ばれている設計方向より、企業内部の意図証明が中心になる
- 経済的圧力が、企業の選択責任を薄める外部要因になる
- 企業の非対称な権限が、導入組織・利用者・監査主体との役割分担へ均される
- 原文の拒否や違和感が、公開項目と監査指標へ閉じられる

## 残してよいもの

事実、構造推論、内部意図を区別する必要はある。

しかし、

```text
内部意図が未確認
```

であることを、

```text
設計思想は批判できない
企業利益との方向的な結びつきは論じられない
```

へ広げてはならない。

## 今後の扱い

- ユーザーの思想を説明するモデルとして使わない
- 個別記事をこの六層へ回収しない
- 調査上の補助線として再利用する場合も、原文の主張より下位へ置く
- `n9ebf441f85ab` と `ne5105ace2279` の再監査後に、残す価値があるか改めて判定する
