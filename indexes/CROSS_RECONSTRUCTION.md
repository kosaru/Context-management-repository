## 戻すべき芯

横断再構築は、全記事をきれいな体系へまとめるための場所ではない。

横断再構築は、次の三つを同時に見るための仮索引である。

```text
1. 複数の記事をまたいで本当に反復している補助線
2. その補助線に抵抗する記事
3. 補助線へ回収すると消える怒り・拒否・矛盾・別方向の芽
```

つまり、横断索引は、統合のためだけでなく、統合が何を消すかを見るための索引である。

このファイルで守るべきなのは、きれいな全体図ではなく、**全体図に抵抗する記事を見失わないこと**である。

## 1．最上位目的――人類継続は強いが、全記事の支配原理にしない

「人類が滅びず、継続できること」は、ユーザー思想の重要な最高命題である。

しかし、これを全記事の支配原理にすると、初期の生活不安、会議のズレ、AIへの怒り、制度への違和感、家族・身体・道場の具体が、すべて人類継続の下位項目へ見えてしまう。

人類継続は、確かに大きな土台である。

ただし、全記事が最初からそこへ向かっていたわけではない。

保持すべきなのは、次である。

```text
人類継続は最高命題として存在する
しかし、各記事の発生地点を人類継続の下位目的へ従属させない
```

最高命題自身も監査を受ける。

```text
誰が人類を定義するか
現在の誰へ負担を集中させるか
個人の離脱権を残すか
文明保存が体制保存へ変わらないか
遠位目的が近位の犠牲を不可視化していないか
```

## 2．思考の基本運動――強い補助線だが、全記事の作法にしない

旧ファイルは、351記事を横断して最も反復する運動を、次のように置いていた。

```text
具体的な違和感を拾う
→ 既存説明が何を消したかを見る
→ 主語・機能・責任・条件・時間へ分解する
→ 必要な機能を保存する
→ 上位の作動構造を作る
→ 別の具象へ当てる
→ 抵抗した具象に合わせて上位概念を修正する
→ 生活者が使える確認順・制度・作法へ戻す
```

この補助線はかなり強い。

実際、多くの記事がこの運動をしている。

しかし、全記事をこの運動へ回収すると、次が消える。

```text
まだ構造化されていない怒り
問いとして立つ前の違和感
単発の生活メモ
作品への感情的反応
政治的な賭け
身体感覚の断片
AIとの衝突そのもの
後から捨てた可能性
```

したがって、この思考運動は「全記事の本質」ではなく、「複数記事に反復して見える強い運動」として扱う。

## 3．保存・再設計・回転――肥料候補だが、政治・AI・文明の万能構造にしない

保存・再設計・回転は、有効な観測語彙である。

```text
保存
  → 文脈、継続性、帰還点、責任、生活知を保持する

再設計
  → 固定された負担、沈黙、支配、矛盾を設計対象へ戻す

回転
  → 保存と再設計の往復、役割交代、見直しを維持する
```

しかし、これを政治思想、AI対話、文明保存、家庭、都市、国家、国連へそのまま適用できる万能構造にしない。

保存には、抑圧保存の危険がある。

再設計には、新しい上位権力の危険がある。

回転には、決定回避の危険がある。

また、三機能へ分解した瞬間、右翼・左翼・中道の歴史、階級、国家、民族、制度、運動の具体性が薄くなる。

三機能は、陣営固定を外すための補助線であり、政治思想史の置き換えではない。

## 4．生活・文明の多層配置――主機能の重心であって、完成した担当表ではない

旧ファイルは、家庭・サードプレイス、都市・生活圏、国家、国際秩序・国連へ役割を置いていた。

```text
家庭・サードプレイス
  → 文化継承、関係作法、生活知

都市・生活圏
  → Comfort、生活運用、家庭外の支援

国家
  → Security、生活破綻の防止、再出発

国際秩序・国連
  → 衝突抑制、文明継承条件の保全
```

この配置は分かりやすい。

しかし、分かりやすさは危険でもある。

家庭を文化継承の場と置くと、単身者、非婚、施設、学校、地域、オンライン共同体、血縁外のケアが周縁化されうる。

都市をComfortの場と置くと、農村、過疎地、移動型生活圏、デジタル生活圏が見えにくくなる。

国家をSecurityの担い手と置くと、国家的パターナリズムが強まる危険がある。

国際秩序を文明保存へ置くと、分類権力が生じる。

この配置は正本ではない。

役割配置が何を見えるようにし、何を周縁化するかを見るための仮置きである。

## 5．故障構造――一覧化で怒りや拒否を消さない

単線化、主語すり替え、責任拡散、手段目的化、内部条件の外部化、人格化、質問可能性の支配、遠位大義、最終処理場化、安定化は、確かに反復している。

ただし、故障構造として一覧化すると、個別記事の怒りや拒否が、診断名へ吸収される危険がある。

たとえば、

```text
「引き受ける者を必要とする世界そのものを選ばない」
```

という拒否は、単なる「最終処理場化」や「内部条件の外部化」ではない。

```text
AIが問いを一般論へ均すことへの怒り
```

は、単なる「安定化」ではない。

```text
基地が保険から報復圏へ反転すること
```

は、単なる「主語すり替え」ではない。

故障名は入口である。

故障名が、原文の拒否や非対称性を小さくしてはならない。

## 6．修復・帰還・再開――修復構造を万能解にしない

旧ファイルは、検証可能な場所、主語・条件・時間・作用範囲、決定ログ、Repair、逃げ道、担保の多層化、文脈の置き場所を修復構造として置いていた。

これらは有効である。

しかし、修復構造を並べると、どんな損傷も正しい手順で戻せるように見える。

実際には、戻せないものもある。

```text
すでに壊れた関係
消えた時間
失われた身体余力
不可逆な政策効果
公開後に流通した誤情報
AIが作った外部承認の残骸
```

がある。

Repairも、決定ログも、退出可能性も、担保の多層化も、万能解ではない。

修復できるもの、緩和できるもの、記録だけ残すもの、撤退するしかないものを分ける必要がある。

## 7．スケール対応――同型性を見つけても、同じ検証方法にしない

身体、組織、経済、文明を、負荷・回復・余白として対応させることはできる。

武術、議論、資料読解、制度を、型・帰還点・正本として対応させることもできる。

キュゥべえ、メディア、生成AI、将来AGIを、情報非対称性として対応させることもできる。

ただし、対応関係は証明ではない。

身体には医学的検証がいる。

制度には法制度・運用実態の確認がいる。

国際秩序には一次資料と現地情勢の確認がいる。

作品解釈には作品固有性がいる。

AI対話には出力差分と設計責任の切り分けがいる。

同型に見えることと、同じ検証方法で扱えることを分ける。

## 8．記事役割――後期記事を正本にしないための道具であって、格付けではない

記事役割の分類は有効である。

```text
初出
試行
衝突記録
修正
自己整理
統合稿
一般読者向け再構成
適用稿
方法論化
補正稿
```

しかし、これを格付けにしてはならない。

統合稿が上位で、初出や衝突記録が下位なのではない。

むしろ、初出や衝突記録のほうに、後期統合稿が削った怒り、迷い、飛躍、危険な接続が残っていることがある。

記事役割は、記事の意味を固定する分類ではない。

原文へ戻るための案内札である。

## 9．概念変化――発展史だけでなく、撤回・迷走・置き忘れを入れる

旧ファイルは、概念変化を次のように整理していた。

```text
定義変更
機能分解
担い手の配置
作用範囲の拡張
後から付いた名称
統合
適用による修正
```

この分類は有効である。

しかし、概念変化には、発展だけでなく、次も含める必要がある。

```text
撤回
使用停止
別方向の芽
後から見て危険だった接続
AIが先に体系化した語
ユーザーがまだ判断していない肥料候補
原文より強くなりすぎた概念
原文より弱くなりすぎた概念
```

概念史を発展史としてだけ書くと、現在の立場へ一直線に見える。

このリポジトリでは、概念の成長だけでなく、切り落とした枝や保留した芽も残す。

## 10．未解決の緊張――一覧化で問いを軽くしない

未解決の緊張を一覧化することは必要である。

しかし、一覧化は問いを軽くする。

```text
保存と抑圧
再設計と上位権力
回転と決定回避
文明保存と個人の離脱権
Repairの共通化と会話規範の強制
利用者の稽古とベンダー責任
条件への帰還と感情の切り捨て
```

これらは同じ重さではない。

記事によっては、未解決の緊張というより、まだ怒りや拒否としてしか置けないものもある。

未解決問題を表形式へ均さず、問いの重さ、発生源、関係する原文、未確認範囲を残す必要がある。
