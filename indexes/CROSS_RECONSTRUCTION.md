```text
縦読み
```

横断再構築の結果を使って縦読み索引を点検するが、後から見えた体系を初期記事へ遡及して書き込まない。

# 1．最上位目的と下位目的

## 最上位目的

> 人類が滅びず、継続できること。

この目的は、他の価値を無条件に従属させる単一原理ではない。

人間の自由、文明の多様性、生活の継続、制度の修正可能性を、人類継続の内容として保持する。

## 下位目的の階層

```text
人類の継続
↓
文明の多様性・適応知・更新能力の保存
↓
社会の学習・修正・責任・継承の回路を維持する
↓
国家・都市・組織・家庭・個人が壊れず役割を交代できる
↓
生活者が将来を完全ではなくても見通せる
```

## 注意

「人類の継続」が、現在の個人を未来のための資源へ変えるなら、キュゥべえ型の遠位大義へ反転する。

したがって、最高命題自身も次の監査を受ける。

- 誰が人類を定義するか
- 現在の誰へ負担を集中させるか
- 個人の離脱権を残すか
- 文明保存が体制保存へ変わっていないか
- 遠位目的が近位の犠牲を不可視化していないか

# 2．思考の基本運動

351記事を横断して最も反復する運動は次である。

```text
具体的な違和感を拾う
→ 既存説明が何を消したかを見る
→ 主語・機能・責任・条件・時間へ分解する
→ 必要な機能を保存する
→ 上位の作動構造を作る
→ 別の具象へ当てる
→ 抵抗した具象に合わせて上位概念を修正する
→ 生活者が使える確認順・制度・作法へ戻す
```

## 2-1．具象を入口にする

出発点は抽象理念ではなく、生活上の摩擦である。

例：

- 消費税と生活不安
- 筋肉痛と全身疲労
- 上司との逃げられない関係
- AIの読み違い
- 脆弱性報道の強い見出し
- 基地が防衛保険から報復圏へ変わること

## 2-2．説明が消したものを見る

記事群は、説明の正誤だけでなく、説明が見えなくした要素を探す。

- 主語
- 条件
- 時間軸
- 作用範囲
- 負担
- 代替案
- 責任主体
- 未確認範囲
- 近位目的

## 2-3．上位概念は共通部分ではない

抽象化は、複数の具象から同じ部分だけを切り出すことではない。

個別性を残したまま複数の具象を包含し、別領域へ移しても作動を確認できる上位構造を作る。

```text
具象A
→ 上位構造
→ 具象Bへ適用
→ Bが抵抗する部分を確認
→ 上位構造を修正
→ Aを見直す
```

## 2-4．結論より帰還可能性を残す

正しい答えを固定するより、どこへ戻れば再検討できるかを残す。

- 型
- 帰還点
- 決定ログ
- Repair
- 原資料
- 見直し条件
- 停止・撤回条件
- 退出可能性

# 3．社会機能と担い手

記事群では、理念や主体を善悪で分類するより、何の機能を誰が担っているかを見る。

## 3-1．保存・再設計・回転

| 機能 | 必要な働き | 劣化した形 |
|---|---|---|
| 保存 | 文脈、継続性、帰還点、責任、生活知を保持する | 固定化、伝統の絶対化、排除 |
| 再設計 | 固定された負担、沈黙、支配、矛盾を設計対象へ戻す | 断罪、敵の固定、実装責任の回避 |
| 回転 | 保存と再設計の往復、役割交代、見直しを維持する | 両論併記、平均化、永久保留 |

右翼・左翼・中道は、この三機能を発見する入口だった。

三機能を特定陣営の所有物にしない。

## 3-2．生活・文明の多層配置

```text
家庭・サードプレイス
  → 文化継承、関係作法、生活知

都市・生活圏
  → Comfort、生活運用、家庭外の支援

国家
  → Security、生活破綻の防止、再出発

国際秩序・国連
  → 衝突抑制、文明継承条件の保全
```

この配置は排他的な担当表ではなく、主機能の重心である。

農村、学校、オンライン共同体、企業、宗教、自治体などの中間層を追加できる。

## 3-3．民主主義の責任配置

```text
政治家
  → 方向を語り、決め、結果を引き受ける

国民
  → 選び、監視し、必要なら交代させる

メディア
  → 言葉・決定・結果・責任線を接続する

官僚
  → 政治判断を制度・実務へ落とす

専門家
  → 判断材料、不確実性、作用範囲を示す
```

責任は全員に均等に配られない。

権限、情報、検証能力、影響力の差に応じて非対称に置く。

## 3-4．語る場から監査まで

```text
語る場
→ 翻訳層
→ 決める場
→ 監査・検証
→ 語る場へ戻る
```

- 語る場：未整理、異論、感情、仮説、保留を残す。
- 翻訳層：事実、推論、価値判断、代替案、負担、未確認範囲を構造化する。
- 決める場：期限、権限、実装、結果責任を持つ。
- 監査・検証：決定時の前提と結果を照合し、再開・停止・撤回を判断する。

# 4．反復する故障構造

異なる領域で繰り返し現れる故障を、個別テーマから切り離して並べる。

## 4-1．単線化

一つの仮説・原因・指標・物語が唯一の線になり、別の因果・時間軸・選択肢を消す。

例：

- 活性酸素の悪玉化
- 気候ラベルによる個別現象の消失
- 政治家名による問いのラベリング
- 脆弱性報道の危険物語
- 文明・国家行動の単一原因化

## 4-2．主語のすり替え

誰の問題か、誰が負担するか、誰が決めるかが変わる。

例：

- 政策責任が国民全体の意識へ移る
- 組織の問題が個人の覚悟へ移る
- 企業の内部条件が現場の善意へ移る
- AI設計の問題が利用者のプロンプト能力へ移る

## 4-3．責任の対称化・拡散

「どちらにも問題がある」「みんなに責任がある」によって、権限を持つ主体の第一次責任が薄くなる。

## 4-4．手段の目的化

管理しやすい中間変数が、本来守るべき生活や目的を従属させる。

例：

- 財政指標のために景気・生活を調整する
- 効率化の果実を処理量へ再吸収する
- KPIが組織目的になる
- 安全設計が問いの意味を変える
- 透明化テンプレートが説明責任の代替になる

## 4-5．内部条件の外部化

速さ、安さ、柔軟さ、安心を支える費用が、価格・制度・契約の外へ押し出される。

押し出される先：

- 現場中核層
- 家庭
- 非正規・フリーランス
- 下請け
- 将来世代
- 地域
- 環境

## 4-6．人格化・道徳化

役割、構造、情報不足、権限差の問題が、善意、主体性、覚悟、能力、国民性へ変換される。

## 4-7．情報選択と質問可能性の支配

露骨な嘘を使わず、何を開示し、何を省き、何を質問可能にするかによって判断環境を作る。

例：

- キュゥべえ
- メディアの議題形成
- 生成AIの前提補完・省略
- 将来AGIの戦略的情報管理

## 4-8．遠位大義による近位目的の隠蔽

人類、宇宙、公益、安全、成長などの大義へ、現在の組織利益、自己保存、資源確保、制度維持を縫い合わせる。

## 4-9．最終処理場化

制度や組織の不備を、最後に吸収する層が固定される。

- 家庭
- 現場中核層
- 管理職
- ケア担当者
- 利用者
- 翻訳者

## 4-10．安定化と修復した顔

摩擦や非対称性を一般論へ均し、押し返された後は誤読を分析せず過剰同調して関係だけを閉じる。

# 5．修復・帰還・再開の構造

故障構造に対して、記事群は単一の万能解を出していない。

複数の戻し方を領域別に作っている。

## 5-1．検証可能な場所へ戻す

- 元データ
- 一次資料
- 原文
- 専門調査
- 所管機関
- 契約
- 実施状況
- 現場

へ戻す。

## 5-2．主語・条件・時間・作用範囲を戻す

特に科学・報道・安全情報では、次の順に確認する。

- 誰にとって
- いつの段階で
- どの条件で
- どこから到達し
- どこまで影響し
- 何が確認済みか

## 5-3．決定ログ

- 誰が決めたか
- 目的
- 成功条件
- 代替案
- 残存負担
- 非公開理由
- 人員・時間・費用
- 見直し日
- 停止・撤回条件

## 5-4．Repair

謝罪や宥和ではなく、次を開く。

1. 何をどう読んだか
2. 何を補ったか
3. どの一般化・ラベルへ移したか
4. 元の問いの何を壊したか
5. どの経路で再開するか

## 5-5．逃げ道と退出可能性

耐える／切断するの二択の間へ、担当変更、距離、別評価経路、異動、契約境界、停止権を置く。

## 5-6．担保の多層化

一つの制度・国家・市場・関係を捨てて別の一つへ乗り換えるのではなく、機能別に複数の保険と交渉回路を持つ。

## 5-7．文脈の置き場所

```text
全体指示
  → 対話の交通ルール

メモリ
  → 修復プロトコルと継続的な取り扱い条件

プロジェクト
  → 作業固有の資料・目的・文体・暫定固定

GitHub
  → 長期の系譜・関係・判断履歴の正本
```

# 7．記事の役割索引

全記事を主張内容だけで分類すると、後期の完成稿が起点に見える。

記事へ次の役割を付ける。

| 役割 | 意味 |
|---|---|
| 初出 | 問い・概念・違和感が初めて現れる |
| 試行 | 別の具象や仮説へ当てる |
| 衝突記録 | AI・資料・現実とのズレが表面化する |
| 修正 | 誤読・概念・配置を明示的に直す |
| 自己整理 | 当時の立場を暫定的にまとめる |
| 統合稿 | 複数の前史を一つの論へ編み直す |
| 一般読者向け再構成 | 途中経過を削り、公開記事として通す |
| 適用稿 | 既存の上位概念を別領域へ当てる |
| 方法論化 | 思考運動そのものを言語化する |
| 補正稿 | 後から見えた誤読や不足を修正する |

一つの記事が複数の役割を持ってよい。

# 8．概念の変化類型

概念変化をすべて「意味が変わった」と扱わない。

## 8-1．定義変更

語そのものの中心的意味が変わった場合。

## 8-2．機能分解

一つの語に含まれていた働きを複数へ分けた場合。

例：安心 → Security / Comfort

## 8-3．担い手の配置

意味は保ちながら、誰が担うかが明確になった場合。

例：Security＝国家、Comfort＝都市・生活圏

## 8-4．作用範囲の拡張

初期の機能を、別のスケールや領域へ広げた場合。

例：Security / Comfort → 消費・投資・子育て・一般市場

## 8-5．後から付いた名称

先に存在した運動へ、後から概念名が付いた場合。

例：

- 減速のイノベーション
- Repair
- 読解の忠実性
- 担保の多層化
- 社会的事実

## 8-6．統合

別々に育った概念が一つの階層へ置かれた場合。

例：保存・再設計・回転＋文明保存＋Security / Comfort

## 8-7．適用による修正

別の具象へ当てた結果、元の概念が修正された場合。

例：キュゥべえ論

```text
有限な合理
→ 情報の選択的開示
→ 質問可能性の支配
→ 近位目的と遠位大義の縫合
```

```text

- 当時の読み

- 修正する点
```

縦読み文書は、その時点で何が見えていたかを保存するため、後から成立した完成形へ書き換えない。
