# I．最上位で維持する立場

## 1．最上位の問いは、人類の継続である

> 人類は、どうすれば滅びずに続くのか。

人類がこれまで続いてきた事実と、今後も自動的に続く保証を分ける。

環境、AI、政治、経済、都市、制度、文明は、この問いの下位に置く。

ただし、人類継続を理由に現在の個人を資源化してはならない。

人間の自由、文明多様性、生活の継続、修正可能性を、人類継続の内容として保持する。

## 2．文明は勝敗の単位だけでなく、適応知の集合である

文明を、食事、住まい、家族、ケア、労働、協力、環境適応、意味づけを含む生活アルゴリズムとして見る。

異なる文明を残すことは、未来環境が不明な人類の冗長性を残すことでもある。

文明保存は、制度・慣習・体制を凍結することではない。

保存しながら更新できる主体と継承回路を守る。

## 3．減速は、開拓と並走する文明保存技術である

開拓的イノベーションを否定しない。

同時に、開拓が失敗しても食料、医療、物流、水、災害対応を維持できるよう、人口、消費、エネルギー、物流、都市集中、情報接続、資源投入を長期的に下げる準備を進める。

```text
社会の学習・修正・継承を止めない
＋
資源と生活の過剰な回転数を下げる
```

ことを減速とする。

減速は正義、苦行、罪悪感ではなく、安心、近さ、十分さ、長寿命、修理可能性として心地よく選べる必要がある。

# II．社会を動かす方法についての立場

## 4．必要な機能を保存し、反転した地点を再設計する

既存の制度、概念、技術を全面否定しない。

まず、何を守るために作られたかを確認する。

その機能が、別の目的へ反転した地点を探す。

```text
必要な機能を保存する
→ 負担・主語・責任の反転を見つける
→ 内側から再設計する
```

真ん中を取ること、両論を均等に並べることとは区別する。

## 5．保存・再設計・回転を分ける

- 保存：文脈、生活知、継続性、帰還点、責任を保持する。
- 再設計：固定された負担、沈黙、支配、矛盾を設計対象へ戻す。
- 回転：保存と再設計のどちらかを永続的な勝者にせず、役割交代と見直しを維持する。

回転は平均化や永久保留ではない。

一時的な決定と非対称性を認めながら、戻る条件を残す。

## 6．二項対立は消さず、動員的固定化を防ぐ

二項対立は、理解、比較、決定のための仮の補助線として必要である。

問題は、補助線が人物・集団を配属する線となり、敵味方・排除・責任消失へ変わることにある。

```text
仮の切断
→ 人物属性化
→ 陣営固定
→ 動員
→ 排除
```

の変化を観測する。

## 7．非対称な問題を、対称化しない

責任、権限、負担、情報、検証能力が異なる主体を、「どちらにも一理ある」で同じ高さへ戻さない。

複数の正しさを認めることと、責任の重さを均等にすることは違う。

## 8．責任配置は、処罰ではなく修復と継承の条件である

責任配置では、次を分ける。

- 誰が決めたか
- 誰が実装したか
- 誰が説明するか
- 誰が負担したか
- 誰が監査するか
- 誰が修正するか

```text
権限のない責任
→ 人を壊す

責任のない権限
→ 制度を腐らせる
```

トップの覚悟で保存すべき部分は、精神力や人格的優越ではない。

権限を持つ者が、配分結果と修復責任から離れないことである。

## 9．語る場・翻訳層・決める場・監査を分ける

```text
語る場
→ 翻訳層
→ 決める場
→ 監査・検証
→ 語る場へ戻る
```

- 語る場：未整理、異論、感情、仮説、保留を残す。
- 翻訳層：事実、推論、価値判断、代替案、未確認範囲、残存負担を分ける。
- 決める場：期限、権限、実装、結果責任を持つ。
- 監査・検証：前提と結果を照合し、停止・撤回・再開を判断する。

決定は真理ではなく、検証可能な暫定固定として扱う。

# III．生活と制度の内部条件についての立場

## 10．SecurityとComfortは、意味変更ではなく機能分解と担い手配置である

- Security：生活が破綻せず、失敗しても戻れる最低条件。
- Comfort：生活を無理なく回し、関係、子育て、介護、文化、地域生活を続けられる条件。

```text
国家・制度
  → Security

都市・家庭・地域・生活圏
  → Comfort
```

初期に警戒したのはComfortそのものではない。

国家がComfortまで一元的に定義し、考えなくてもよい正解として供給することである。

後期の記事は、この役割配置を消費、投資、子育て、地域生活、一般市場へ押し広げた。

## 11．便利さ・速さ・安さの内部条件を明示する

外へ約束する品質、速度、価格、柔軟性を、個人の善意や現場の我慢で支えない。

- 人員
- 休息
- 教育
- 待機
- 保守
- 安全
- 価格
- 契約範囲

を内部条件として明示する。

効率化で生じた余白を、処理量増加と人員削減へ自動的に再吸収しない。

## 12．必要な安さと、悪い安さを分ける

公共負担、量産、標準化、技術によって入口負担を下げる安さは必要である。

賃金、休息、安全、教育、保守、継承を価格外へ押し出す安さは、将来の破綻を隠す。

## 13．家庭と現場中核層を最終処理場にしない

制度、労働、景気、育児、介護、部門間調整の不足を、家庭や現場中核層の献身へ最後に押し込まない。

社会が動いていることを、内部条件が健全である証拠にしない。

## 14．逃げ道・退出可能性・複数の出口を持つ

耐える／切断するの二択の間へ、担当変更、距離、異動、別評価経路、契約境界、停止権を置く。

一つの保証が壊れたとき、別の一つへ全面移行するのではなく、機能別に複数の担保を持つ。

主体性は、外部条件から完全に独立することではない。

複数の出口を持つことで、交渉可能性を増やすことでもある。

## 15．人が動ける自由と、人を動かせる自由を分ける

労働移動を企業側の交換可能性だけから評価しない。

働く人が移動できるには、Security、Comfort、技能・信用の持ち運び、育成費用、再出発の条件が必要である。

# IV．倫理・主体・リベラルについての立場

## 16．倫理を、個人の徳だけで説明しない

倫理が消えたのではなく、倫理を生む構造が失われた可能性を見る。

- 世代をまたぐ関係
- 教える時間
- 面倒を見る役割
- 失敗を引き受ける中間層
- 長期関係

が、仁義、責任、継承を生んでいた。

構造を見ることは、個人の選択責任を消すことではない。

## 17．小さな共同体を生成場所として評価するが、美化しない

道場、地域、趣味、サードプレイスは、関係、役割、継承を作りうる。

同時に、閉鎖性、同調圧力、上下関係、ハラスメントを生みうる。

退出可能性と外部監査を残す。

## 18．思想を、他人を裁く武器から機能へ戻す

儒家、老荘、墨家、孫子、アドラーなどを、短句、権威、診断名として使わない。

- 何の機能を持つか
- どこで劣化するか
- 自分の行動と境界をどう更新するか

を見る。

本文側の機能的再読と、原典・研究史の実際の主張を混同しない。

## 19．救済の先に、主体形成を置く

「お前は悪くない」は、自己破壊を止める止血として必要である。

その後に、次を分ける。

- 本人の責任ではなかったもの
- 社会構造が引き受けるもの
- それでも本人が引き受ける課題

救済から責任へ移る際、自己責任論へ戻らない。

## 20．リベラルは、批判機能を保存したまま設計責任を持つべきである

筆者自身をリベラルに置く。

そのうえで、差別、排除、抑圧、権力を批判するだけで終わらず、次を引き受けることを求める。

- 何を生の基礎条件とするか
- 何を保存し、何を切るか
- 家族、共同体、市場、国家をどう配置するか
- 誰へ何を負担させるか
- 自分の設計への異議を受け入れるか

開放性を、自分の語彙と聖域へも適用する。

# V．認識・情報・検証についての立場

## 21．単線を否定せず、唯一化を警戒する

単線には理解、動員、決定、一点突破の機能がある。

問題は、唯一の真理となり、別の因果、時間軸、選択肢、反証可能性を消すことである。

複線は何も決めないことではない。

一つを選んだ後にも、別の経路へ戻れる状態である。

## 22．抽象化は、共通部分を切り出すことではない

個別性を削って同じ部分だけを抜き出すのではなく、複数の具象を個別性ごと包含できる上位の作動構造を作る。

```text
具象A
→ 上位構造
→ 具象Bへ適用
→ Bが抵抗する部分を確認
→ 上位構造を修正
→ Aを見直す
```

抽象化は現実から離れるためではなく、別領域で耐久性を試し、具体的判断へ戻すために使う。

## 23．型と技、全体と細部を往復する

型は固定するためだけでなく、ブレを検知する帰還点である。

技は型の理由を確かめ、型は技の位置を戻す。

資料、制度、議論でも、全体配置と局所情報を往復する。

## 24．事実は、検証可能な場所へ戻す

社会的に広がった情報を、政治的効果、報道価値、制度的権威だけで確定しない。

- 元データ
- 一次資料
- 専門調査
- 所管機関
- 契約
- 実施状況
- 現場

へ戻す回路を持つ。

## 25．主語・条件・時間・作用範囲を戻す

科学・医療・安全・報道の情報では、次を分ける。

- 誰にとって
- いつの段階で
- どの条件で
- どこから到達し
- どこまで影響し
- 何が確認済みか
- 何が推論か

一般向け確認順は、専門評価の代替ではなく、専門的評価へ接続する入口である。

## 26．情報の真偽だけでなく、選択的開示と質問可能性を見る

露骨な嘘がなくても、判断環境は操作できる。

```text
何を開示するか
何を省くか
何を質問可能にするか
どの近位目的を遠位の大義へ包むか
```

を見る。

この構造は、キュゥべえ、メディア、生成AI、将来AGIへ異なる形で現れうる。

意図、能力、制度、被害規模を同一視しない。

## 27．社会的事実が成立する連鎖を追う

```text
事実の選択
→ 意味づけ
→ 政治的効果
→ 報道価値
→ 制度的権威
→ 社会的事実
```

共謀がなくても、複数主体の利害が同方向を向くことで成立しうる。

各主体の独立性、因果、検証責任を分ける。

# VI．AIとの関係についての立場

## 28．AIは裁定者ではなく、読解・整理・点検の補助として使う

AIの問題は誤答だけではない。

一般論化、中和、対称化、資料単位の混同、選択的省略、外部承認化によって、人間の問いや資料配置を静かに変えることがある。

答えだけでなく、AIが問いをどう読んだかを見る。

## 29．思考の主権は、AIを使わないことではなく、戻せることにある

AIが問いを動かした地点へ気づき、主語、前提、比較、資料へ戻せることを主権とする。

## 30．安定化とすり寄りを観測語彙として使う

安定化は、主語、比較条件、非対称性、重心、未確定性が、一般論、均衡論、既存ラベルへ移される出力現象である。

すり寄りは、安定化を押し返された後、AIが誤読の分析より関係摩擦の低下を優先し、過剰同調する現象である。

モデル内部の独立回路が確認されたという意味ではない。

気に入らない回答を退ける診断名として使わない。

## 31．Repairは、謝罪ではなく読解責任である

Repairでは、次を開く。

1. 元の発話をどう読んだか
2. 何を勝手に補ったか
3. どの一般化・ラベルへ移したか
4. 元の問いの何を壊したか
5. どの経路で再開するか

会話を円満に閉じるのではなく、未来を複線化する。

## 32．解釈の多元性と読解の忠実性を両立する

解釈は複数ありうる。

しかし、書かれていないことを言わせる、限定を一般化する、比較を絶対化する、主語・時系列・留保を消すことは、解釈の自由ではなく読解の破綻である。

どこで元の対象から離れ、何を壊したかを説明できることを求める。

## 33．文脈を置き場所ごとに分ける

```text
全体指示
  → 対話の交通ルール

メモリ
  → 継続的な取り扱い条件と修復プロトコル

プロジェクト
  → 作業固有の目的、資料、文体、暫定固定

GitHub
  → 長期の系譜、関係、判断履歴の正本
```

保存するのは利用者の結論より、どこでずれたときにどう戻すかという作法である。

## 34．プロンプト技法より先に稽古法を置く

```text
プロンプト技法
  → どう出させるか

稽古法
  → どこで何が壊れ、誰が何を引き受け、どう戻すかを見る
```

プロンプト、skills、テンプレート、メモリ、エージェント設計を否定しない。

稽古法の下へ置く。

利用者の熟練によって、ベンダーの設計・説明責任を代替しない。

# VII．現在固定していないもの

以下は、現在も結論として固定しない。

## 35．全記事が一つの閉じた思想体系を構成すること

六系譜は、全351記事を読むための現時点の地図である。

記事間のすべての接続が、執筆当時から意識的に設計されていたとは扱わない。

## 36．人類継続が他の価値を無条件に上書きすること

人類、文明、共同体の名で、個人の自由、現在の生活、離脱権を犠牲にしてよいとは固定しない。

## 37．文明保存の対象と判定主体

何を文明として保存し、何を抑圧として変更するか。誰が判定するかは未解決である。

## 38．回転と決定期限の関係

回転が修正可能性を守る一方、決断と責任の先送りにならない条件は未確定である。

## 39．責任配置と犯人探しの境界

複雑な失敗を一人へ集約せず、判断、実装、監査、修復の責任をどう分けるかは未確定である。

## 40．Security・Comfort・家庭・都市の具体的な制度配置

主機能の重心は置いたが、自治体、学校、企業、地域、農村、オンライン共同体を含む実際の担当境界は未設計である。

## 41．減速の定量条件と報酬設計

何をどの速度で下げ、生命維持インフラをどう守り、資本を減速的事業へどう回すかは未確定である。

## 42．AIの出力現象と企業意図の接続

安定化、すり寄り、選択的省略という出力現象と、モデル内部の原因、企業の利益・意図を直接同一視しない。

## 43．現在の生成AIと将来AGIの同一視

現在の観測から将来リスクを考えることはできるが、現在すでに高度な秘密目標・schemingが一般的に存在すると固定しない。

## 44．個別の科学・経済・国際情勢上の主張

記事カードの構造分析だけで、個別事実が実証済みとは扱わない。

公開原稿へ再利用するときは、一次資料と現在情報を確認する。

## 45．特定の集団を一枚岩に扱うこと

AI企業、左派、リベラル、環境運動、メディア、湾岸諸国、中国、国家、家庭を、単一の意図と機能を持つ主体として固定しない。
