# Security・帰還可能性モデル――非崩壊、退出、再出発を分ける

更新日：2026-06-24

## このファイルの役割

Securityを「安心感」や一つの給付制度へ縮めず、社会の非崩壊、個人の退出、回復、別の配置への再接続として分解する。

## 1．安心の三つの意味

### 主観的安心

危険や不安をあまり感じない心理状態。

### 非崩壊の保障

危機が起きても、生活・制度・社会が致命的崩壊へ落ちないこと。

### 行動可能性としての床

失敗・離職・移動・関係変更のあとも、立ち止まり、別の選択を試し、再参加できること。

制度は主観的安心を完全には約束できない。制度上の目標は、非崩壊と選択可能性である。

## 2．Securityの五段階

```text
非崩壊
→ 停止
→ 退出
→ 帰還・回復
→ 再参加
```

### 非崩壊

生命、住居、医療、所得、基盤が直ちに破局へ落ちない。

### 停止

危害・過負荷・行き過ぎを止められる。

### 退出

職場、関係、地域、制度から離れられる。

### 帰還・回復

生活と判断能力を回復し、選択肢を再評価できる。

### 再参加

元の場所に限らず、別の仕事・地域・役割・共同体へ接続できる。

## 3．安心を約束しない

国家基盤は次を保証できない。

- 事故が起きない
- 戦争や災害が起きない
- 損失がない
- 不安を感じない
- すべての人が成功する

約束すべきなのは次である。

- 破局を避ける最低線
- 守れる範囲と限界の表示
- 負担の可視化
- 行き過ぎを止める権限
- 失敗後の修復
- 再出発の入口

限界表示は保障放棄ではない。修正可能な保障の条件である。

## 4．専門知と民主的制御

### 専門家

手段、仕様、リスク、代替案、運用、修復計画を設計する。

### 政治・市民

目的、守る範囲、優先順位、負担上限、停止条件、見直し時期を共有する。

```text
手段の専門委任
≠ 目的と制御点の白紙委任
```

民主主義は、全員が細部を決めることではなく、行き過ぎを止め、目的へ戻し、負担を再配分できる状態である。

## 5．帰還可能性

帰還は元の状態へ戻ることだけではない。

```text
元の場所へ戻る
または
別の場所へ再接続する
```

ことを含む。

必要な要素：

- 失敗を致命傷にしない
- 一度止まれる
- 生活を維持できる
- 状態を回復できる
- 別の選択を試せる
- 再参加を拒まれ続けない

## 6．帰還可能性の七層

| 層 | 必要な機能 |
|---|---|
| 所得 | 空白期間の最低生活 |
| 住居 | 離職・離婚・移動後の居場所 |
| 医療・ケア | 所属変更後も切れない支援 |
| 学習 | 別の役割へ移る技能 |
| 移動 | 地域・職場・関係を変える能力 |
| 経歴・資格 | 失敗や空白を永久の排除理由にしない |
| 関係・所属 | 相談・承認・参加の新しい入口 |

一層だけでは不十分である。

## 7．能力を関係として見る

```text
能力の現れ方
＝ 個人の技能
× 環境
× 役割
× 時期
× 支援
× 関係
```

一つの環境での失敗を人格全体へ拡張しない。

ただし環境要因を認めることは、本人の技能・選択・責任を消すことではない。変更可能な条件を分離することである。

## 8．安心の床

安心の床が保障するのは結果ではない。

```text
成功保証
ではなく
試行可能性
```

である。

- 休止できる
- 別案を試せる
- 学び直せる
- 失敗後も生活が続く
- 再参加できる

ベーシックインカムは一候補だが、所得以外の層を代替しない。

## 9．制度経路

```text
危害・不適合を認識
→ 停止
→ 退出
→ 生活維持
→ 回復・再評価
→ 試行
→ 再参加
```

各段階の責任主体と接続方法を明示する。

制度が存在しても、申請不能、情報不足、経歴差別、住居喪失などで経路が切れれば実質的自由はない。

## 10．責任配置

### 国家・自治体

非崩壊の最低線と、退出から再参加までの基盤を用意する。

### 政治

守る対象、優先順位、負担、停止条件を決め、限界を説明する。

### 専門家

手段とリスクを提示し、目的を独占しない。

### 企業・組織

休職、配置変更、退職後の再応募、学び直しを人格評価から切り離す。

### 支援機関

所得、住居、医療、学習、就労の制度間断絶をつなぐ。

### 個人

床を成功保証や判断の外注とせず、試行・再評価へ使う。

## 11．指標候補

- 退出までに必要な期間
- 退出後の所得・住居・医療の継続率
- 空白期間後の再就業・再参加率
- 配置変更の利用可能性
- 再応募・学び直しへの制度障壁
- 失敗後の債務・健康・関係悪化
- 保障限界と停止条件の認知度
- 異議申立てから再審査までの時間

主観的安心度だけで評価しない。

## 12．故障形

### 安心の過剰約束

限界・負担・優先順位を隠し、想定外で修正不能になる。

### 床の不足

退出できず、合わない配置に留まり続ける。

### 所得だけの床

住居・医療・学習・所属の断絶が残る。

### 帰還先の固定

元の場所へ戻ることだけを回復とし、別配置への再接続を認めない。

### 無期限の試行

再参加の入口や負担上限がなく、保留状態が固定される。

### 安心感の演出

実質的な停止・退出権がないまま、相談や励ましだけを提供する。

## 13．AIとの関係

AIは思考の試行空間を補助できる。

- 言葉の外化
- 案の比較
- 再記述
- 低コストの練習

しかし、所得・住居・医療・配置変更・再参加を保障しない。

AIによる心理的な安心感を、制度上の帰還可能性と混同しない。また、整えすぎ、迎合、外部承認化によって判断可能性を削る危険を監査する。

## 14．未解決問題

1. 非崩壊の最低線を誰が決めるか。
2. 保障限界を正直に示しながら、排除や恐怖を増やさない方法は何か。
3. 七層の保障をどの制度・主体へ分担するか。
4. 退出後の空白を経歴上の欠陥にしない方法は何か。
5. 試行可能性と負担上限をどう両立するか。
6. 再参加を拒否された人の異議申立てをどう保障するか。
7. 環境不適合と技能不足・差別・健康問題をどう切り分けるか。
8. 主観的安心と実質的選択可能性の差をどう測るか。
