# 第D段階――犠牲を固定しない継続設計

更新日：2026-06-24

> **状態：準備稿・未開始**
>
> 現在の作業は `roadmaps/PHASE_B2_KEY_ARTICLE_SELECTION.md` である。横断再構築で重要性が判明した記事を選び、記事単位の根拠・修正・抵抗点を確認した後に、この第D段階へ進む。

## この段階の位置づけ

第A段階では351記事を収集し、第B段階では縦読みと横断再構築を行い、第C段階では新着・更新を継続的に取り込む運用を作った。

第B-2段階では、横断再構築によって重要性が見えた記事だけを選び、必要な詳細カードを増やす。

第D段階は、その選定と詳細化を終えた後に開始する。

第D段階では、過去記事の整理を主目的にしない。

```text
重要記事の選定・詳細化
→ 記事単位の根拠・修正・抵抗点を確認
→ 六系譜・現在地・未解決問題を必要に応じて修正
→ 整理された概念から未解決の緊張を選ぶ
→ 規範・事実・制度・運用へ分解する
→ 具体的な設計原理を作る
→ 異なる領域へ適用する
→ 抵抗した具象で原理を修正する
→ 新しい記事・研究・道具へ戻す
```

過去の思想を閉じた体系にするのではなく、次の思考を発生させる研究プログラムへ移す。

---

# 1．中心研究課題

> 必要な機能を継続させながら、その維持コストを現在の個人・家庭・現場へ固定しない設計は可能か。

この問いは六系譜を貫く。

- 人類継続・文明保存：何を次へ渡すのか。
- 保存・再設計・回転：どのように変え続けるのか。
- Security・Comfort・内部条件：維持費用を誰が担うのか。
- 倫理・主体・共同体：責任を担える主体はどこで生まれるのか。
- 検証・抽象化・情報：何を根拠に設計し、誤りをどう発見するのか。
- AI・読解・Repair：問いと修復回路をどう維持するのか。

六本を並列テーマとして扱わず、継続設計の異なる必要条件として再配置する。

---

# 2．次の段階で解くべき四つのボトルネック

## 2-1．継続の内容

人類継続を、種の生存だけで定義しない。

最低限、次を継続の内容として検討する。

- 現在の個人の自由と尊厳
- 共同体から離脱する権利
- 文明・生活様式・知識の複数性
- 制度を批判し修正する能力
- 次世代が別の選択をできる余地

中心問題：

```text
継続確率を上げる
≠
現在の人間を未来の資源にしてよい
```

## 2-2．維持費用と責任の配置

制度・市場・組織・家庭が機能するとき、その内部費用を可視化する。

- 誰が決めるか
- 誰が利益を得るか
- 誰が待機するか
- 誰が失敗を吸収するか
- 誰が修復するか
- 誰が次へ継承するか

中心問題：

```text
権限のない責任
→ 人を壊す

責任のない権限
→ 制度を腐らせる
```

## 2-3．決定と修正の両立

修正可能性を残すことが、決定回避や永久保留へ変わらない制度を作る。

必要項目：

- 決定期限
- 決定主体
- 実装責任
- 成功・失敗条件
- 見直し日
- 停止・撤回条件
- 退出経路
- 修復責任

中心問題：

```text
一度は決める
＋
決定を真理にしない
```

## 2-4．認識環境の設計

嘘か真実かだけでなく、判断可能性を誰が構成しているかを見る。

- 何が開示されたか
- 何が省かれたか
- 何が質問可能だったか
- 誰の言葉に権威が付いたか
- どの情報が検証可能な場所から離れたか
- どの近位目的が遠位大義へ包まれたか

中心問題：

```text
情報を与える
≠
判断条件を保障する
```

# 3．研究プログラムの四本柱

## 柱A．継続の規範核

### 目的

人類継続・文明保存・生活継続の関係を明示し、遠位大義による現在の資源化を防ぐ。

### 主な問い

- 継続に含める不可欠な価値は何か。
- 文明保存と抑圧の固定をどう分けるか。
- 継承しない自由を保存の中へ含められるか。
- 保存対象を決める主体をどう多元化するか。

### 成果物

- 継続設計の規範原則
- 文明保存の監査項目
- 離脱権と継承権の対応表
- 遠位目的・近位目的・現在負担の分離様式

## 柱B．制度の作動核

### 目的

保存・再設計・回転を、思想的比喩から制度運用へ降ろす。

### 主な問い

- 必要機能を誰が認定するか。
- 再設計者が新しい上位権力にならない条件は何か。
- 回転に期限・責任・停止条件をどう持たせるか。
- 翻訳層の権力をどう監査するか。

### 成果物

- 保存・再設計・回転の判定表
- 責任配置マトリクス
- 決定ログの最小仕様
- 語る場・翻訳層・決める場・監査の運用モデル

## 柱C．生活と経済の内部条件

### 目的

Security・Comfort・内部SLA・減速を、生活者が使える制度と指標へ変換する。

### 主な問い

- 国家・自治体・都市・企業・家庭の担当境界をどう置くか。
- 移動しても失われないSecurityをどう作るか。
- Comfortを一つの正解へ固定せず、選択可能にする方法は何か。
- 速さ・安さ・便利さを支える内部資源をどう価格・契約へ戻すか。
- 資源回転を下げる企業へ、どの報酬を与えるか。

### 成果物

- Security・Comfort責任配置表
- 内部SLAテンプレート
- 悪い安さを判別する点検表
- 減速指標と報酬構造の仮説
- 移動可能なSecurityの制度案

## 柱D．情報・AI・修復の統治

### 目的

検証可能性、質問可能性、社会的事実、Repairを、情報環境の監査と再設計へ降ろす。

### 主な問い

- 事実が権威化される連鎖をどこで反転できるか。
- 自発的開示と情報過多をどう分けるか。
- AIが問いを動かした地点をどう記録するか。
- 利用者の熟練とベンダー責任をどう分けるか。
- Repairを会話技法から組織・制度の修復手順へ広げられるか。

### 成果物

- 質問可能性監査
- 社会的事実の逆流設計
- AI読解差分ログ
- Repairプロトコルの組織版
- 出力現象・モデル原因・企業意図の分離表

# 4．進める順序

四本柱を同時並行で始めない。

## 第D-0段階――規範核と禁止事項

最初に、何を守るかと、何をしてはならないかを固定する。

作るもの：

1. 継続設計の核
2. 遠位大義による資源化の禁止
3. 最終処理場化の禁止
4. 離脱権・修正権・異議申立権

この段階を飛ばすと、制度案が効率的な犠牲配分へ変わる。

## 第D-1段階――責任・決定・退出の基本部品

作るもの：

1. 責任配置マトリクス
2. 決定ログ
3. 停止・撤回・再開条件
4. 退出可能性の設計
5. 翻訳層の監査

## 第D-2段階――三つの具体領域へ適用

最初から文明全体へ適用しない。

### 適用領域1：組織と仕事

- 外部品質と内部SLA
- 現場中核層の最終処理場化
- 効率化の果実
- 権限と責任

### 適用領域2：都市と生活圏

- SecurityとComfort
- 家庭外のケア・文化・居場所
- 移動可能性
- 小共同体と退出権

### 適用領域3：メディアとAI

- 情報選択
- 質問可能性
- 社会的事実
- Repair
- ベンダー責任

三領域で耐えた原理だけを文明・国際秩序へ戻す。

## 第D-3段階――減速と文明保存の実装

D-0〜D-2で作った原理を、資源、エネルギー、物流、人口、国際制度へ適用する。

ここで初めて、減速の定量条件、報酬構造、文明保存型国際制度を扱う。

# 5．最初に作る六つの成果物

優先順位順。

## 1．継続設計の核

仮題：

> 人類が続くとは、何が残ることなのか

目的：生存、自由、文明多様性、修正可能性、離脱権の関係を固定する。

## 2．犠牲固定化の検出表

仮題：

> 社会は、誰を最後の処理場にしているのか

目的：家庭、現場、下請け、将来世代、環境への負担外部化を検出する。

## 3．責任配置マトリクス

仮題：

> 誰が決め、誰が負担し、誰が直すのか

目的：決定・実装・説明・監査・修復・継承を分ける。

## 4．検証可能な暫定決定

仮題：

> 決める。しかし、真理にはしない

目的：保存・再設計・回転を、期限と撤回条件を持つ手順へ変える。

## 5．Security・Comfort配置表

仮題：

> 安心は、誰がどこまで担うのか

目的：国家、自治体、都市、企業、家庭、市場の役割を具体化する。

## 6．社会的事実の逆流設計

仮題：

> 事実らしさを、検証可能な場所へ戻す

目的：メディア、政治制度、専門家、AIを通じた権威化の連鎖を反転する。

# 6．記事化の順序

最初から大著や体系書を作らない。

```text
設計メモ
→ 具体例への適用
→ 反例・限界
→ 修正版
→ 一般読者向け記事
```

各テーマについて、少なくとも次の三稿を分ける。

1. **核となる主張**：何を提案するか。
2. **抵抗する具象**：どこで提案が壊れるか。
3. **再設計稿**：壊れた点をどう修正したか。

統合稿だけを公開すると、思考の成立順と棄却した読みが消えるためである。

---

# 7．調査の精度区分

各成果物では、次を混同しない。

## 規範

何を守るべきかという本文側の判断。

## 構造仮説

複数の具象を説明するために作った上位構造。

## 制度案

役割、手順、権限、指標、契約へ降ろした提案。

## 事実主張

研究、統計、一次資料、実施状況による確認が必要な内容。

## 推論

確認済み事実から本文が押し広げた範囲。

記事末の補記では、既存研究が扱う範囲と本文独自の展開を分ける。

---

# 8．研究を止める条件

次の状態になった場合、体系化を進めず一度戻る。

- 六系譜へすべてを回収し、抵抗する具象が見えなくなった。
- 「人類継続」が反論不能な大義として使われた。
- 保存対象の判定主体が曖昧なまま制度案が進んだ。
- 責任配置が犯人探しへ変わった。
- 回転が決定回避の言い換えになった。
- Securityが固定雇用・固定居住への服従になった。
- Comfortが正しい生活様式の強制になった。
- 減速が貧困層への我慢の要求になった。
- AI利用者の熟練がベンダー責任の代替になった。
- 研究紹介が本文を権威づける飾りになった。

---

# 9．完了条件

第D段階の完了は、記事本数では測らない。

次を満たしたとき、初版完成とする。

- 継続の内容と禁止事項が明文化されている。
- 責任配置・決定・退出・修復の基本部品がある。
- 組織、都市、情報環境の三領域で適用と修正を行った。
- 適用で壊れた原理を記録している。
- 減速と文明保存を、規範だけでなく指標・報酬・制度へ接続した。
- 一般読者が自分の生活・職場・地域へ持ち帰れる確認順がある。

# 10．開始条件

第D段階は、第B-2段階で次を満たした後に開始する。

- 六系譜の主要な初出・転換・修正が記事単位で確認されている。
- 後期統合稿の前史が追える。
- 現在の体系へ抵抗する記事が選ばれている。
- 未解決問題へ必要な記事が詳細化されている。
- 第D段階の前提に、記事単位の根拠と反例がある。
