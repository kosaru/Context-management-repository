## 本文コーパスについて

エクスポートXML原本と、そこから生成した本文JSONLは、現時点ではGit履歴へコミットしていない。

理由は次の通り。

- 原本を無条件にGit履歴へ残さないという運用方針を維持するため
- 本文コーパスの保存単位と更新方法を確定してから追加するため
- 解析結果と原資料を混同しないため

`import_note_export.py`を実行すると、月別・分割された`YYYY-MM-partNN.jsonl`を生成できる。各行は1記事で、note ID、タイトル、URL、公開日時、更新日時、本文Markdown、本文ハッシュ、画像参照数を持つ。

## 正本の扱い

- 公開中の最新本文：note公開ページ
- 初期全体分析の入力：ユーザー提供のnoteエクスポートXML
- 文脈・系譜・現在地：GitHub上の記事カードと索引
- 新着・更新検出：全体分析完了後の定期スクレイピング

## 注意

- 画像本体はXMLへ含まれていない。画像が論旨に必要な記事だけ別途紐づける。
- エクスポート日時点の本文と、公開ページの後日の修正には差が生じうる。
- 解析済みカードは本文更新だけで自動上書きしない。
