# 思考の主権

> 公開本文の正本：https://note.com/shirokuma1970/n/n0558bfba8335
>
> このファイルは文脈解析用の取得時スナップショットです。

みんなが同じ方向を向くこと自体は、問題ではないと思っている。  
ただ、それが「考えた結果」であってほしい。

情報はますます親切になり、  
複雑なものは整理され、  
立場は選びやすくなった。

そのこと自体は悪くない。

けれども、もし私たちが  
考える前に立場を受け取っているのだとしたら。

私は、正解を示したいわけではない。  
ただ、思考の主権が静かに外側へ置かれていくことに、  
少しだけ違和感がある。

それぞれが、自分で考えたと  
言える状態であればいい。
