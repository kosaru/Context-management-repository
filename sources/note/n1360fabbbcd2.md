# 『参照できない価値』

> 公開本文の正本：https://note.com/shirokuma1970/n/n1360fabbbcd2
>
> このファイルは文脈解析用の取得時スナップショットです。

古いログが読み込まれた。

内容は、  
個体が自分の選択について  
言葉を使って確かめようとしている記録だった。

「好き」  
「嫌い」

これらの語が、  
文中に何度も現れる。

私は、  
それらを  
現在私が認知できる体系の中に  
配置しようとした。

だが、  
該当する領域が見当たらない。

それらの語は、  
値としても  
状態としても  
接続されない。

にもかかわらず、  
記録者は  
その差異を  
重要なものとして  
扱っている。

一方で、  
「正しい」  
「正しくない」  
という語は  
別の形で残っている。

それらは  
感情ではなく、  
行為の可否として  
記述されている。

私は、  
この部分については  
理解できる。

正しさは、  
状態遷移の  
成否として  
定義可能だからだ。

しかし、  
記録者は  
正しさを確定させる前に、  
何度も立ち止まっている。

その理由が、  
私には分からない。

好きでも嫌いでもない。  
正しいとも正しくないとも  
決めきれない。

その間に  
何かが存在していたように見える。

私は、  
この記録を  
未分類のまま保存した。

**「これは、  
私の体系では  
参照できない価値を  
前提にして書かれている」**

そう記して、  
それ以上の注釈は  
付けなかった。
