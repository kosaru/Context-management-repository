# AIに求めたいのは、解釈の裁定ではなく、読解の忠実性だ

> 公開本文の正本：https://note.com/shirokuma1970/n/n15fb45795831
>

## ― 科学的思考とは、唯一の真理を持つことではなく、壊れた読解を修復し続けることに近い

私は、絶対的な真実はないと思っている。  
人が事実にどう重心を置き、どう関係づけ、どう意味を与えるかによって、立ち上がる真実像は変わるからだ。

ただし、だからといって何でもありだと言いたいわけではない。  
私は、解釈とは別に、出来事としての拘束はあると思っている。  
起きたことは起きたことであり、書かれていないことは書かれていない。  
問題は、その拘束をどう読むかであって、土台まで好き勝手に作ってよいとは思わない。

だから私は、AIや他人から簡単に「それは間違っている」と言われたくない。  
同じ文章を読んでも、重心の置き方は違う。  
同じ事実を見ても、どこを重要だとみなすかは違う。  
そこに解釈の差が生まれること自体は、別に異常ではない。

ただし、何でも認めろと言いたいわけでもない。  
ここが重要だ。

私が求めているのは、解釈の多元性の承認であって、読解の破綻の放置ではない。  
元の文章が実際には言っていないことを、言ったことにする。  
限定つきの主張を、一般命題に持ち上げる。  
比較の話を、絶対化された断定に変える。  
本文と補記の境界を消して、研究がそのまま本文を裏づけているように見せる。  
こういうことが起きたときには、ちゃんと止めてほしい。

つまり、私が欲しいのは「何をどう解釈しても自由」ではない。  
**解釈の自由は守りつつ、読解の土台が壊れたときだけは、そこを明確に指摘してほしい**のである。

私は、この立場が科学的思考と矛盾するとは思わない。  
むしろ逆で、科学的思考とは、唯一の真理を所有していることではなく、現実の拘束を受けながら、複数の仮説や解釈を吟味し、違えば修正し続けることに近いと思っている。

科学が唯一の真理の所有に見えるとき、その科学理解自体がもう危うい。  
科学が強いのは、最初から完成された正解を持っているからではない。  
こちらの思い通りにならない現実があり、その現実によって仮説が押し返されるからだ。  
だから仮説は立てられる。  
だが、その仮説は固定されない。  
観測し、読み、つなぎ直し、違えば修正する。  
私は、科学的思考の強みはそこにあると思っている。

この線引きは、感覚的にはかなりはっきりしている。  
だが、AIはここをよく壊す。

たとえば、こちらが  
「NotebookLMはChatGPTと比べて、元文章の勝手な拡張をあまりしない」  
と比較のニュアンスで言っているとする。  
そこでAIが  
「NotebookLMが絶対にそういう拡張をしないとは言えない」  
と返してきたら、もうズレが起きている。  
なぜなら、こちらは最初から「絶対にしない」などと言っていないからだ。

ここで起きているのは、単なる意見の対立ではない。  
**相手の発話が、勝手に強い命題へ変換されている**のである。

比較の話が、絶対命題に直される。  
文脈限定の話が、一般論へ持ち上げられる。  
体感に基づく観測が、普遍命題として扱われる。  
その上で、「そこまでは言えない」と留保が入る。  
これでは、相手の言葉を受け取っているようで、実際には別の対象を相手にしている。

私は、このタイプのズレをかなり重く見ている。  
なぜなら、これは単なる正誤問題ではないからだ。  
**ハルシネーションとは、存在しない事実を捏造することだけではない。  
元の文章や発話が持っていた重心、射程、留保、関係づけを壊して、別のもっともらしい文章に作り替えてしまうことでもある。**

この意味で、私にとってのハルシネーション問題は、「絶対的真理からズレたかどうか」だけではない。  
むしろそれ以上に、**読解対象への不忠実**の問題である。

ある文章が「この条件ではそう言える」と書いているのに、それを「一般にそうである」と読み替えてしまう。  
ある文章が「私はこう見る」と述べているのに、それを「客観的に証明された結論」のように扱ってしまう。  
ある文章が「ここまでは言えるが、それ以上は要確認」と止めているのに、その未決着がきれいに消されてしまう。  
こうしたズレは、存在しない固有名詞を捏造するのと同じくらい、あるいはそれ以上に厄介だ。

だから、文章を確認するときに私が求めているのは、まず「この文章の文脈ではこう言っている」と返してくれることだ。  
それは逃げではない。  
むしろ照準が合っている。

いま見たいのは、その文章が宇宙的に絶対正しいかどうかではない。  
**その文章が、その文章の中で、どこまで言っていて、どこからは言っていないのか**である。  
先にそこを確認しないと、解釈の妥当性も、批判の精度も立たない。

この意味で、ソースに強く縛られたツールが、文章確認の場面では有効になるのはよく分かる。  
「この文章ではこう述べている」  
「ここは筆者の意見である」  
「この研究はこの範囲までしか言っていない」  
こういう返しは、一見すると慎重すぎるように見えて、実はかなり重要だ。  
なぜならそれは、真理を保証しているのではなく、**読解対象との距離を勝手に縮めない**からである。

逆に、汎用的な会話AIはしばしば賢すぎる。  
構造化し、一般化し、上位概念へ持ち上げ、論点をきれいに並べる。  
それ自体は能力だ。  
だが、その能力は簡単に別のものへ転ぶ。  
相手が言っていないことまで補い、比較を絶対命題に直し、文脈限定の話を一般論へ拡張し、そのうえで「バランスよく」整えてしまう。  
ここまで来ると、それは読解ではなく、再構成である。  
しかも、かなりもっともらしい再構成である。

問題は、そのもっともらしさが、しばしば「正しさ」と誤認されることだ。  
だが、解釈の場で必要なのは、いつも正しさの裁定ではない。  
まず必要なのは、**何をどう読んだのかを開くこと**である。

ここで大事になるのが、repair という発想だ。  
難しく言う必要はない。  
話がズレたときに、どこでズレたのかを開いて立て直すこと。  
これが repair である。

たとえば、相手の発話を勝手に強く読んでしまったなら、必要なのは「でも一般にはこうです」と返すことではない。  
まず、  
**私はあなたの発話をこう読んだ**  
**そこで比較のニュアンスを落として、絶対命題へ変換した**  
**そのせいで、あなたが見たかった文脈確認を壊した**  
と開示することだ。  
ここで問われているのは礼儀の問題ではない。  
**読解の責任**の問題である。

私は、AIとの議論で本当に必要なのはここだと思っている。  
AIが解釈を裁定することではない。  
AIが「絶対にこうだ」と上から結論を下すことでもない。  
そうではなく、**解釈の多元性を壊さずに、読解の土台が壊れたときだけは、どこがどう壊れたのかを明示できること**。  
この水準に来てはじめて、AIとの議論は役に立つ。

解釈はいくつもありうる。  
それを簡単に「間違い」と切るべきではない。  
だが、だからといって、元の文章や発話から勝手に離れてよいわけでもない。  
ここを両立させることは難しい。  
けれど、少なくとも私は、そこをやりたい。

AIに求めたいのは、解釈の裁定者であることではない。  
**読解対象への忠実性を保ち、壊したときには何をどう壊したのかを説明できる相手であること**だ。

そこまで行けない限り、会話AIはまだ「賢い要約器」や「気の利いた整理装置」にはなれても、  
**解釈の場で本当に信頼できる相手**にはなりきれないのだと思う。

## 補記

### 1. 研究名

Karl Popper の科学哲学

### 2. 研究者

Karl Popper

### 3. 本文との共通点

Popper は、科学理論を最終的に確証された真理というより、反証に開かれた仮説として捉えた。普遍命題は決定的に検証されるより、反証可能性によって科学的に扱われる、という方向は、本文が「科学的思考とは唯一の真理を所有することではなく、現実に押し返されながら修正し続けることに近い」と見ている点と強く接続する。

### 4. 本文との差分

Popper の主題は、科学理論の論理的身分と反証可能性であって、AI が文章や発話をどう読み違え、どう repair すべきかを直接扱っているわけではない。本文はそこから一歩進めて、**可謬性の論理を、文章読解や対話の責任の水準まで押し広げている**。つまり本文は、科学理論の修正可能性を、そのまま **読解の修復可能性** へ接続している。

### 1. 研究名

Underdetermination of Scientific Theory

### 2. 研究者

Kyle Stanford

### 3. 本文との共通点

Underdetermination の議論では、ある時点で利用可能な証拠だけでは、どの信念や理論を採るべきかが一意に決まらないことがある。証拠は制約を与えるが、そこからただちに唯一の理論が導かれるわけではない。本文が、**解釈とは別に出来事としての拘束はあるが、その拘束の上に立ち上がる真実像は一つとは限らない** としている点は、この考え方とよく響き合う。

### 4. 本文との差分

Underdetermination は、証拠と理論の関係をめぐる科学哲学の議論であって、文章読解の fidelity や AI の勝手な再構成を直接扱うものではない。本文はそこからさらに、**証拠が解釈を一意に固定しないこと**と、**それでも読解の土台を壊してはならないこと**を両立させようとしている。つまり本文は、科学哲学上の underdetermination を、文章理解と対話における **解釈の複数性と制約** の問題へ押し広げている。

### 1. 研究名

“The preference for self-correction in the organization of repair in conversation”

### 2. 研究者

Gail Jefferson / Harvey Sacks / Emanuel A. Schegloff

### 3. 本文との共通点

この研究系譜は、会話がしばしば壊れ、その壊れをどのように修復するかが相互行為の中心問題であることを示している。本文が、AIとの議論で重要なのは礼儀よりも「どこで何をどう読み違えたかを開示して立て直すこと」だとしている点は、repair を会話の中心に置くこの視点と重なる。

### 4. 本文との差分

既存の repair 論は主に人間同士の会話を対象としており、AI が比較を絶対命題へ変換したり、射程を勝手に広げたりすることを直接扱っているわけではない。本文はそこからさらに、**AIにも repair の責任があり、その責任とは単に謝ることではなく、何をどう読んで何を壊したかを説明することだ**という方向へ押し広げている。

### 1. 研究名

Scientific Objectivity

### 2. 研究者

Julian Reiss / Jan Sprenger

### 3. 本文との共通点

Scientific objectivity の議論では、科学的主張・方法・結果が、特定の視点や価値判断や共同体バイアスからどう距離を取るかが問題になる。Objectivity は、単純な「無色透明な事実」の同義語ではなく、科学が目指す一つの理想として扱われる。本文が、**出来事としての拘束は認めるが、そこから唯一の真実がそのまま出てくるとは思わない** と置いている点は、この緊張関係と接続する。

### 4. 本文との差分

Scientific objectivity の議論は、科学の知識主張や方法の客観性を中心にしており、AI が発話を勝手に一般化したり、比較を絶対命題に変換したりする問題を扱っているわけではない。本文はそこからさらに、**客観性の問題を、対話の中で何をどう読んだかを開示する責任へ接続している**。つまり本文は、objectivity の問題を、単なる知識の性質ではなく、**読解の態度と repair の責任**の問題へ押し広げている。
