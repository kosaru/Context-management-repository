# メディアをハブとした情報の流れについて（メモ）

> 公開本文の正本：https://note.com/shirokuma1970/n/n1d84d75c28ea
>
> このファイルは文脈解析用の取得時スナップショットです。

社会は直接つながっているようでいて、  
実際には多くの媒介を経由している。

政治も、経済も、企業も、研究者も、  
市民に届くときには、何らかの編集を通る。

その中心にあるのがメディアだ。

メディアは単なる通路ではない。  
選び、整理し、順序を与え、強弱をつける。

情報はその過程で意味を持つ。

だから、メディアは「発信者」でもあり、  
同時に「翻訳者」でもある。

しかしそれだけではない。

メディアは他のメディアを参照し、  
SNSはメディアを引用し、  
政治家はメディアを意識して発言する。

情報は直線ではなく、循環している。

発信 → 編集 → 受信 → 反応 → 再編集。

メディアはその循環のハブに位置している。

ハブは力を持つが、孤立してはいない。

広告主、読者、視聴者、アルゴリズム、  
それぞれがメディアに影響を与える。

つまりメディアは、  
外から社会を観察する存在ではなく、  
社会の回転の一部である。

この構造が見えるとき、  
対立は単純な善悪ではなく、  
複数の力が交差する動きとして見えてくる。

責任とは、正しさの宣言ではない。

自分がどの位置に立ち、  
どの力を通し、どの力を弱めているのかを  
自覚することだ。

メディアをハブとした情報の流れは、  
止まらない。

止めることもできない。

だが、その流れをどの角度で映すかは、  
常に選択されている。

その自覚があるかどうか。

そこに、誠実さの差が生まれる。
