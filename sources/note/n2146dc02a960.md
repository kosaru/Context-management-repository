## 戦争は、大量生産・大量消費の究極系ではないか

ここでは戦争を、一度物質の流れとして抽象化してみたい。

戦争では、大量の資源を掘る。

大量のエネルギーを使う。

大量の兵器を作る。

大量の人間と物資を移動させる。

使う。

壊す。

失う。

また作る。

相手の都市や工場やインフラも壊す。

そして戦争が終われば、それを再建する。

つまり、

**採取  
→ 生産  
→ 使用  
→ 破壊  
→ 再生産**

という物質の循環を猛烈な速度で回す。

平時の大量生産・大量消費は、

**採取  
→ 生産  
→ 販売  
→ 消費  
→ 廃棄  
→ 買い替え**

である。

もちろん、戦争と一般消費が同じだと言っているのではない。

人間の殺傷を伴う戦争には、消費社会とはまったく異なる政治的・倫理的問題がある。

ここで見ているのは、

**大量の物質を取り込み、短期間で使い切り、次の物質を投入し続ける文明の回転**

である。

その意味で、戦争は大量生産・大量消費の究極系と見ることができる。

近代の総力戦が実際に国家規模の生産・資源動員を必要としたことは歴史的にも確認できる。

第二次世界大戦では、兵器・燃料・原材料・輸送能力・工業生産そのものが戦争へ大量投入された。

戦争は、文明の物質回転を異常な速度まで上げる。
