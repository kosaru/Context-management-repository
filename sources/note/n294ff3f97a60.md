# 尊厳と技術が両立する産業構造へ

> 公開本文の正本：https://note.com/shirokuma1970/n/n294ff3f97a60
>
> このファイルは文脈解析用の取得時スナップショットです。

日本の産業構造を考えるとき、「空洞化」という言葉が浮かぶ。  
だが本当に怖いのは、工場が海外に移ることそのものではない。技術が静かに失われていくことだ。

技術は単なる生産手段ではない。  
図面やデータだけでは伝わらない現場の感覚、素材の癖を読む経験、妥協しない美意識の積み重ね。そこには身体性があり、世代を超えて継承される文化に近いものがある。

同時に、国家にとって技術は戦略資源でもある。  
この二面性をどう扱うかが、これからの産業構造を考えるうえで重要だと思う。

中小企業の技術継承問題は、その核心にある。  
価格転嫁が適切に行われず、投資余力が生まれない環境では、若い世代が技術を継ぐ動機を持ちにくい。尊厳が損なわれれば、技術はやがて途絶える。

だからといって、単純な保護や補助で延命することが解決策だとは思わない。  
市場を壊す必要もない。

必要なのは、尊厳を損なわない最低限のルール整備だ。  
下請法の実効性を高め、価格転嫁が正当に行われる環境を整えること。取引の透明性を確保し、交渉力の非対称が固定化しないようにすること。

それは価格統制ではない。  
競争を止めることでもない。  
フェアネスを確保するための、控えめだが確かな構造補正にすぎない。

尊厳を守ることと経済成長は、必ずしも対立しない。  
正当な対価が支払われ、技術への投資が可能になれば、更新が進み、競争力はむしろ強まる。短期的な摩擦はあっても、長期では補完関係になり得る。

技術は保存すべき遺産ではなく、更新され続ける文化だ。  
その文化が誇りを持って継承される環境を整えること。  
それが結果として、国力の基盤を支える。

市場を維持しながら、尊厳を失わせない。  
競争を保ちながら、技術を消耗させない。

両立は可能だと、私は考えている。  
少なくとも、不可能だと決めつける理由はない。

まずは、その可能性を諦めないでいたい。
