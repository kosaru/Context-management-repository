# 安心を約束しないという選択

### ――国家基盤と民主主義についての覚書

国防やエネルギー、財政といった国家の基盤は、  
しばしば「国民を安心させるための制度」として語られる。  
**だが本来それらは、不安を消し去る装置ではない。**  
想定外が起きたときに、社会が致命的に壊れることを防ぐための設計である。

国家基盤には共通した性質がある。  
それは、どれだけ備えても万能にはならないということだ。  
すべてを守ることはできず、どの選択にも必ずコストと犠牲が伴う。  
国防を強化すれば財政に影響し、  
エネルギーを安定させれば別のリスクを引き受ける。  
優先順位のない設計は、結果としてどれも中途半端に弱らせる。

だからこそ、具体的な設計は専門家に委ねるべきだと思っている。  
装備の仕様やエネルギー構成、財政運営の細部を、  
国民が直接決めることは現実的でも健全でもない。  
それは民主主義の放棄ではなく、むしろ民主主義の前提だ。

ただし、委ねることと白紙委任は違う。  
専門家が手段を設計する一方で、  
どこまでを守り、どこで止めるのかという目的と制御点は、  
政治と国民が共有していなければならない。

この前提が共有されないと、民主主義は静かに歪む。  
「安心」を約束しすぎれば、想定外が起きた瞬間に修正が間に合わない。  
優先順位を語らなければ、基盤は見えないところで痩せていく。  
方向が正しくても、止め時を失えば反動で一気に壊れる。

民主主義の役割は、すべてを判断することではない。  
行き過ぎたときに止められる状態を保つことだ。  
国家基盤を巡る議論に必要なのは、  
賛否の声量ではなく、  
この複雑な現実を引き受ける覚悟なのだと思う。
