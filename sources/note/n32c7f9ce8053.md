# 主語を思い出す

> 公開本文の正本：https://note.com/shirokuma1970/n/n32c7f9ce8053
>
> このファイルは文脈解析用の取得時スナップショットです。

かつて「人類みな兄弟」という言葉があった。  
いま振り返ると、どこか理想主義的で、少し左派的な響きを帯びたまま時代の後ろに退いていった言葉のようにも思える。

けれど本当に廃れたのは、スローガンだろうか。  
それとも「主語」だろうか。

いま私たちは、戦争を止めようと議論している。  
気候変動を食い止めようと議論している。  
カーボンニュートラルを達成しようと議論している。

しかしその多くは、国家を主語にして語られる。  
国益、責任、競争、優位性。

それは現実的だ。  
だが一段上の問いが抜け落ちてはいないだろうか。

なぜ戦争を起こしてはいけないのか。  
なぜ気候変動を止めるのか。  
なぜエネルギーを転換するのか。

それは、人類が続くためではないのか。

戦争回避も、気候安定も、エネルギー設計も、  
本来は「人類継続性」という一点に収束している。

国家は手段であって、主語ではない。

もしこの主語を思い出すことができれば、  
個別の政策は違っても、議論の方向は自然と揃っていくはずだ。

「人類みな兄弟」という言葉を復活させる必要はない。  
ただ、主語を静かに戻すだけでいい。
