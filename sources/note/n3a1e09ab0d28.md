# 人類共通の課題と、制約が生む合理性

> 公開本文の正本：https://note.com/shirokuma1970/n/n3a1e09ab0d28
>
> このファイルは文脈解析用の取得時スナップショットです。

カーボンニュートラルは本来、人類共通の課題である。

しかし現実の議論は国家間の競争や責任論に収斂しがちだ。

その中で、日本という国を少しだけ眺めてみる。

資源に乏しく、化石燃料の多くを輸入に頼る国。  
地震や台風といった災害も多い。

その制約の中で、日本は静かに技術を積み上げてきた。

たとえば、

・高効率ガスタービン（三菱重工業）  
・液化水素の海上輸送実証（川崎重工業）  
・次世代電池や電動化技術（トヨタ自動車）

どれも大きな理念を掲げる前に、  
制約の中で効率を高めるという姿勢から生まれている。

それは誇るべき物語というより、  
生き残るための合理性である。

そしてふと思う。

資源制約、災害リスク、エネルギー不安定。  
これらは日本特有の問題だろうか。

地球という有限な環境の中で生きるという意味では、  
人類そのものが同じ条件を抱えているのではないか。

もしそうなら、日本の姿は  
未来の人類が直面する状況の縮図なのかもしれない。

声高に語る必要はない。

ただ、主語を国家から人類へと上げてみたとき、  
見え方が少し変わる。
