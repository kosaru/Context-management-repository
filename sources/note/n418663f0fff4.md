# 世界大戦を経ずに、主語を人類へ戻すことはできるか

> 公開本文の正本：https://note.com/shirokuma1970/n/n418663f0fff4
>
> このファイルは文脈解析用の取得時スナップショットです。

国家は必要である。  
民主主義も必要である。

それらは国家レイヤーで機能する仕組みだ。  
税制や福祉、安全保障といった日常の政治は、選挙周期の中で回る。

しかし一方で、文明の存続確率に直結する問題がある。

核兵器の拡散。  
制御不能な技術の暴走。  
地球規模の環境上限。  
世代をまたぐ不可逆的な負債。

これらは国家単位では完結しない。  
けれど、すべてを一つの統治機構に委ねる話でもない。

必要なのは、もう一つのレイヤーかもしれない。

国家を否定せず、市場も否定せず、  
ただし文明の存続確率を下げる領域だけを、  
長期の座標で見つめる視点。

それは価値観を統一するものではない。  
経済体制を揃えるものでもない。

ただ、「越えてはいけない線」を共有する。

すでにその萌芽はある。  
核不拡散の枠組みや、気候変動に関する国際的な合意。  
国家を越えて共通の線を引こうとする試みは存在している。

問題は制度の強さではなく、主語である。

それらを国家間の交渉として見るのか、  
人類の持続可能性を守る活動として見るのか。

視点が変わるだけで、意味は変わる。

歴史を振り返れば、  
人類が主語を上げた契機は常に破局だった。

だとすれば、また破局を経なければ  
主語を戻すことはできないのだろうか。

主語を一段上げるという発想は、  
世界大戦のような出来事を経ずに  
人類を主語へ戻すための一つの案になり得るのではないか。

まだ完成形はない。

ただ、この問いを置くこと自体が、  
破局を前提としない文明設計への小さな試みなのかもしれない。
