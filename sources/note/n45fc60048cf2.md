# 科学と東洋哲学

> 公開本文の正本：https://note.com/shirokuma1970/n/n45fc60048cf2
>
> このファイルは文脈解析用の取得時スナップショットです。

― 生き方の指針としての東洋思想

近代社会は、西洋思想の上に築かれている。  
科学、合理性、制度設計。  
それらは人類に大きな進歩をもたらした。

しかし同時に、別の問題も生んだ。

合理性は効率を生む。  
だがそれだけでは、人間がどう生きるべきかまでは示さない。

現代社会ではしばしば、

* 短期利益
* 評価
* 効率

が行動原理になりやすい。

その結果、社会の中で次のような変化が起きている。

収束の過程で、社会の倫理は徐々に削ぎ落とされてきた。

```
仁義
↓
組織から消える

礼
↓
マナー化

面子
↓
戦術化
```

倫理が弱まり、  
体裁や戦術だけが残る社会である。

これは長期的には危険な構造だと感じている。

---

日本社会はかつて、別の形の倫理を持っていた。

それは思想として強く意識されていたわけではない。  
むしろ文化や生活の中に溶け込んでいた。

```
仁義
礼
義理
面倒を見る
```

こうした生活倫理は、  
企業、地域、教育などを通じて社会の中に存在していた。

しかし1990年代以降、  
合理化と制度改革の中でそれは組織から徐々に消えていった。

人の中にはまだ残っている。  
だが若い世代には次第に伝わりにくくなっている。

---

ここで改めて考える必要があるのが、東洋哲学である。

東洋思想は、世界の仕組みよりも  
**人がどう生きるか**を中心に考えてきた。

* 仁義を重視する儒家
* 自然体を説く道家
* 合理性を追求する墨家
* 戦わない戦略を説く兵家（孫子）

これらは互いに異なる思想である。  
しかし共通しているのは

```
人間を見る思想
```

である。

西洋思想が二千年かけて人間の問題に到達したとすれば、  
東洋思想は二千年前からそこを出発点としていたようにも見える。

もちろん歴史の中で歪みも生まれた。  
国家統治の道具として利用されたこともある。

それでもなお、  
そこには人間が生きやすくなるための知恵が残っている。

---

だからといって、  
昔に戻ればよいわけではない。

現代社会は

* 科学
* 民主主義
* 合理性

の上に成り立っている。

それを否定する必要はない。

むしろ必要なのは

```
科学
＋
東洋哲学
```

という組み合わせではないかと思う。

科学は世界を理解する。  
東洋哲学は人間の生き方を示す。

この二つは役割が違う。

---

東洋哲学を見直すというのは、  
思想研究の話ではない。

それはむしろ

```
生き方の指針
```

としての再確認である。

人が壊れずに生きるために。  
社会が長く続くために。

そのための知恵が、  
東洋思想の中にはまだ多く残っているように思う。

---

## 補記

――理論的位置づけと差分

### 西洋合理主義

（デカルト以降の近代思想）

**共通点**：理性と論理によって世界を理解し、制度を設計する。  
**差分**：人間関係の倫理や生き方の指針については制度外に置かれやすい。

---

### 東洋倫理思想

（儒家・道家・墨家・兵家）

**共通点**：人間関係や社会の持続性を中心に据える。  
**差分**：制度よりも生活倫理や人格を重視する。

---

### 現代社会との関係

現代社会は、西洋的合理性によって成立している。  
しかしその合理性だけでは、人間の生き方を支える倫理は十分に説明されない。

その空白を埋める可能性として、  
東洋哲学の生活倫理は再び参照される価値があるように思われる。
