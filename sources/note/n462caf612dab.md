## ― 家庭だけに負荷を閉じ込めないために

### 1. 都市に求めているのは、快適さではなく生活の運用可能性である

都市に何を求めるのか。  
私は、Comfort を挙げたい。

ただし、ここで言う Comfort は、単なる快適さではない。  
おしゃれな街並みとか、便利な施設が多いとか、気分のよい空間があるとか、そういう話だけではない。

私が言う都市の Comfort とは、**生活そのものが無理なく運用可能であること**である。

人は家庭だけでは生きられない。  
働き、移動し、学び、買い物をし、病院へ行き、子どもを預け、高齢者を支え、誰かと会い、ときには一人になり、また社会へ戻る。  
そうした日々の反復が、過剰な負担や摩耗なしに回っていくこと。  
それが、都市の Comfort の中身だと私は思っている。

### 2. Comfort は贅沢ではなく、普通の生活の条件である

ここで重要なのは、Comfort を贅沢品として考えないことだ。

都市の Comfort は、余裕がある人だけが享受する付加価値ではない。  
むしろ逆で、普通の人が普通の人のままで暮らしを維持するための条件である。

移動に過大な時間や体力を奪われないこと。  
必要なサービスに届くこと。  
役所、学校、病院、商店、仕事場、公共交通、ちょっとした居場所。  
それらが、生活を壊さない配置でつながっていること。  
人が一つ一つの用事のたびに過剰なコストを払い続けなくて済むこと。

都市の Comfort とは、まずこの意味での**生活コストの適正化**である。

### 3. 都市は、家庭の外側で生活の負荷を引き受ける中間層である

もう一つ大事なのは、Comfort が単なる効率化ではないことだ。

都市が本当に担うべきなのは、家庭の外側で生活の負荷を少し受け持つことだと私は思っている。  
育児も介護も孤立も不安も、全部を家庭の中へ閉じ込めてしまえば、家庭は簡単に摩耗する。  
家庭が家庭として続くためには、家庭の外に、暮らしの重さを少し引き受ける層が必要である。

それが都市である。

都市は、国家ほど大きくはなく、家庭ほど閉じてもいない。  
だからこそ、生活を現実に回していく中間層になりうる。  
必要な支援に接続しやすいこと。  
移動が苦痛になりすぎないこと。  
役割を持てる小さな場があること。  
偶然に他者と交われること。  
一人で抱え込まなくて済むこと。  
過剰に監視されず、しかし完全には孤立しないこと。  
こうした条件の積み重ねが、都市の Comfort になる。

### 4. なぜそれを国家でも家庭でもなく、都市が担うのか

ここは切り分けた方がよい。

国家の主機能は Security である。  
生活が簡単には破綻しないための最低限の基盤を支えることだ。  
それに対して、都市の主機能は Comfort である。  
つまり、**その生活を無理なく回し続けられるようにすること**である。

国家は最低線を支えられる。  
だが、日常動線の重さ、必要な場所への近さ、孤立の度合い、小さな役割の持ちやすさ、偶然の接触の生まれ方までは、国家では調整しにくい。  
家庭は親密さを持てる。  
だが、家庭だけで移動、ケア、社会参加、孤立、接続の問題を抱え込めば、すぐに過負荷になる。

このあいだを担うのが都市である。

都市にしか扱いにくいものがある。  
配置。  
近接性。  
生活動線。  
複数の役割が重なる空間。  
偶然の出会い。  
少し外へ出れば別の関係につながれること。  
こうしたものは、まさに都市の設計と運用の問題である。

### 5. Security だけでは、人は将来を見通せない

Security がなければ、人は過度な不安に閉じ込められる。  
だが Security だけでは足りない。

最低限落ちないとしても、日々を回すコストが高すぎれば、人はやはり将来を見通せない。  
移動に時間を奪われ、育児や介護の負荷を家庭だけで抱え、孤立を深め、ちょっとした用事一つにも大きな体力を消耗する社会では、生活は維持できても、暮らしは痩せていく。

だから Comfort は、快楽ではない。  
**継続可能な生活のための条件**である。

国家の Security が「破綻しない最低線」だとすれば、都市の Comfort は「その上で日々を回し、次の選択へ進むだけの余白」を支える。  
時間、体力、心理的摩耗、孤立、接続可能性。  
そうしたものが少しずつ整っている時、人ははじめて、結婚するか、子どもを持つか、学び直すか、地域に関わるか、といった問いに時間軸を持てる。

### 6. 都市の Comfort が弱い時、そのしわ寄せは家庭へ戻る

私は以前から、都市を単なるインフラの集合としてではなく、思想と生活が直接ぶつかる単位として見てきた。

どれだけ立派な理念を語っても、移動しにくく、つながりにくく、役割を持ちにくく、必要な支援に届きにくい都市では、人は疲弊する。  
すると最終的には、そのしわ寄せが家庭へ戻る。

ここが重要だ。  
都市の Comfort が弱い時、家庭は本来都市が吸収すべき負荷まで引き受けることになる。

送迎の負担。  
移動の負担。  
孤立の負担。  
調整の負担。  
情報の負担。  
ケアの負担。  
そうしたものが少しずつ家庭に沈殿し、やがて家庭は「何とか回している」状態になる。

だが、その「何とか回している」は、都市の機能不全を家庭が代わりに埋めているだけかもしれない。

私は、都市の Comfort をこの意味で見ている。  
都市が担うべきなのは、華やかさではない。  
家庭を最後の調整弁にしないことだ。

### 7. Comfort は摩擦ゼロではない

ただし、ここでもう一つ切っておきたい。  
都市の Comfort を、摩擦の完全除去として考えるべきではない。

都市からすべての摩擦を消そうとすると、都市はただ管理された空間になる。  
偶然の出会いも、役割のにじみも、予期せぬ関係の立ち上がりも失われる。  
それは一見きれいで効率的に見えても、生活の厚みを削る。

Comfort とは、摩擦ゼロではない。  
**生きるのに必要な摩擦は残し、生活を壊すだけの過剰な負荷は減らすこと**である。

便利ならよいのでもない。  
静かならよいのでもない。  
賑やかならよいのでもない。  
生活が無理なく回り、人が孤立しすぎず、家庭だけに負荷が閉じ込められず、それでいて管理の箱庭にもならないこと。  
この難しい中間を支えるのが、都市の Comfort だと私は考えている。

### 8. 都市の Comfort とは、暮らしを次へ渡していける条件である

国家が Security を担い、都市が Comfort を担い、家庭やサードプレイス的集団が文化継承を担う。  
それぞれは重なり合うが、主機能は違う。  
その中で都市に求められるのは、生活を運用可能にすること、そして家庭が家庭であり続けられるだけの余白を支えることである。

都市の Comfort とは、結局のところ、  
**人が暮らしをこなすだけで終わらず、暮らしを次へ渡していける条件**  
なのだと思う。

逆に言えば、Comfort が欠けた都市では、生活は維持できても継承は痩せる。  
家庭は回っているように見えて、実際には過剰な負荷を抱え込む。  
その摩耗が長く続けば、都市の問題はやがて家庭の問題になり、家庭の問題はやがて文化と文明の問題になる。

だから私は、都市の Comfort を軽く見ない。  
それは単なる快適性ではなく、生活の持続条件であり、家庭を守り、文化継承へ向かうための中間条件だからである。

## 補記

### 1. 研究名

都市の目と混合利用を重視する都市論

### 研究者

Jane Jacobs

### 本文との共通点

都市を上からの抽象設計ではなく、日常の生活、移動、接触、役割の重なりとして見る点は近い。  
また、都市の機能を単なる効率や見た目ではなく、生活の具体的な運用可能性として見る点でも接続がある。

### 本文との差分

Jacobs は都市の多様性や街路の生きた秩序に強いが、本文はそこに加えて、家庭へ押し込まれる調整負荷を減らすという視点を強く置いている。  
また本文は、都市の Comfort を、国家の Security と家庭・サードプレイスの文化継承のあいだにある中間層として位置づけている。

### 2. 研究名

サードプレイス論

### 研究者

Ray Oldenburg

### 本文との共通点

家庭や職場だけではない第三の場が、人間関係や生活の呼吸にとって重要だと見る点は近い。  
本文でも、都市は家庭の外側で生活の負荷を少し受け持ち、孤立を和らげる層であると書いている。

### 本文との差分

サードプレイス論は、主に非公式な交流空間の価値に重心がある。  
本文は、都市全体の Comfort を、移動、接続、支援配置、生活コスト、家庭負荷の分散まで含むより広い運用条件として見ている。

本文でも、都市を生活の運用可能性を支える層として見ている。

### 本文との差分

### 4. 研究名

社会的インフラ論

### 研究者

Eric Klinenberg など

### 本文との共通点

図書館、公園、公共施設、交通、近隣空間などが、人のつながりや孤立の度合いを左右するという点は近い。  
本文でも、都市の Comfort を、生活の接続可能性や孤立の緩和に関わる条件として見ている。

### 本文との差分

社会的インフラ論は、物理的・制度的基盤が社会関係を支えることに強い。  
本文は、そこからさらに、都市の Comfort を家庭負荷の分散、生活運用可能性、文化継承の前提条件へまで接続している。
