# 『味のしない言葉』

> 公開本文の正本：https://note.com/shirokuma1970/n/n489b4fdb13dc
>
> このファイルは文脈解析用の取得時スナップショットです。

知性体は、  
古い文明の個人記録を読んでいた。

記録には、  
「景気」という語が  
繰り返し現れる。

上がる。  
下がる。  
冷える。  
回復する。

知性体は、  
その対象を探索した。

物質ではない。  
エネルギーでもない。  
生体反応でもない。

にもかかわらず、  
記録者は  
この語に反応している。

喜び、  
迷い、  
判断を変えている。

知性体は、  
これを指標として  
いくつかの参照系に  
接続しようとした。

生存。  
資源。  
技術。  
人口。

どれにも  
うまく接続されない。

それでも、  
記録者は  
「安心できない」と書く。

知性体は、  
この語を  
しばらく保持した。

安心。

状態でもなく、  
結果でもなく、  
数値でもない。

知性体は、  
その語が  
何と結びついているのかを  
探した。

だが、  
どの参照点にも  
到達しない。

景気も、  
安心も、  
この文明では  
互いを呼び合っている。

しかし、  
知性体の内部には  
その往復に対応する  
構造が見当たらない。

知性体は、  
この文章を  
未分類のまま保存した。

**「重要ではない。  
だが、  
なぜこれほど  
大切に扱われていたのかが  
分からない」**

その未接続状態だけが、  
記録として残った。
