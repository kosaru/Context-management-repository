# 国家の Security とは何か

## ― 個々人が将来を見通せるための基盤として

### 1. 国家の役割を、軍事や治安だけで読まない

国家の役割とは何か。  
私はまず、Security を挙げたい。

ただし、ここで言う Security は、単なる軍事や治安の話ではない。  
もちろんそれらは含まれる。  
だが、それだけでは足りない。

私が言う Security とは、**人が生活を破綻させずに生きていける最低限の基盤**である。

暮らしが簡単には崩れないこと。  
病気や失業や事故や災害が、そのまま人生の即時崩壊に直結しないこと。  
家庭を持つか、子どもを育てるか、学び直すか、仕事を変えるか、誰かを支えるか。  
そうした選択に、最低限の時間軸を持てること。  
Security とは、そういう意味での土台である。

### 2. Security がない社会では、人は将来を見通せなくなる

少なくとも私には、人は過度な不安の中では、防御に閉じるように見える。

先のことを考える余裕を失う。  
学び直す余白も、挑戦する余白も、誰かを支える余白も削られる。  
失敗を極端に恐れるようになる。  
視野は短くなり、その日その日をしのぐことが優先される。

家庭も同じである。  
毎日が崩壊寸前のままでは、文化の継承どころか、その日を回すことだけで精一杯になる。  
将来を見通すというのは、未来を完全に予測できることではない。  
生活が簡単には壊れず、今日の選択を明日へつなげられるという感覚を持てることだ。  
Security がない社会では、その感覚そのものが痩せていく。

### 3. Security は「守り」ではなく、自由の条件でもある

ここで重要なのは、Security を消極的な「守り」の言葉としてだけ読まないことだ。

Security がない社会では、人は縮こまる。  
防御的になる。  
短期的になる。  
自分と家族を守ることだけで精一杯になり、世界を広げる余力を失う。  
すると社会全体としても、探索、起業、学習、挑戦、信頼形成といった動きが痩せていく。

逆に言えば、Security があるからこそ、人は少し先を見ることができる。  
失敗しても即座に全てを失うわけではないと思える。  
だから学び直しにも踏み出せるし、家庭も維持できる。  
家庭を維持できるからこそ、文化は継承される。  
文化が継承されるからこそ、文明は下から続く。

つまり Security とは、単なる防御ではない。  
**人が将来を見通しながら自由に生きるための条件**でもある。

### 4. 家族や地域や企業が担っていた Security は、すでに弱っている

私は以前、日本社会の生活基盤が、家族や地域から企業へとかなり移っていた時期があったと考えた。  
企業は、単なる賃金支払いの場ではなく、ある種の生活共同体機能まで引き受けていた。  
雇用の安定、共同体感覚、役割感覚、人生設計の枠。  
もちろんそれは窮屈さも抱えていたが、少なくとも一時代の Security ではあった。

しかし、その企業社会が流動化し、共同体機能を弱めた後、私たちは自由だけを手に入れたのではない。  
同時に、生活基盤の不安定化も広く引き受けることになった。

その結果として起きたのは、単なる競争激化ではない。  
もっと深いところでの、不安の常態化である。

明日がどうなるか分からない。  
家庭がこのまま維持できるか分からない。  
教育や医療や介護の負担がどこまで膨らむか分からない。  
失敗した時に立て直せる感覚がない。  
こうした状態では、人は長期的に考えにくい。  
社会全体もまた、短期利益と防御反応に引っ張られやすくなる。

### 5. だから国家には、国家の主機能がある

ここで言いたいのは、国家がすべてを面倒見ろという話ではない。  
国家が家庭を代替しろという話でもない。  
都市や共同体や市場の役割まで国家が飲み込めという話でもない。

そうではなく、国家には国家の主機能がある、という話だ。  
その主機能が Security である。

家庭や地域や企業は重要である。  
だが、生活破綻を防ぐ最低線を、社会全体に対して広く支えるだけの規模と制度を持つのは、結局国家である。  
雇用、所得、医療、教育、治安、防災、安全保障。  
細部は様々でも、国家が支えるべきなのは、**生活が簡単には崩れないという最低限の信頼**である。

この最低線があるからこそ、その上で都市は Comfort を支えられる。  
家庭やサードプレイス的集団は、文化継承やケアの反復を担える。  
さらに国際秩序は、文明の衝突を管理するだけでなく、文明保存の条件を守る方向へ移ることができる。

順番を崩してはならない。

### 6. 国家が Security を担わない時、その不安は各家庭へばら撒かれる

家庭だけに Security を押し込めれば、家庭は摩耗する。  
企業だけに Security を依存すれば、企業の変動がそのまま生活崩壊へつながる。  
都市に Security まで背負わせれば、都市は過負荷になる。  
そして国家が本来担うべき Security を引き受けないなら、社会全体は不安を各家庭へばら撒くことになる。

その時に起きるのは、目に見える破局だけではない。  
もっと静かな摩耗である。

結婚や出産をためらう。  
子どもを育てる余力が消える。  
学び直しに踏み出せない。  
病気や介護が家庭を直撃する。  
失敗を極端に恐れる。  
社会全体が短期化する。

こうして、生活の継続可能性が少しずつ痩せていく。  
そして、その先にあるのは、文明の保存どころか、生活の再生産そのものの不安定化である。

### 7. 国家の Security とは、家庭が明日へ渡っていけるための土台である

私は、Security をここまで広く見ている。  
それは軍事や治安を軽く見るという意味ではない。  
むしろ逆で、それらも含めて、**人間が過度な恐怖や不安に追い込まれず、生活を壊さずに生きられる条件を国家が支えるべきだ**と言っている。

国家の Security とは、国旗や国境の防衛だけではない。  
それは、家庭が明日へ渡っていけるための最低限の土台である。  
家庭が明日へ渡っていけるからこそ、文化は継承される。  
文化が継承されるからこそ、文明は続く。

だから私は、国家の Security を軽く見ない。  
それは、生活の持続条件であり、個々人が将来を見通せるための基盤であり、文明保存の前提条件でもあるからだ。

国家が Security を担うとは、人々を檻に入れて管理することではない。  
人々が将来を見通しながら自由に生きられる最低限の土台を支えることである。

### 1. 研究名

人間の安全保障

### 研究者

国連開発計画、人間の安全保障研究の系譜

### 本文との共通点

安全保障を軍事や国家防衛だけでなく、人間の生活基盤が破綻しないための条件として広く捉える点は近い。  
本文でも、国家の Security を、生活が簡単には崩れないための最低線として置いている。

### 本文との差分

人間の安全保障論は、脅威からの保護や生活基盤の安定には強いが、それを家庭での文化継承や文明保存まで一つの下からの継続回路として束ねるところまでは通常は行かない。  
本文は、Security を生活基盤であると同時に、家庭と文明をつなぐ前提条件として読んでいる。
