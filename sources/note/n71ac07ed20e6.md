# 社会の力みを読む―― 持続可能な社会のための老荘思想

> 公開本文の正本：https://note.com/shirokuma1970/n/n71ac07ed20e6
>
> このファイルは文脈解析用の取得時スナップショットです。

老荘思想というと、個人の生き方の知恵として語られることが多い。  
力を抜け。  
無理をするな。  
自然体で生きろ。  
そうした言葉にまとめられがちである。

もちろん、それは一面では間違っていない。  
だが個人的には、老荘思想の射程はそこに留まらないと思っている。  
むしろ老荘思想は、**社会構造がどこで不自然に力み、どこで本来の連動を壊しているのかを見るための視点**としても読めるのではないか。

私がここで言う持続可能な社会は、SDGs的な持続可能性とは全く違う。  
私が重視しているのは、普遍的な目標を上から共有することではなく、地域ごとに異なる歴史、文化、産業、人間関係を壊さず、その土地なりの形で続いていけることである。  
共通なのは「続いていけること」であって、「同じであること」ではない。  
歴史も文化も産業も人間関係も違う以上、持続可能性の形もまた地域ごとに異なるはずだ。  
にもかかわらず、一つの理想像を上から配布し、各地域を同じ型にはめ込もうとすれば、そこで構造は不自然に力み始める。

この「力み」は、個人の身体にも社会構造にも起こる。  
何かを維持しようとして必要以上に固める。  
不安があるから管理を強める。  
成果を急ぐあまり、短期的に測れるものばかりを増やす。  
その結果、一見すると秩序は強まったように見える。  
だが実際には、現場の判断は痩せ、関係のしなやかさは失われ、構造の持続性そのものが削られていく。

ここで言いたいのは、管理するなとか、制度をなくせという話ではない。  
張力そのものは必要である。  
軸のない身体が崩れるように、軸のない社会も漂流する。  
問題は、**必要な張力と、構造を壊す力みとを区別できなくなること**にある。

私は、しなやかさとは単に柔らかいことではないと思っている。  
**軸があるからこそ、しなやかに変えられる。**  
逆に軸がなければ、柔軟さはただの場当たりになる。  
また軸が弱いまま不安だけが強くなると、人は全体を固めようとする。  
その硬直は、短期的には安心を与えるかもしれない。  
しかし長い目で見れば、変化に対応できず、かえって壊れやすくなる。

老荘思想をここでどう読むか。  
私はそれを、何もしないことの勧めとしては読まない。  
また、放っておけば自然にうまくいくという楽観としても読まない。  
そうではなく、**過剰な作為が全体を壊すことへの警告**として読む。

ここで言う作為とは、工夫そのものではない。  
調整そのものでもない。  
必要なのはむしろ調整であり、工夫である。  
ただ、それが全体の流れを見ずに、上から一つの型を押しつけ、測りやすいものだけで世界を切りそろえ始めたとき、作為は力みに変わる。  
その瞬間に、本来つながっていたはずのものが切れ始める。

社会構造を持続可能にするために必要なのは、すべてを一律に最適化することではない。  
地域ごとの差を消すことでもない。  
むしろ、地域ごとの個性や関係性を壊さずに、なお続いていけるようにすることだ。  
そのためには、各地域が自分たちなりの形で動ける余地が必要になる。  
同時に、単なる放任ではなく、全体として共有されるべき軸も必要になる。

ここでいう軸とは、同じ答えを全国一律で配ることではない。  
**それぞれの地域が、その地域なりに続いていけることを守る**という方向である。  
軸は一つでも、形は複数でよい。  
むしろ複数でなければ不自然である。

この意味で、私は持続可能な社会を、固定された完成形とは考えない。  
持続可能な社会とは、状況の変化に応じて変手できる社会である。  
ただし、その変更は漂流ではなく、軸に沿った調整でなければならない。  
身体でいえば、軸があるから変手が利く。  
社会でも同じで、共有されるべき方向があるからこそ、制度や運用はしなやかに変えられる。

だから、老荘思想で社会構造を読むとは、理想社会の設計図を描くことではない。  
むしろ、**この構造は今どこで力んでいるのか。どこで地域の個性を押し潰しているのか。どこで必要な張力を越えて硬直に変わっているのか。**  
そう問い続けることに近い。

もし老荘思想に現代的な意味があるとすれば、それはここにあるのではないかと思う。  
個人の内面を慰めるためだけではなく、社会の側の作為と硬直を見抜くための視点として。  
そして、地域ごとに異なる持続可能性を守るための感覚として。

私にとって老荘思想は、放任の思想ではない。  
ましてや、何も決めないための言い訳でもない。  
それは、**社会を無理に固めすぎず、しかし漂流もさせず、軸を持ったまましなやかに続けていくための感覚**に近い。  
持続可能な社会とは、そのような感覚を失わない社会のことではないかと思っている。

## 補記

### この感覚に近い研究と、その共通点・差分

私は老荘思想を中国思想史の専門的文脈で論じたいわけではない。  
ここでやっているのは、老荘思想の中にある「過剰な作為が全体を壊す」という感覚を、社会構造の問題へ引き寄せて読み直すことである。  
その意味で、以下の研究や考え方には近い部分がある。

### 1. 道家思想研究

**研究名：道家思想研究**  
**研究者：老子・荘子研究全般**

**共通点**  
無理に押し通すこと、硬さを強さと見なすこと、一つの尺度で全部をそろえようとすることへの警戒は、私の問題意識とかなり重なる。

**差分**  
ただし私は、古典の忠実な解説を書いているわけではない。  
老荘思想そのものよりも、その核にある感覚を、現代の社会構造の読みへ応用しようとしている。

### 2. 多中心的統治

**研究名：polycentric governance**  
**研究者：エリノア・オストロム**

**共通点**  
地域ごとに条件が違う以上、持続可能性の実現も一律ではなく、複数の中心を持つほうが現実に近いという感覚は、私の考えとかなり近い。

**差分**  
ただし私は、制度設計の技術論そのものを書きたいわけではない。  
中心にあるのは、統治の形式よりも、構造が過剰に力まないための感覚である。

### 3. 地域基盤型政策

**研究名：place-based policy**  
**研究者：地域政策研究全般**

**共通点**  
私が「持続可能な社会の形は地域ごとに違う」と考えるのは、この地域基盤型の発想と強く響き合う。  
一つの正解を全国一律に当てはめない、という点で近い。

**差分**  
ただし私は、政策手法としての地域基盤型政策を推したいのではない。  
それ以前に、地域差を無視して同じ型に押し込めること自体が、構造の力みではないかと見ている。

### 4. レジリエンス思考

**研究名：social-ecological resilience / resilience thinking**  
**研究者：レジリエンス研究全般**

**共通点**  
私が持続可能性を、同じ状態を固定することではなく、変化に応じて続いていけることとして捉えるのは、この考え方に近い。

**差分**  
ただし私は、生態学的モデルや指標の話をしたいわけではない。  
ここで問題にしているのは、社会構造がどこで硬直し、どこでしなやかな変更可能性を失うのかという感覚である。

### まとめ

私の感覚に近いのは、  
道家思想の中にある過剰な作為への警戒、  
多中心的統治、  
地域基盤型政策、  
そしてレジリエンス研究である。

ただし、私がやっているのはそれらの理論紹介ではない。  
私は、老荘思想の中にある「無理に固めすぎるな」「一つの尺度で全部を支配しようとするな」という感覚を、地域ごとの差異を含んだ持続可能な社会の条件として読み直しているのである。

だからこれは研究の要約ではなく、  
**社会構造を持続可能にするために老荘思想をどう使えるか、という現時点での記録**である。
