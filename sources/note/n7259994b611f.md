# まだ残っているからこそ危ない

> 公開本文の正本：https://note.com/shirokuma1970/n/n7259994b611f
>
> このファイルは文脈解析用の取得時スナップショットです。

前にも、今が最後の機会かもしれない、という話を書いた。  
そのときも危機感はあった。  
けれど今回、別の角度から考えてみて、その感覚はむしろ強くなった。

いまの日本は危ない。  
景気が悪いとか、成長率が低いとか、そういう意味だけではない。  
もっと深いところで、日本社会を日本社会として支えてきた前提条件そのものが、理解されないまま削られていく危険がある。  
私はそこに強い不安を持っている。

日本には、まだ独自の強さが残っている。  
しかもそれは、抽象的な美徳として語られる強さではない。  
危機のたびに、実際に現れてきた強さだ。  
だからこそ危ないのである。  
残っている強さがあるから安心なのではない。  
その強さがまだ残っているうちに、その意味を取り違えたまま壊してしまうかもしれない。  
そこが危ない。

日本文化の基層は、中国思想だけでは説明できない。  
儒家や老荘、仏教の影響はもちろん大きい。  
しかしその下には、もっと古い層がある。  
石や木や土地や場に、ただの物以上の気配を感じる感覚。  
教義として明確に語られるわけではなく、薄い雰囲気のように、長く生活の底に残り続けてきた感覚。  
そうしたものが、日本文化の深層にあるのだと思う。

日本は、外から来たものをそのまま受け入れてきたわけではない。  
いったん受け止め、噛み合わないところで摩擦を起こし、時間をかけて自分たちに合う形へ変形してきた。  
拒絶ではなく、変形して受容すること。  
そこに、日本の一つの特徴があったように思う。

戦後の日本型資本主義も、その延長線上にあったのではないか。  
純粋な市場原理でもなく、純粋な共同体主義でもない。  
企業共同体、官僚調整、地域社会、家族構造、利益分配。  
そうしたものを折衷しながら、日本なりの資本主義社会が組まれていた。  
少なくとも、しばらくのあいだはそれで回っていた。

しかしバブル崩壊以後、その仕組みは長く揺らいだ。  
失われた30年とは、単なる不況ではなかったと思う。  
日本型に最適化されつつあった資本主義社会が内側から綻び、そこに外からさまざまな圧力が重なり、企業も政治も個人も右往左往させられた時代だった。  
その過程で、答えを外国に求める場面も多かった。  
だが、そこで日本の深層構造そのものが消えたわけではなかった。

それは、リーマン・ショックやコロナ禍で見えた。  
日本も大きな打撃を受けた。  
それでも、雇用や社会の崩れ方は、欧米ほど極端ではなかった。  
回復も、それなりに速かった。  
現場の調整力、雇用維持、生活防衛、社会の崩れにくさ。  
そうしたものが、危機の場面で実際に働いていた。  
つまり、日本社会の底にはまだ粘りが残っていたのだと思う。

だが、そのこと自体が安心材料になるとは限らない。  
むしろ問題はそこから先にある。  
その粘りを見て、上の層が「日本はまだ大丈夫だ」と思ってしまえば危険だ。  
もっと言えば、政治家や企業家が「日本は危機を乗り切れた」と成功体験を持つこと自体は悪くないとしても、その成功の意味を取り違えれば危うい。

なぜなら、その危機対応の成功は、政治家や企業家だけの成果ではなかったからだ。  
国民が支えたのである。  
現場で耐えた人々がいた。  
雇用の調整を引き受けた人々がいた。  
生活を切り詰めた家計があった。  
社会全体の我慢と粘りがあった。  
その下支えがあったからこそ、日本は持ちこたえた。

だから、その成功は上の層だけの成功体験で終わってはならない。  
国民が再び先の見える生活を営める形で返されなければならない。  
ここに政治の責任がある。  
危機を乗り切ったことを誇るのではなく、その強さを支えた国民に返すこと。  
賃金、可処分所得、雇用の安定、地域の維持、将来不安の軽減。  
そうしたものを通じて、国民が再び先の見える生活へ戻れるようにすること。  
そこまで行かなければ、それは本当の意味での成功ではない。

しかも、ここには時間の制約がある。  
失われた30年は、一世代が入れ替わる時間だった。  
今後も、同じ強さを日本人が自動的に持ち続けるとは思わないほうがいい。  
かなりの若者は、すでに欧米化した考え方をしている。  
それ自体を単純に悪いと言いたいわけではない。  
だが、これまで日本の深層構造を支えてきた感覚や粘りが、この先も同じように維持される保証はない。  
つまり、今見えている強さは、放っておけば続くものではない。

だからこそ、いまの日本は危ない。  
まだ残っている強さがある。  
だが、その強さは永続する前提ではない。  
にもかかわらず、上の層がその意味を十分に理解しないまま、世界基準への最適化や、外からの補充でその場をしのごうとすれば、その強さの前提そのものを壊しかねない。

ここから先は、かなりはっきりした分岐に入る。  
日本の文化を壊して世界基準に最適化するのか。  
それとも、日本の独自性を持った強さを今後も継承できるのか。  
たぶん政治家や企業家は、すでにその判断を始めている。  
そして、その判断は単なる経済政策ではない。  
どんな社会を次の世代に渡すのかという選択そのものだ。

そのとき、外国を手本として従うべきではない。  
外国の考えを材料として取り入れることはあってよい。  
だが、判断の起点を外に置いてはならない。  
日本の政治家や企業家は、日本の文化、日本の社会、日本の国民生活に立脚して、自分たちの頭で考え、自分たちの責任で行動しなければならない。  
そうしなければ、日本の文化に根ざした強さは維持できない。

そして私は、もう一つの危うさも感じている。  
リーマンやコロナを乗り切れたのは、日本の国民性があったからでもある。  
我慢、調整、場を壊さない感覚、相互期待、責任感。  
そうした、制度の外側にある人間の癖のようなものが、日本社会の危機耐性を支えていた。  
その前提を上の層が理解しないまま、労働力として外国人を入れていく方向へ進むなら、危険は小さくない。  
問題は、単に人手不足を埋めるかどうかではない。  
外国人を日本人と同じように使おうとしても、同じようには機能しないだろう。  
だからといって、外国人に合わせた構造を企業に広げていけば、今度は日本人の強さを支えてきた企業の前提そのものが壊れていく。  
それは労働力の補充ではなく、日本社会の持っていた強さの条件を、自ら崩していくことになりかねない。

要するに、今問われているのは、日本にまだ独自の強さがあるかどうかだけではない。  
その強さがまだ残っているうちに、それを継承できる社会へつなげられるかどうかだ。  
もしそれができないなら、今見えている強さは、次の世代には継承されず、ただの過去の話として失われていくかもしれない。

前にも、今が最後の機会かもしれないと思った。  
今回また、別の角度から考えて、同じ場所に戻ってきた。  
だから、やはりそうなのだと思う。

**いまの日本は危ない。**  
**まだ独自の強さは残っている。**  
**だが、その強さの意味を取り違えたまま進めば、その前提そのものを自ら壊すことになる。**  
**だからこそ今、その強さを継承できる社会へつなげられるかどうかが、決定的に重要なのだ。**
