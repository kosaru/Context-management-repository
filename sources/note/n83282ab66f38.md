# 第8回：人が動ける社会と、人を動かせる社会は違う――労働力の流動性を、安心の土台から考える

### 1. 労働力の流動性は、明るい言葉として届いているのか

労働力の流動性という言葉がある。

政策や経済の言葉としては、前向きに語られることが多い。

人が一つの会社に縛られず、必要に応じて働く場所を変えられる。  
技能を持った人が、より合う場所へ移れる。  
企業も必要な人材を外から採れる。  
社会全体として、人材が硬直せずに動く。

そう説明される。

だが、一般市民の実感は、たぶんそれほど明るくない。

労働力の流動性と聞いて、多くの人がまず感じるのは、自由よりも不安ではないか。

正社員でいられなくなるのではないか。  
会社に切られやすくなるのではないか。  
非正規や派遣に流されるのではないか。  
収入が不安定になるのではないか。  
住宅ローンや賃貸契約で不利になるのではないか。  
社会的信用まで落ちるのではないか。  
会社が人を使い捨てしやすくなるだけではないか。

つまり、労働力の流動性は、政策の言葉としては「人が動ける自由」に見える。

しかし、生活者の実感としては、「企業が人を動かせる自由」に見えやすい。

ここを分けなければならない。

人が動ける社会と、人を動かせる社会は違う。

人が動ける社会とは、働く人が自分の意思で職場を選び直せる社会である。

一方、人を動かせる社会とは、企業が必要なときに人を集め、不要になれば外へ出せる社会である。

同じ「流動性」という言葉で語られていても、主語が違えば中身は変わる。

この主語を曖昧にしたまま労働市場を語ると、働く人の自由のように見えて、実際には企業の調達可能性だけが高まることになる。

### 2. 本来、流動性は一般市民に有利であるべきだった

労働力の流動性そのものが悪いわけではない。

本来、労働力の流動性は、一般市民に有利な概念であるべきだった。

一つの会社に人生を預けなくてよい。  
合わない職場から離れられる。  
技能を持って別の場所へ移れる。  
子育てや介護に合わせて働き方を変えられる。  
地域を移っても働ける。  
学び直して再参入できる。  
失敗しても戻れる。  
会社に依存しすぎずに生活できる。

こういう流動性なら、働く人にとって大きな意味がある。

会社に閉じ込められない。  
上司や組織に人生を握られすぎない。  
ブラックな職場から逃げられる。  
自分に合う場所を探せる。  
家庭や地域生活と働き方を調整できる。

これは、減速のイノベーションとも相性がよい。

なぜなら、減速のイノベーションが考えたいのは、企業を速く回すことではなく、人が壊れず、生活を続けながら選び直せる社会だからである。

人が動けることは大事である。  
だが、それは人が市場に放り出されることではない。

動いても生活が壊れないこと。  
動いた先で働き続けられること。  
動いたことで社会的信用を失わないこと。  
動いた後にも戻れる場所があること。

そこまで含めて、初めて労働力の流動性は一般市民にとっての自由になる。

### 3. しかし現在の流動性は、企業側に先に効きやすい

現実には、労働力の流動性の利点は、企業側に先に現れやすい。

必要なときに人を採る。  
不要になれば契約を終える。  
即戦力を市場から買う。  
教育コストを外部化する。  
固定費を変動費化する。  
下請け、委託、派遣、外注で不足を埋める。  
繁忙期だけ人を増やす。  
専門人材だけを短期で使う。

これは企業にとっては合理的である。

市場は変わる。  
技術は変わる。  
需要も変わる。  
競争環境も変わる。

その中で、企業が人員配置を柔軟にしたいと考えるのは自然である。

しかし、企業にとって合理的な流動性が、そのまま働く人にとっての自由になるとは限らない。

企業にとっての流動性は、しばしば人材の調達しやすさである。  
固定費を変動費に変えることでもある。  
教育や待機や生活不安のコストを、企業の外へ逃がすことでもある。

だが、働く人にとって必要なのは、単に市場に出されることではない。

動いても生活が壊れないこと。  
移っても技能が活かせること。  
働きながら学び直せること。  
家庭や地域生活を失わないこと。  
次の仕事に移るまでの不安が大きすぎないこと。  
年齢や契約形態によって、いきなり市場から弾かれないこと。

つまり、働く人にとっての流動性には、安心の土台が必要である。

その土台がないまま流動性だけを高めれば、それは自由ではなく不安定化になる。

### 4. Security と Comfort を労働市場に置く

前回、第7回では、安心を Security と Comfort に分けて考えた。

Security は、生活が壊れないための安心である。  
Comfort は、心地よく続けるための安心である。

この二つは、労働市場にも必要である。

労働における Security とは何か。

仕事を失っても、すぐに生活が壊れないこと。  
次の仕事へ移るまでの生活が支えられること。  
病気や介護や子育てで働き方を変えても、人生が破綻しないこと。  
契約が弱い人ほど一方的に負荷を背負わされないこと。  
最低限の賃金、休息、安全、相談先があること。  
雇用形態が変わっても、社会的信用が急落しないこと。

これは、甘えではない。

働く人が市場の中で動くための基礎防衛である。

では、労働における Comfort とは何か。

働き続けても心身が削られすぎないこと。  
現場に余白があること。  
教育や引き継ぎが行われること。  
人間関係が壊れきっていないこと。  
働く場所や時間に、ある程度の選択肢があること。  
家庭や地域生活と両立できること。  
自分の仕事に意味や手応えを感じられること。

これは贅沢ではない。

人が長く働き、学び、移り、戻り、支え合うための生活感覚である。

Security がなければ、人は守りに入る。  
Comfort がなければ、人は長く続けられない。

この二つがないまま労働力の流動性を高めても、人は自由に動けない。

ただ、不安定な状態で動かされるだけになる。

### 5. 流動性には、信用のポータビリティが必要である

労働力の流動性を考えるとき、見落とされやすいものがある。

社会的信用である。

日本社会では、雇用形態が社会的信用に大きく関わっている。

正社員であることは、単に雇用が安定しているというだけではない。

住宅ローン。  
賃貸契約。  
クレジットカード。  
自動車ローン。  
結婚。  
子育て。  
家族形成。  
親族からの見られ方。  
社会的評価。

こうした場面で、正社員という属性は強い信用として扱われやすい。

一方、非正規、派遣、委託、個人事業主、フリーランスは、収入があっても信用が低く見られやすい。

これは、労働市場の中だけの問題ではない。

雇用形態が変わると、企業に対して弱くなるだけではない。  
社会に対しても弱くなる。  
金融機関に対しても弱くなる。  
住居市場に対しても弱くなる。  
家族形成や将来設計に対しても弱くなる。

これで、どうして国民が安心して労働力の流動性を受け入れられるだろうか。

正社員を離れた瞬間に、社会的信用まで落ちる。  
派遣になれば信用が下がる。  
非正規になれば将来設計が難しくなる。  
委託や個人事業主になれば、収入があっても不安定に見られる。

これでは、人は動けない。

動くたびに信用を失うなら、それは自由な移動ではない。

労働力の流動性を本当に働く人の自由にするなら、技能のポータビリティだけでは足りない。

社会的信用のポータビリティが必要である。

働き方が変わっても、住まいを借りられる。  
収入が変動しても、信用を評価できる。  
学び直しや転職中でも、生活が壊れない。  
非正規や委託でも、社会保障からこぼれない。  
働き方を変えても、将来設計ができる。

ここまで整って初めて、人は安心して動ける。

企業にとっての流動性だけを高めるなら、制度は簡単である。  
人を採りやすく、切りやすく、外注しやすくすればよい。

しかし、国民にとっての流動性を作るなら、信用を持ち運べる社会が必要になる。

### 6. 流動性は、生活予測性とセットでなければならない

労働力の流動性を高めるなら、生活予測性も同時に高めなければならない。

転職しやすくするなら、転職中の生活をどう支えるのか。  
学び直しを求めるなら、学ぶ時間と費用を誰が持つのか。  
副業や独立を促すなら、社会保障や税務や契約リスクをどう支えるのか。  
派遣や委託を増やすなら、現場の安全や教育や休息をどう守るのか。  
個人事業主を増やすなら、交渉力の弱さをどう補うのか。  
非正規でも社会的信用をどう持てるようにするのか。

ここを見ずに「流動性が大事だ」と言うと、働く人にだけ不確実性が移る。

企業は柔軟になる。  
だが、働く人の生活は不安定になる。

企業は固定費を減らせる。  
だが、働く人は収入、訓練、健康、契約リスクを個人で抱える。

企業は必要な時だけ人を使える。  
だが、人は必要とされない時期を自分で耐えなければならない。

これは、社会全体として本当に効率的なのか。

表面上は効率化に見えるかもしれない。

しかし、働く人の不安が増えれば、消費は弱くなる。  
長期の生活設計もしにくくなる。  
子育ても難しくなる。  
地域に根を張りにくくなる。  
学び直しも、防衛的なものになる。

第6回で書いたように、景気とは一般市場に円が回ることだった。

働く人の生活予測性が壊れれば、一般市場に円は回りにくくなる。

労働力の流動性は、景気の外側の話ではない。

働く人が将来をどう見通せるかは、一般市場そのものに関わっている。

### 7. 内部SLAとつながる

第5回では、外部SLAと内部SLAの話を書いた。

利用者に対して、どの水準のサービスを提供するのか。  
これが外部SLAである。

だが、そのサービスを支える現場の条件はどうなっているのか。  
これが内部SLAの問題である。

外部に対して、早く届けます。  
安く提供します。  
いつでも対応します。  
高品質にします。  
柔軟に応じます。

そう約束するなら、その裏側で働く人の条件も見なければならない。

人員は足りているのか。  
休息はあるのか。  
教育はあるのか。  
安全は守られているのか。  
無理な納期や価格が現場に押し込まれていないか。  
正社員以外の人に負荷が逃げていないか。

外部SLAだけが強くなり、内部SLAがないままになると、現場は壊れる。

そして、労働力の流動性だけが高まると、その負荷はさらに見えにくくなる。

正社員が抱えきれない負荷は、非正規へ流れる。  
非正規が抱えきれない負荷は、派遣へ流れる。  
派遣が抱えきれない負荷は、下請けへ流れる。  
下請けが抱えきれない負荷は、委託へ流れる。  
委託が抱えきれない負荷は、個人事業主へ流れる。

すると、企業の中からは負荷が消えたように見える。

だが、社会から消えたわけではない。

契約の弱い場所へ移っただけである。

これでは、流動性が高まったのではない。

余白のなさが、弱い場所へ流れただけである。

### 8. 正社員だけを見ても足りない

労働市場を考えるとき、正社員だけを見ても足りない。

もちろん、正社員の長時間労働や賃金や転職の問題は重要である。

だが、現代の労働市場は正社員だけでできていない。

非正規。  
派遣。  
下請け。  
委託。  
フリーランス。  
個人事業主。  
ギグワーカー。  
副業人材。

こうした人たちが、現場を支えている。

物流、介護、教育、IT、建設、清掃、警備、制作、配達、事務、販売、保育、地域サービス。

さまざまな領域で、正社員ではない働き手が、サービスの一部を支えている。

ここを見ずに、企業と正社員だけで労働市場を語ると、現実を見誤る。

働く人の Security と Comfort を考えるなら、契約形態を越えて見る必要がある。

正社員だけ守られても、非正規に負荷が逃げるなら意味がない。  
非正規だけ見ても、派遣や下請けに逃げるなら意味がない。  
下請けだけ見ても、委託や個人事業主へ逃げるなら意味がない。

社会全体として、誰がどの負荷を引き受けているのか。

ここを見なければならない。

内部SLAとは、企業の中だけの話ではない。

サービスを支える労働の連鎖全体に対して、どこまでの条件を守るのかという問いである。

### 9. 人手不足を、安い労働力で埋めてよいのか

いま、人手不足が叫ばれている。

人が足りない。  
採用できない。  
現場が回らない。  
店舗を開けられない。  
配送が維持できない。  
介護が足りない。  
建設が足りない。  
農業が足りない。  
IT人材が足りない。

この状況に対して、外国人労働者の受け入れが語られることがある。

ここで注意しなければならない。

問題は、外国人労働者が増えること自体ではない。  
問題は、なぜ安い労働力が必要とされるのかである。

中小企業の現場では、円安による原材料費やエネルギー費の上昇がある。  
価格転嫁の難しさがある。  
多重下請け構造がある。  
慢性的な人手不足がある。

価格を上げられない。  
賃金も上げられない。  
それでも仕事量は維持しなければならない。

この状況に置かれた企業に残される選択肢は、多くない。

自分の取り分を削る。  
事業を縮小する。  
撤退する。  
省人化に投資する。  
サービス水準を見直す。  
それでも足りなければ、今の条件でも働いてくれる人を探す。

ここで、外国人労働の話が出てくる。

これは、外国人を使いたいという単純な選好ではない。

追い込まれた企業にとっての、短絡的だが合理的な最適化である。

だが、その合理性が積み重なると、別の問題が固定化される。

賃金が上がらない構造が温存される。  
技能や生産性への投資が起きにくくなる。  
人材が短期・回転前提になる。  
内部SLAの整備が後回しになる。  
社会的コストが後から膨らむ。

これは、日本人労働者にも、外国人労働者にも、どちらにとっても好ましくない。

問題は移民か排外かではない。

価格転嫁できない円安経済が、安い労働力を最適解にしてしまう構造である。

この構造のまま受け入れを拡大すれば、賃金も生産性も上がらない均衡が固定化される。

労働力の流動性が、企業の人材確保のためだけに進めば、ここに接続される。

人手不足が起きる。  
本来なら賃上げ、待遇改善、省人化、サービス水準見直し、内部SLA整備の圧力がかかる。  
しかし、外から安い労働力を追加できれば、その圧力は薄まる。

これでは、労働市場は一般市民に有利にならない。

企業にとっては助かる。  
だが、働く人の Security と Comfort は強くならない。

### 10. 労働組合だけでは受けきれない領域

かつては、労働者の条件を守る仕組みとして、労働組合が大きな役割を持っていた。

団体交渉。  
団体行動権。  
賃金交渉。  
労働時間の交渉。  
職場環境の改善。

もちろん、今も労働組合は重要である。

だが、現代の労働市場では、労働組合だけで受けきれない領域が広がっている。

非正規。  
派遣。  
業務委託。  
フリーランス。  
個人事業主。  
副業人材。  
プラットフォーム労働。  
外国人労働者。

こうした働き方では、企業と労働者の関係が見えにくくなる。

雇用なのか。  
委託なのか。  
取引なのか。  
実質的な指揮命令があるのか。  
誰が安全配慮を持つのか。  
誰が教育コストを持つのか。  
誰が待機時間や移動時間や準備時間を負担するのか。  
誰が生活支援や相談を担うのか。

境界が曖昧になるほど、働く人の交渉力は弱くなりやすい。

企業対労働者個人では、対等ではない。

この非対称性を放置したまま、労働力の流動性だけを上げれば、働く人は市場に一人で出される。

それを自由と呼んでよいのか。

ここで必要なのは、古い制度に単純に戻ることではない。

労働組合が担ってきた「集団的な交渉力」を、現代の契約形態に合わせてどう再設計するかである。

正社員だけでなく、非正規、派遣、委託、個人事業主、外国人労働者まで含めて、働く人の Security と Comfort をどう守るのか。

これは、次の労働市場の大きな問いである。

### 11. 労働力の流動性が、学び直し市場を作る

労働力の流動性が高まると、学び直し市場も広がる。

リスキリング。  
資格取得。  
キャリアコーチング。  
転職支援。  
副業講座。  
AI講座。  
プログラミング講座。  
ビジネススクール。

これらがすべて悪いわけではない。

学び直しで救われる人はいる。  
新しい技能を得ることは大事である。  
働く人が自分の可能性を広げることは、社会にとっても良い。

だが、ここでも問いが残る。

学び直しは、安心を土台にした選択なのか。  
それとも、不安に追い立てられた防衛行動なのか。

スキルが古くなるから学べ。  
転職できなくなるから学べ。  
AIに負けるから学べ。  
市場価値が下がるから学べ。  
会社は守ってくれないから学べ。

この言い方ばかりになると、学びは自由ではなくなる。

不安処理になる。

本来、学び直しは、働く人が次の可能性を広げるためのものだと思う。

しかし、Security がなければ、学び直しは生活防衛になる。  
Comfort がなければ、働きながら学ぶ余白がなくなる。

時間がない。  
お金がない。  
体力がない。  
家族のケアがある。  
仕事だけで疲れ切っている。  
学んでも社会的信用が回復するとは限らない。

その状態で「学べ」と言われても、人は壊れる。

労働力の流動性を語るなら、学び直しを個人の努力だけにしてはいけない。

学ぶ時間。  
学ぶ費用。  
学び直した後に活かせる場所。  
失敗しても戻れる仕組み。  
年齢で切られない市場。  
雇用形態が変わっても失われない信用。

そこまでセットで考える必要がある。

### 12. 流動性は、企業の投資責任を消してよいのか

労働力の流動性が高まると、企業は外から人材を調達しやすくなる。

これは便利である。

だが、それによって企業の育成責任が薄くなっていないか。

必要な人材は市場から採ればよい。  
即戦力を採ればよい。  
合わなければ入れ替えればよい。  
教育は個人がやればよい。  
資格は自分で取ればよい。  
経験は外で積んできてくれればよい。

この考え方が強くなると、企業は人材を育てる場所ではなく、人材を消費する場所になっていく。

しかし、社会全体で見れば、誰かが人を育てなければならない。

新人を育てる。  
未経験者に機会を与える。  
中堅を鍛える。  
熟練者の技術を継承する。  
失敗を吸収する。  
現場で学ぶ時間を作る。

これらはコストである。  
だが、社会にとっては投資でもある。

企業が人材育成を外部化し続けると、短期的には効率的に見える。  
しかし、長期的には技能の土台が痩せる。

どこかで誰かが育てた人材を奪い合うだけになる。  
未経験者は入りにくくなる。  
若い人は育たない。  
中高年は更新の機会を失う。  
現場の継承が細る。

これは、一般市場を弱くする。

企業が長期で人を育てられない社会では、働く人も長期で生活を組み立てにくい。

労働力の流動性は、企業の育成責任を消すための言葉であってはならない。

### 13. 人が動ける社会には、戻れる場所がいる

人が動ける社会には、戻れる場所が必要である。

転職できる。  
学び直せる。  
独立できる。  
副業できる。  
地域を移れる。  
働き方を変えられる。

これは大事である。

だが、動けることと、戻れないことは違う。

失敗したら終わり。  
病気になったら終わり。  
介護が始まったら終わり。  
子育てで離れたら戻れない。  
年齢を重ねたら市場から外れる。  
一度非正規になったら戻れない。  
一度個人事業主になったら保障が薄い。  
一度社会的信用を落としたら回復しにくい。

これでは、人は動けない。

本当に人が動ける社会には、戻れる場所がいる。

失敗しても戻れる。  
学び直して戻れる。  
育児や介護の後に戻れる。  
病気の後に戻れる。  
地域を変えても戻れる。  
違う働き方から戻れる。  
一度雇用形態が変わっても、社会的信用を取り戻せる。

この「戻れる場所」は、Security である。

そして、戻った先で壊れずに続けられる条件は、Comfort である。

労働力の流動性を本当に働く人の自由にするなら、この二つが必要になる。

人を動かすだけなら簡単である。

人が動けるようにするには、社会の側に受け止める設計が必要である。

### 14. 減速のイノベーションから見た労働市場

減速のイノベーションは、労働力の流動性を否定しない。

人が動けることは大事である。  
合わない場所から離れられることも大事である。  
技能を持って別の場所へ移れることも大事である。  
企業が新しい事業に必要な人材を集めることも大事である。

だが、減速のイノベーションは、労働力を単なる調達資源としては見ない。

働く人は、生活者でもある。  
家族を持つ人でもある。  
地域で暮らす人でもある。  
消費者でもある。  
学ぶ人でもある。  
介護する人でもある。  
次の世代を育てる人でもある。

働く人の Security と Comfort が壊れれば、一般市場も壊れる。

不安定な労働は、不安定な消費を生む。  
不安定な消費は、企業の長期投資を弱くする。  
企業の長期投資が弱まれば、雇用も育成も細る。  
その結果、さらに労働市場が不安定になる。

これは悪循環である。

減速のイノベーションが考えたいのは、この悪循環を断つことである。

労働力を流動化するなら、同時に安心の土台を作る。  
人が動ける自由と、動いても生活が壊れない Security を両立させる。  
働き続けても壊れない Comfort を用意する。  
雇用形態が変わっても社会的信用を持ち運べるようにする。  
企業が人材を消費するのではなく、育て、活かし、必要に応じて移れるようにする。

それが、労働市場における減速のイノベーションではないかと思う。

### 15. 次に問うべきは、誰が内部条件を守るのか

ここまで考えると、次の問いが出てくる。

誰が、内部条件を守るのか。

外部SLAは、利用者や顧客に見えやすい。

何日で届ける。  
何時間で対応する。  
いくらで提供する。  
どの品質で提供する。

これは市場で見えやすい。

だが、内部SLAは見えにくい。

何人で回しているのか。  
どれだけ休めているのか。  
誰が教育しているのか。  
誰が待機しているのか。  
誰が夜間対応しているのか。  
誰が責任を負っているのか。  
どの契約形態の人に負荷が流れているのか。  
その人たちの社会的信用はどう扱われているのか。

ここは見えにくい。

だからこそ、放置されやすい。

企業に任せるだけでよいのか。  
労働者個人に交渉させるだけでよいのか。  
労働組合だけで受けられるのか。  
行政がどう関与するのか。  
業界ごとのルールが必要なのか。  
発注者責任をどう見るのか。  
プラットフォームの責任をどう見るのか。  
外国人労働者の受け入れをどう位置づけるのか。  
信用のポータビリティをどう作るのか。

この回だけで答えは出せない。

だが、方向は見えてきた。

労働力の流動性を高めるなら、内部条件も同時に見える化しなければならない。

人が動ける社会を作るなら、人を動かす側の都合だけではなく、動いた人が壊れずに暮らせる条件を整えなければならない。

### おわりに：流動性を、安心の土台から考える

労働力の流動性は、必要である。

一つの会社に縛られすぎる社会は、息苦しい。  
合わない職場から離れられることは大事である。  
技能を持って別の場所へ移れることも大事である。  
企業が新しい事業に必要な人材を集めることも必要である。

だが、流動性には主語がある。

人が動ける社会なのか。  
人を動かせる社会なのか。

ここを分けなければならない。

企業にとっての流動性だけを高めれば、労働力は調達しやすくなる。  
固定費を変動費化できる。  
教育や待機のコストも外へ逃がせる。  
人手不足も、より安い労働力の追加で処理しやすくなる。

しかし、それでは働く人の生活予測性は壊れる。

非正規、派遣、委託、個人事業主、外国人労働者に負荷が流れる。  
雇用形態が変われば、社会的信用も落ちる。  
学び直しは不安処理になる。  
子育てや地域生活は難しくなる。  
企業も国内需要を信じにくくなる。

だから、労働力の流動性は、安心の土台から考えなければならない。

仕事を失ってもすぐに生活が壊れない Security。  
働き続けても心身が削られすぎない Comfort。  
雇用形態が変わっても失われない社会的信用。  
学び直しや転職を選べる余白。  
家庭や地域生活を壊さずに働ける条件。  
契約形態を越えて、負荷が弱い場所へ逃げない設計。

人が動ける社会と、人を動かせる社会は違う。

減速のイノベーションが目指すべきなのは、人を市場に放り出す流動性ではない。

人が動ける自由と、動いても壊れない安心を両立させる労働市場である。

**本文との共通点**

**研究者**  
ガイ・スタンディング

スタンディングのプレカリアート論は、不安定な雇用や生活基盤の中で、安定や保障を欠いた人々が増えていることを論じる。プレカリアートは、単に低所得というだけでなく、安定、将来予測性、職業的アイデンティティなどを欠いた階層として扱われている。

**本文との差分**  
本文は、不安定化そのものを描くだけではなく、「労働力の流動性」という前向きに見える言葉が、企業側の調達可能性として先に実装されると、働く人の Security と Comfort が崩れるという構造に焦点を当てている。また、社会的信用の低下、信用のポータビリティ、内部SLAという観点から、流動化された働き手が労働市場だけでなく社会全体に対して弱くなる点を強調している。

### 4. 研究名・資料

**研究者・主体**  
OECD

**本文との共通点**  
OECDは、日本の労働市場について、非正規雇用の多さや二重構造、社会保険や訓練の拡充、労働供給や生産性向上の必要性などに触れている。2024年のOECD資料でも、日本の雇用は高齢者や女性の就業増によって支えられていること、非正規雇用の課題、社会保険や訓練の拡充が重要であることが示されている。

**本文との差分**  
OECDの議論は、労働供給、生産性、雇用保護、訓練、社会保険といった政策課題として整理される。本文はそこからさらに、労働力の流動性が「企業が人を動かせる自由」として先に機能していないかを問うている。特に、非正規、派遣、委託、個人事業主などに負荷が流れたとき、社会的信用まで落ちるなら、労働者は安心して流動性を受け入れられないという点が本文側の焦点である。

### 5. 研究名・資料

Recruiting Immigrant Workers: Japan 2024

**研究者・主体**  
OECD

**本文との共通点**  
OECDの日本の外国人労働者受け入れに関する報告では、日本の労働移民制度が日本の雇用主による需要に強く結びついていることが示されている。報告では、日本への労働移民は雇用主側の需要に駆動されており、どの制度でも日本の雇用主からの仕事のオファーが必要であると説明されている。

**本文との差分**  
本文は、外国人労働者受け入れそのものの是非を論じるのではない。焦点は、円安、価格転嫁の難しさ、多重下請け構造、人手不足が重なったとき、安い労働力が「短絡的だが合理的な最適化」として選ばれやすくなる構造にある。外国人労働者が悪いのではない。問題は、価格転嫁できない構造が、賃上げ、技能蓄積、省人化、内部SLA整備ではなく、安い労働力への依存を最適解にしてしまう点である。

### 6. 本文側の独自概念

内部SLA

**位置づけ**  
本文側の独自概念

**本文との共通点**  
本文では、外部SLAを「利用者や顧客に対して約束するサービス水準」とし、内部SLAを「そのサービスを支える現場の条件」として扱っている。外部に対して早い、安い、便利、高品質を約束するなら、その裏側で働く人の人員、休息、教育、安全、契約条件、社会的信用まで見なければならない。

**既存研究との差分**  
既存のSLAは、主にサービス提供者と利用者の合意や品質保証として語られることが多い。本文はそれを労働市場へ押し広げ、サービス水準の裏にある労働条件、契約形態、下請け、委託、個人事業主、外国人労働者まで含めた「支える側の条件」として再定義している。ここでは、内部SLAは単なる企業内管理ではなく、労働の連鎖全体を壊さないための社会設計として扱われている。

### 7. 本文側の独自概念

信用のポータビリティ

**位置づけ**  
本文側の独自概念

**本文との共通点**  
本文では、労働力の流動性には技能のポータビリティだけでなく、社会的信用のポータビリティが必要だと考えている。働き方が変わっても住まいを借りられること、収入が変動しても信用を評価できること、非正規や委託でも社会保障からこぼれないこと、働き方を変えても将来設計ができることが必要である。

**既存研究との差分**  
労働市場改革では、技能の持ち運び、リスキリング、転職可能性が語られやすい。本文はそこに、住宅、金融、家族形成、社会的評価まで含む「信用の持ち運び」を加えている。雇用形態が変わるたびに社会的信用が落ちるなら、人は安心して動けない。したがって、労働力の流動性を一般市民に有利なものにするには、信用のポータビリティが不可欠である、という点が本文側の押し広げである。

### 8. 本文側の独自概念

労働市場における減速のイノベーション

**位置づけ**  
本文側の独自概念

**本文との共通点**  
本文全体の中心概念である。ここでいう労働市場における減速のイノベーションは、労働力の流動性を否定するものではない。人が動ける自由と、動いても生活が壊れない Security、働き続けても壊れない Comfort、雇用形態が変わっても失われない社会的信用を両立させる設計である。

**既存研究との差分**  
既存の労働市場改革では、柔軟性、雇用保護、職業訓練、非正規対策、外国人労働者受け入れなどが個別に論じられる。本文は、それらを「企業が人を動かせる社会」ではなく「人が動ける社会」に再設計するという観点でつなぎ直している。減速のイノベーションは、人を市場に放り出す流動性ではなく、人が生活を壊さずに選び直せる労働市場を作るための概念である。
