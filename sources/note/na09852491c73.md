# 最近、正解を求める空気が強くなっている気がする。

> 公開本文の正本：https://note.com/shirokuma1970/n/na09852491c73
>
> このファイルは文脈解析用の取得時スナップショットです。

何かが起きるたびに、 「本当はどうなのか」 「誰が正しいのか」 「結論はどれなのか」 と、すぐに答えが欲しくなる。

答えがあれば安心する。 立場がはっきりすれば落ち着く。

曖昧さより断定のほうが拡散されやすい。

でも、それは誰かの性格の問題なのだろうか。

不確実性は増え続けている。 経済も技術も国際情勢も、常に揺れている。

その上で、私たちは常時接続の空間にいる。 発言は記録され、評価は数値化され、 失敗は掘り返される。

不確実で、可視化され、評価され続ける社会。

その中で「正解はある」と思いたくなるのは、 むしろ自然な反応かもしれない。

正解があると思えれば安心できる。 世界は理解可能で、誰かが舵を握っていると感じられる。

けれど。

正解がないかもしれない、という前提を 引き受けることなしに、 社会は本当に安定するのだろうか。

状況は変わる。 仮説は更新される。 最善は、いつも暫定だ。

それでも私たちは、 立場のある人に「迷うな」と求め、 専門家に「断言せよ」と期待し、 そして同時に、 その断言を裏切りと呼ぶ。

もしかすると、 SNSが荒れているのは、 誰かが愚かだからではなく、

私たちが「不確実であること」を 許せなくなっているからなのかもしれない。

正解があることは、安心につながる。 けれど、正解がない可能性を忘れることは、 別の不安を育ててはいないだろうか。

この構造の中で、 私たちはどんな態度を選んでいるのだろう。

そして——

自分は本当に、 「正解を急ぐ側」に立っていないと言い切れるだろうか。
