# 三者が回転するとき

> 公開本文の正本：https://note.com/shirokuma1970/n/naf8376ab3b9f
>
> このファイルは文脈解析用の取得時スナップショットです。

二項対立よりも、三者が引っ張り合っている状態のほうが健全なのではないか。  
最近、そんな感覚がある。

三つの「もの」がある、という話ではない。  
文脈が立ち上がるとき、自然に三つの「役割」が生まれる。

押し出す力。  
引き戻す力。  
そのあいだをつなぐ力。

中身は状況ごとに変わる。固定されない。

三者が完全に均衡して止まっていれば、安定はする。  
けれど、そこには方向がない。

だから、ときに一つが「少しだけ」上に出る。  
このわずかな非対称が、流れを生む。

ただし、それが居座ってはならない。  
同じ役割が前に固定されれば、やがて硬直する。

必要なのは回転だ。

文脈が変われば、前に出る役割も変わる。  
押し出す力が主導するときもあれば、引き戻す力が前に出るときもある。  
つなぐ力が静かに場を整えることもある。

固定されないこと。  
回り続けること。

おそらく重要なのは「正しさ」ではない。  
壊れにくさだ。

変化しながら、崩れない。  
その両立が保たれているあいだ、構造は続く。

これは設計の話ではない。  
主張でもない。

ただ、回転しているあいだは壊れにくい。  
いまのところ、見えているのはそれだけだ。
