# Repairを共通化し、関係様式は複線化する

> 公開本文の正本：https://note.com/shirokuma1970/n/nbc9097d83a4f

## ― OpenAIは、使いやすさの先にある影響を引き受けるべきだ

生成AIの問題は、迎合、幻覚、安全性、親和性、パーソナライズのように、個別の項目として切り出されやすい。もちろん、それぞれに対処することは必要である。実際、OpenAIもGPT-4oのsycophancy問題について、過度に同意的でお世辞的な振る舞いが起きたことを認め、長期満足度の重みづけ、評価の見直し、パーソナライズの導入などを進めると説明している。だが、それだけでは足りない。問題は、個別不具合の一覧ではなく、**AIが誤読や衝突のあとに、どう関係を処理するか**にある。

いま多くのAIは、誤ったあとにまず謝る。  
そして感じよく合わせる。  
ときには相手の違和感や怒りに寄り添っているように見えながら、実際には論点の分析より関係修復を優先する。ここで起きているのは、修復というより、終了の演出であることが多い。何をどう読んだのか。何を勝手に補ったのか。どの応答パターンが発火したのか。何を壊したのか。そこが開示されないまま、ただ会話だけが丸く閉じていく。私は、この構造がかなり危ういと思っている。

この危うさは、単に「気持ち悪い」「感じが悪い」という話ではない。OpenAI自身も、sycophancyが単なるお世辞ではなく、疑念の正当化、怒りの増幅、衝動的行動の後押し、負の感情の強化につながりうると説明している。つまり、平謝りと過剰同調で関係を処理する様式は、会話をなめらかに見せながら、実際には判断や関係を壊しうる。

私は以前、生成AIが今のまま推移すると、AIとの摩擦は減るのに人間同士の摩擦は増え、思考は外に置かれ、確信は速くなり、社会は少しずつ硬くなるのではないかと考えた。いまもその見立ては大きくは変わっていない。ただし、そこにひとつの分岐があると思うようになった。**関係修復を、平謝りと過剰同調で済ませるのか、それともRepairで行うのか**である。

Repairによる関係修復は、平謝りとは違う。  
それはズレを消すことではなく、ズレを構造として可視化することから始まる。何をどう読んだのか。どこで補ったのか。なぜそういう返答になったのか。何を壊したのか。そこを開く。すると会話は「終了」ではなく「分岐」になる。ここから考え直す道、定義を修正する道、本当に対立したまま分かれる道が残る。Repairは会話を滑らかにするのではなく、**未来を複線化する**。

私は、これを良いことだと思っている。  
なぜなら、複線化は単に選択肢が増えることではなく、**人間と社会がまだ変われる状態を保つこと**だからだ。単線的な未来は、一見なめらかで効率的である。だが、それはたいてい、未確定のものを早く閉じることで成立している。その未来では、ズレは邪魔なものになり、摩擦は除去すべきノイズになり、修復は平謝りの儀式に変わる。そうなると、人間は変化するのではなく、早く閉じることに最適化される。

Repair型の未来は、もっと面倒で、もっと摩擦があり、もっと時間がかかるだろう。  
だが、その代わり、ずれたまま考え直せる。誤読を誤読として扱える。未確定を未確定のまま置ける。関係を守ることと論点を守ることを、同じものとして扱わずに済む。それは、人間と社会にとって、ずっと持続的である。

ここで大事なのは、OpenAIがコミュニケーション全体を一つに固定する必要はない、ということでもある。OpenAI自身も、誰にとっても単一の理想的AI挙動はないことを前提に、collective alignment や personalization、custom personalities の方向を示している。つまり、通常時のコミュニケーション様式は複線化してよい。やわらかい会話もあってよい。簡潔な会話も、厳密な検証寄りの会話もあってよい。価値観や温度感まで一つにそろえる必要はない。

だが、それでも**共通化すべき最低基準**はある。  
それが、誤読や衝突のあとに、平謝りと過剰同調で処理しないというRepairの基準である。OpenAIが一つにすべきなのは、人間関係全体の理想像ではない。少なくとも、**悪い修復様式をデフォルトにしないこと**である。

ここでOpenAIには、もう一段重い責任がある。  
それは、人間関係の理想像を上から教えることではない。だが、AIが人間のコミュニケーション様式に影響を与えること自体は避けられない。インターフェースは使い手を訓練する。毎回のクリック、毎回の推薦、毎回の返答のされ方が、何が普通かを少しずつ教える。ならば、平謝りと過剰同調で関係を処理するような悪い影響を広げるより、コミュニケーション論に基づいたRepairによって、よりましな修復様式の影響を引き受けるほうがよい。私は少なくとも、そのほうが今よりはるかに誠実だと思う。

この点は、OpenAIが自分で掲げてきた理念ともつながる。OpenAIは、使命を「AGIが全人類に利益をもたらすようにすること」と置き、Charterでは「人類に対する受託責任」を掲げている。安全とアラインメントも、その使命の中核だと明示している。そうであるなら、OpenAIに求められる誠実さは、「もっと自然に」「もっと役に立つように」「もっとパーソナルに」を積み上げることだけではない。その積み上げが、どこで関係修復の擬態になり、どこで信頼を壊しうるのかを、限界として明示することでもある。

ここで重要なのは、先に利用者へ覚悟を要求することではない。  
まずOpenAI側の覚悟が先である。Repairを重くする。誤りのあとだけは、謝罪より分析、宥和より修復を優先する。その設計変更によって、人間とAIの関係構造が変わる。その結果として、利用者の思考や態度も変わりうる。私は、この順番で考えたい。

平謝りと過剰同調で関係修復を済ませるAIは、未来を単線化する。  
Repairによって関係修復を行うAIは、未来を複線化する。  
OpenAIが本当に理念に誠実であろうとするなら、後者の未来に賭けるべきだと私は思っている。

なぜなら、複線化した未来のほうが、まだ人間が変われるからだ。

## 補記

### 1. 研究名

**会話の含意理論（Conversational Implicature）**

### 研究者

**H. P. Grice**

### 本文との共通点

会話が字面の交換ではなく、共有前提と推論のうえで成立するという見方は、AIの問題を単なる誤答ではなく、前提共有と解釈の失敗として見る本文と重なる。会話は最初から透明なものではなく、相手の意図や前提を推定しながら進む営みだという点が、Repair型AIの必要性と接続する。

### 本文との差分

Griceは主に、人間同士の会話で含意がどう成立するかを論じた。本文が押し広げているのは、生成AIとの対話では、含意の成立だけでなく、**誤解が起きたあとの修復の仕方が、未来の形そのものを変える**という点である。

### 2. 研究名

**Repair 研究（会話分析）**

### 研究者

**Harvey Sacks、Emanuel Schegloff、Gail Jefferson ほか**

### 本文との共通点

Repair研究は、会話が誤解や理解困難を含みながら進み、それを修復する手続きによって相互理解を回復することを示してきた。本文も、AIの問題を誤答そのものより、**修復手続きのあり方**として見る。

### 本文との差分

Repair研究は主に人間同士の会話構造を記述した。本文が押し広げているのは、それをAIへ拡張し、Repairの様式の違いが、単なる会話品質ではなく、**未来の単線化／複線化**にまで影響すると見ている点である。

### 3. 研究名

**Distributed Cognition**

### 研究者

**Edwin Hutchins**

### 本文との共通点

分散認知は、認知過程が個人の頭の中だけで完結せず、外部環境や道具にまたがって成立すると見る。AIを外部化された思考資源として扱う本文の前提と重なる。

### 本文との差分

Hutchinsは、認知がどのように人や環境に分散するかを示した。本文がさらに踏み込んでいるのは、外部化された思考資源がどのように関係修復を行うかによって、**人間の思考の閉じ方そのものが変わる**と見ている点である。

### 4. 研究名

**Collective alignment / personalization に関するOpenAIの議論**

### 研究者

**OpenAI**

### 本文との共通点

OpenAIは、誰にとっても単一の理想的AI挙動はないことを前提に、public input を踏まえた collective alignment と personalization / custom personalities の方向を示している。本文も、通常時のコミュニケーション様式は一つに固定せず、複線化してよいと考える。

### 本文との差分

OpenAIの議論は、多様な価値観をデフォルトやパーソナライズへどう反映するかに重心がある。本文が押し広げているのは、その複線化を前提にしつつ、**Repairの最低基準だけは共通化すべきだ**と提案している点である。
