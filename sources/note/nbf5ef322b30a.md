# 今のままでは、10年後に現場の中核層が擦り切れる

> 公開本文の正本：https://note.com/shirokuma1970/n/nbf5ef322b30a
>
> このファイルは文脈解析用の取得時スナップショットです。

私は、今の日本で本当に危ないのは、物価高そのものでも、人手不足そのものでも、賃上げが足りないことそのものでもないと思っている。  
もっと深いところにある。  
**あと10年ほどで、現役世代の現場の中核層が擦り切れること**だ。

しかもこれは、単に人が減るという話ではない。  
日本社会を、平時だけでなく非常時にも持ちこたえさせてきた層が抜けていく、という話である。

私は前にも書いた。  
リーマン・ショックやコロナ禍を日本が比較的持ちこたえられた背景には、制度や政策だけではなく、日本人のあいだで長く形成されてきた行動様式や持ちこたえ方があったのではないか、と。  
我慢、調整、場を壊さない感覚、相互期待、責任感。  
そうした、制度化されきらない行動様式が、日本社会の危機耐性を支えていたのではないか、と。

そして私は、その中核を担ってきたのは、バブル期から2000年直前までに社会人になった人たちだったと思っている。  
この世代は、まだ終身雇用の残滓を身体感覚として知っている。  
企業共同体の空気も、現場の責任の飲み込み方も、平時には言語化されにくい高コンテキストな調整も、かなり深く知っている。  
だから、危機のときに持ちこたえられた。

だが、その世代はそろそろ退役していく。  
完全に抜けるまでにはもう少しかかるだろう。  
しかし、社会の現場を実務で支える中核としては、あと10年ほどでかなり薄くなるはずだ。  
そうなると、次の世代が前に出てくる。  
だがその世代は、表層の価値観としては流動化・個人化・欧米化した言葉の中で育ち、社会に出た時点で終身雇用を前提として知らない。  
それにもかかわらず、現場では依然として、日本的な調整や責任の引き受けが求められる。  
この板挟みは、相当きつい。

平時はまだいい。  
マニュアル化、制度化、低コンテキストなコミュニケーションで、ある程度は回せる。  
だが、緊急時は違う。  
災害、供給網の寸断、突発的なトラブル、制度の外での調整。  
こういう場面では、マニュアルの外で優先順位を変え、関係を壊さず、責任を引き受け、全体を回復へ寄せる力が要る。  
そこでは、平時には見えにくかった高コンテキストな調整能力が一気に必要になる。  
その負担は、間違いなく現場の中核層に集中する。

私は、東日本大震災のときに被災した工場を素早く復旧したような日本の強みは、今後そのままでは期待できなくなると思っている。  
設備や技術だけの話ではない。  
言葉にならない前提を共有したまま、関係先まで含めて一気に動く力である。  
東日本大震災後の企業復旧を扱った研究でも、被災企業のネットワークや社会関係資本が資源の迅速な動員を可能にし、予想以上に速い操業再開を支えたと論じられている。  
つまり、早い復旧を支えていたのは、単なるマニュアルや設備だけではなく、関係性と意味の共有だった。

福島第一原発の事故対応も同じだ。  
あの時、被害の拡大を食い止めたのは、設備や手順だけではない。  
東電の現場、自衛隊、東京消防庁をはじめとする人たちが、文字通り命がけで対応した。  
官邸の事故調報告書やIAEAの報告でも、現場での注水、冷却、電源回復、放水などの対応が、極限状況のなかで続けられたことが確認できる。  
私は、ここにも日本の強みが出ていたと思う。  
平時には見えにくい責任感、関係の維持、全体を止めないための引き受け。  
そうしたものが、最後のところで被害拡大を食い止める力になっていた。

ところが、今の経団連にはそうした危機感が全く感じられない。  
彼らが前に出しているのは、労働移動、リスキリング、多様な人材活用、ジョブ型、外国人材、DX/GX、持続的賃上げといった、構造の組み替えメニューばかりだ。  
何を残すかではなく、どう回すか。  
何が失われるかではなく、どう再編するか。  
そこに重心がある。  
日本社会を支えてきた持ちこたえ方そのものが、あと10年ほどで切れるかもしれない、という危機感はほとんど見えない。  
経団連の提言群でも重心は労働移動、学び直し、多様な担い手、成長分野へのシフトにあり、文化的土台や危機時の復元力の継承は中心テーマに見えない。

連合も同じだ。  
経団連より人間の側を見ているようには見える。  
だが、見ているのは日本の文化ではない。  
前に出ているのは、失業予防、雇用調整助成金、社会保障、能力開発、処遇改善、外国人労働者の保護、男女平等、多様性といった、かなり欧米的な労働者保護の文脈だ。  
それ自体を否定したいわけではない。  
だが、それは日本の土着の文脈や、危機時に発現する日本的な持ちこたえ方を中心に据えた発想ではない。  
経団連が市場と競争の言葉で社会を再編しようとしているのに対し、連合は権利と包摂の言葉で社会を再編しようとしている。  
どちらも、日本の文化を主軸にはしていない。  
連合のビジョンも「働くことを軸とする安心社会」を掲げ、包摂、公正、ディーセント・ワーク、社会保障を前に出している。

では政府はどうか。  
高市首相は、「日本列島を、強く豊かに」という言葉を掲げている。  
地域の生活基盤、産業、医療、福祉、教育、働く場所を全国に整えようという意味では、確かに長期戦略に見える。  
だが、それで**10年後の現役世代の中核層の疲弊を防げるか**と問われれば、私は防げそうにないと思う。  
見えているのは、今の負担、今の暮らし、今の投資、今の成長だ。  
だが、あと10年ほどで現場の中核層が擦り切れ、日本社会の持ちこたえ方そのものが切れるかもしれない、という危機までは、中心には見えていない。  
前に出ているのは、労働市場改革、賃上げ、地方創生、防衛、防災、供給力強化であって、現場の中核層の消耗と継承断絶への手当てではない。  
施政方針や所信表明でも、重心は国力強化、地方の再生、投資、現役世代の負担感の改善に置かれている。

私はここに、かなり大きな危機感を持っている。  
しかも、これは単なる懐古ではない。  
昔に戻れと言っているのでもない。  
外国人を受け入れるなと言っているのでもない。  
欧米の考えを取り入れるなと言っているのでもない。  
問題にしているのは、**日本社会を支えてきた土台を理解しないまま、その上の構造だけを組み替えること**だ。  
それをやれば、平時は回るかもしれない。  
だが、非常時には無理が出る。  
そしてその無理は、間違いなく次の現役世代の中核層に落ちる。

私は、土着の文化や文脈はそう簡単にはなくならないとも思っている。  
若い頃は欧米的な語彙で考えていても、生活圏や関係性がまだ日本の文化の中にある以上、人は40代以降、責任や経験を重ねる中で、だんだんその文脈で行動するようになることがある。  
私自身がそうだったし、過去の人たちも多かれ少なかれそうだったと思う。  
だから、表層だけ見て「もう日本の文脈は消えた」と判断するのも浅い。

しかし、私が本当に心配しているのは、そこではない。  
日本の文化や文脈がなくならないからこそ、心配している。  
なくならないからこそ、最後のところで人は日本的に振る舞ってしまう。  
空気を読み、責任を飲み込み、関係を壊さないように調整し、全体が止まらないように無理を引き受ける。  
問題は、その力を社会、会社、労組、政府が制度として担保しないまま、個人の側だけに残してしまうことだ。

そうなると、日本の文化は守られるのではない。  
**個人の消耗によって延命される**ことになる。  
社会は欧米的に流動化する。  
会社は低コンテキスト化し、労組は権利と包摂の言葉で語り、政府は運営と再配置を進める。  
だが非常時になれば、最後は日本的に頑張ることを個人に要求する。  
この構図が一番危ない。

私は、日本文化の消滅を怖がっているのではない。  
**日本文化の責任倫理だけが、制度保障なしで個人に押し付けられること**を怖がっている。  
それでは文化は残る。  
だが、残り方がすでに不健康だ。  
なくならないから安心なのではない。  
なくならないのに制度が支えないから、個人がすり減るのである。

その意味では、思い切って欧米的な思考になったほうがまだ安心感がある、という感覚もわかる。  
最初から低コンテキストで、契約や制度や権利で割り切る社会なら、自分がどこまで背負うのかがまだ見えやすい。  
だが、日本的な文脈が残っている社会で、その文脈を制度が支えず、構造だけを流動化するなら、一番きついところだけ個人が背負わされる。  
それは、文化を守ることではない。  
文化の名のもとに、個人を擦り減らすことである。

国が担保すべきなのは、まず Security だ。  
人が簡単に終わらないこと。  
過剰な不安で潰れないこと。  
社会の土台が崩れにくいこと。  
そのうえで、都市や家庭が Comfort を持てる場所にならなければならない。  
居心地、関係性、余白、揺れながら生きられる感触。  
それがなければ、人も社会も持続しない。  
今の経団連も連合も政府も、この分業をきちんと見ているようには見えない。  
経団連は構造を見ている。  
連合は労働者保護を見ている。  
政府は運営を見ている。  
だが、日本社会の持続可能性を100年単位で見た時に、あと10年ほどで現場の中核層が擦り切れるという危機は、誰の中心にも見えていない。

だから、私はこれをわざわざ書く。  
このままでは、次の現役世代の中核層は、これまで以上に苦しむことになる。  
自分のアイデンティティと社会からの要求との板挟みで、平時はマニュアルで回し、非常時には文脈を読んで責任を飲み込むことを求められる。  
しかも、その負担を支えてくれる土台は薄くなっている。  
それでも社会は、彼らに持ちこたえることを要求するだろう。  
私は、そこにかなり強い危機感を持っている。

もし日本社会にまだ独自の強さが残っているのだとしたら、今やるべきことは、その強さを前提にしながらも、それにただ寄りかかることではない。  
その強さが失われる前に、次の世代が擦り切れないための土台をつくることだ。  
そこに本気で向き合わないなら、日本は平時には整っていても、非常時には持ちこたえられない社会になる。  
**しかもその時、日本の文化は消えていない。消えていないまま、個人を削りながら残る。**  
それが、私がいま一番怖がっている未来である。

## 補記

### 1) 東日本大震災後の工場復旧研究との接点

**共通点**

* 危機時の復旧力は、マニュアルや設備だけでは説明できない
* 企業間ネットワークや社会関係資本が復旧を支える
* 非常時には、平時に見えにくい共有前提や関係性が効く
* 日本の強みは、形式知だけでなく暗黙知の側にある。

**差分**

* 研究は個別企業や供給網の分析が中心で、文明論までは行かない
* 次世代への継承危機や現役中核層の疲弊は中心課題ではない
* 企業復旧の分析であって、日本社会全体の持続可能性の議論ではない

### 2) 福島第一原発の現場対応との接点

**共通点**

* 非常時には、マニュアル以上に現場の判断と責任の引き受けが問われる
* 東電の現場、自衛隊、東京消防庁などの対応は、極限状況での持ちこたえ方を示している
* 被害拡大を食い止めたのは、技術だけでなく人間の側の踏みとどまりでもある。

**差分**

* 原発事故対応は極限状況であり、一般企業の復旧とは条件が違う
* 公式報告は事実関係と対応経過の整理が中心で、文化論には踏み込まない
* ここで私が見ているのは、そこから読み取れる日本的な現場対応の性質である

### 3) 経団連の将来像との接点

**共通点**

* 人口減少と供給制約の深刻さを見ている
* 現状維持では立ち行かないという認識を持っている
* 人材・地域・産業の再編が必要だと考えている

**差分**

* 経団連は「どう回すか」を見ている
* 私は「何によって持ちこたえてきたか」を見ている
* 経団連は構造再編を前に出すが、文化的土台や危機時の復元力の継承は中心にない
* だから私には、危機感がかなり浅く見える。

### 4) 連合の将来像との接点

**共通点**

* 壊れない社会の必要性を見ている
* 労働者の生活基盤や安心を重視している
* 過度な市場化の危険には一定の感度がある

**差分**

* 連合は労働者保護と包摂の制度を見ている
* 私は日本の土着の文脈や持ちこたえ方を見ている
* 連合の語彙は欧米型の権利・包摂・平等に寄っている
* 日本文化の強みをどう継承するか、という問いには十分届いていない。

### 5) 政府との接点

**共通点**

* 地方、産業、現役世代の負担を重視している
* 長期戦略の必要性を認識している
* 10年単位の国土運営や経済運営は見ている

**差分**

* 政府は「日本列島をどう強く豊かにするか」を見ている
* 私は「日本が100年単位でどう持続するか」を見ている
* 政府は運営と再配置を見ている
* 私は、現場の中核層が擦り切れた後に日本社会が持ちこたえられるかを見ている。

## この立場の核心

* 日本の強みは、平時の合理性より非常時の持ちこたえ方に出る
* その強みは、バブル期から2000年直前までに社会人になった世代が中核で支えてきた
* その世代があと10年ほどで薄くなることは、かなり大きな断層になる
* 東日本大震災後の工場復旧や福島第一原発の現場対応は、その強みが実際に働いた具体例である。
* 経団連、連合、政府はいずれも、この危機を中心には見ていない
* このままでは、次の現役世代の中核層に過剰な負担が集中する
* 日本の持続可能性を考えるなら、その負担を受け止める Security の再設計が必要である

この文章は、昔に戻れと言っているのではない。  
また、外国や外来の考えを拒絶しろと言っているのでもない。  
そうではなく、日本社会を支えてきた土台を理解しないまま構造だけを組み替えることの危険を言っている。  
日本の強みは永遠ではない。  
だからこそ、まだ残っているうちに、それを次の世代が擦り切れずに引き受けられる条件を整えなければならない。
