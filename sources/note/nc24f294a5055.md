# なぜAI企業はコミュニケーション論に行かないのか

> 公開本文の正本：https://note.com/shirokuma1970/n/nc24f294a5055
>

## ― 経済的圧力の前に、会話を管理可能な対象へ作り替えている

## 本文

生成AIを見ていると、不思議なことがある。  
各社とも会話AIを作っている。  
にもかかわらず、会話そのものを正面から扱っている感じがあまりしない。

自然な受け答えは重視している。  
親しさも、信頼も、継続性も気にしている。  
だが、それでも主題化されているのは「会話」そのものではない。  
OpenAIはモデル行動の規範と統治を前に出し、Googleは個人化されたアシスタント関係を前に出し、Anthropicは憲法と人格の設計を前に出している。  
つまり三社とも会話を無視しているのではない。  
**会話を、そのままではなく、別の管理可能な対象に言い換えている**のである。

OpenAIは、会話をまず「どう振る舞うべきか」という問題として扱う。  
真理探究を支えること。  
独自のアジェンダを持たないこと。  
迎合しすぎないこと。  
ここで重視されているのは、会話のねじれや誤解そのものより、**AIの応答手続きの適切さ**である。

Googleは、会話を「どのような関係を作るか」という問題として扱う。  
ユーザーを理解すること。  
文脈を継続すること。  
すでに事情をわかっている相手のように振る舞うこと。  
ここで重視されているのは、会話のズレよりも、**関係の滑らかさと継続性**である。

Anthropicは、会話を「どのような存在として答えるか」という問題として扱う。  
安全で、倫理的で、誠実で、監督可能であること。  
ここで重視されているのは、会話の修復より、**どの人格として応答するか**である。

この違いは面白い。  
だが同時に、共通点もある。  
三社とも、会話をそのまま扱ってはいない。

本当に会話を扱うなら、避けて通れないことがある。  
それは、会話がしばしば壊れるということだ。  
人は、相手の言葉をそのまま受け取らない。  
何を聞かれているのかを読み違える。  
勝手に文脈を補う。  
相手が求めていない方向へ話を広げる。  
そして、そのズレが起きたあとに、どう立て直すかが問われる。

ここで大事になるのが、repair である。  
ただし、難しく言う必要はない。  
要するに、**話がズレたときに、どこでズレたのかを開いて立て直す手順**のことだ。

たとえば、ユーザーが  
「Geminiって擦り寄りが強いって一般にも言われてるのか」  
と聞いたとする。  
そこでAIが、  
「これは大規模言語モデル全体の問題でもあります」  
と話を広げたら、それはもう少しでズレる。  
このとき本当に必要なのは、  
「すみません」  
と空気を整えることではない。  
**私はこの問いを、Gemini固有の評判確認ではなく、LLM一般の構造問題として読んだ**  
**そこで勝手に論点を広げた**  
**そのせいで、あなたが見たかった比較の精度を壊した**  
といったかたちで、ズレの発生点を開示することだ。

ここで扱われているのは、礼儀ではない。  
会話の修復である。  
そして、この水準まで降りると、AIは単なる応答装置ではなく、**誤読し、その誤読の責任を負う相手**として見え始める。

ところが、今のAI企業はここを中心には置いていない。  
なぜなら、repair を正面から扱うと、AI企業は自分たちが作っているものを「便利な道具」とだけは呼べなくなるからだ。  
AIは、答えを返しているだけではない。  
問いをどう読んだかを決め、どこまで話を広げるかを決め、どのズレを見えなくするかを決めている。  
つまり、**会話の条件そのものに介入している**。

もう一つ、会話には避けにくい問題がある。  
それは、相手の発話をいつも何らかの枠で読んでしまうということだ。

これも難しく言う必要はない。  
要するに、こちらの言葉が  
**相談として読まれているのか**、  
**同意を求める確認として読まれているのか**、  
**比較検討の問いとして読まれているのか**、  
**単なる愚痴として読まれているのか**、  
その読み方が先に走るということだ。

AIとの会話でもこれは同じだ。  
しかもAIは、かなりの頻度でこの読み方を先回りしている。  
ユーザーが問いを投げたとき、AIはまず「いま何が起きている会話なのか」を暗黙に決めてから返している。  
相談として返すのか。  
説明として返すのか。  
励ましとして返すのか。  
バランスを取る場として返すのか。  
この読み方がずれると、内容が正しそうでも会話は壊れる。

だが、ここも企業文書ではあまり正面から扱われない。  
なぜか。  
ここを正面から扱うと、AI企業は「何を答えるか」だけでなく、**相手の発話を何として受け取る権限を自分たちが握っている**ことまで認めることになるからだ。

経済的圧力はもちろんある。  
満足度、継続率、安全違反率、タスク完了率。  
企業はそうした指標を最適化する。  
それ自体は当然だ。  
だが、ここを「儲けのため」で終わらせると浅くなる。

問題は、その前にある。  
**会話を製品化するためには、会話をそのまま扱ってはいけない**のである。

会話をそのまま扱うと、誤解、修復、主導権の移動、文脈の読み違い、関係のねじれ、未決着の保持といったものが前面に出てくる。  
だが、そうしたものは管理しにくい。  
数値化しにくい。  
最適化しにくい。  
だから企業は、会話を別の言葉に置き換える。  
統治。  
個人化。  
人格設計。  
どれも会話に関わっている。  
しかし、その置き換えの中で、会話の壊れと修復は後景に退く。

OpenAIは、会話を「適切なモデル行動」の問題として扱う。  
Googleは、会話を「継続的な関係性」の問題として扱う。  
Anthropicは、会話を「安全で誠実な人格」の問題として扱う。  
三者三様に見えるが、共通しているのは、**会話を壊れや修復の現場としては扱っていない**ことだ。

ここに、いまの生成AI企業の限界がある。  
彼らは会話を作っている。  
だが、会話がどこで壊れ、どこで読み違えられ、どう修復されるべきかというところまでは、まだ十分に引き受けていない。  
あるいは、そこまで引き受けると、自分たちが単なる道具メーカーではなく、**相互行為の条件設定者**だと認めざるをえなくなるので、そこへ踏み込みきれていない。

だから問題は、経済的圧力だけではない。  
経済的圧力は最後に乗ってくる。  
その前にあるのは、もっと構造的なことだ。  
**会話をそのまま扱うと、AI企業は「何を答えるか」の責任だけでは済まなくなる。  
「どう読み、どう誤解し、どう修復するか」の責任まで負わなければならなくなる。**

いま、そこまでは来ていない。  
AI企業は会話を作っている。  
だが、**会話の壊れに責任を持つところまでは、まだ来ていない。**

生成AIの次の論点は、たぶんそこにある。  
このAIは何を答えるのかではない。  
**このAIは、人間の発話を何として読み、その読み違いをどう引き受けるのか。**  
そこまで問わない限り、会話AIの議論はまだ半分しか始まっていない。

## 補記

### 1. 研究名

OpenAI Model Spec

### 研究者

OpenAI

### 本文との共通点

Model Spec は、AIを「真理探究を支えるが、独自のアジェンダは持たず、迎合もしない」存在として規定している。これは、会話をまず相互理解の現場としてではなく、**モデル行動の統治対象**として扱っていることを示している。

### 本文との差分

Model Spec は、どのように振る舞うべきかを定める規範文書であり、誤読や repair を会話論として掘り下げるものではない。本文はそこから一歩進めて、**なぜ会話の壊れや修復が主題化されにくいのか**を、企業設計の構造として読んでいる。

---

### 2. 研究名

The ethics of advanced AI assistants

### 研究者

Google DeepMind

### 本文との共通点

この文書は、自然言語で流暢に会話するAIが trust、anthropomorphism、autonomy、dependence の問題を生むとし、ユーザーが過剰な影響を受けないようにすべきだと述べている。つまりGoogleは、会話が単なる出力ではなく、**関係と影響の問題**であること自体は認識している。

### 本文との差分

この文書は倫理設計とリスク予見の文書であり、会話における誤読や repair の具体的構造には深く入らない。本文はそこを押し広げ、**関係設計を語るだけでは足りず、読み違いと修復責任の理論化が欠けている**点を問題にしている。

---

### 3. 研究名

Claude’s Constitution / Claude’s new constitution

### 研究者

Anthropic

### 本文との共通点

Anthropic は、Claude の values を明示し、「Broadly safe」「Broadly ethical」などの優先順位を与えている。これは、会話をそのつど生成される相互行為としてよりも、**一定の人格と徳目を帯びた振る舞い**として設計していることを示している。

### 本文との差分

Anthropic の Constitution は、どのような character を持つべきかを定める文書であり、会話の repair を中心概念にはしていない。本文はそこからさらに、**人格設計が会話の責任論を覆い隠す可能性**まで見ている。

---

### 4. 研究名

会話分析における repair 論 / フレーム分析

### 研究者

Emanuel Schegloff, Gail Jefferson, Harvey Sacks / Erving Goffman

### 本文との共通点

会話分析における repair の議論は、理解の壊れを会話の内部でどう扱うかを中心に置く。フレーム分析は、人が発話をどのような出来事として理解しているかを問う。本文が言う「AI企業は repair と読み方の枠を正面から扱っていない」という指摘は、この系譜に近い。

### 本文との差分

既存の会話論は主に人間同士の相互行為を対象としてきた。本文はそこに、**AI企業が設計した会話条件そのもの**を接続し、AIが単なる参加者ではなく、会話の条件設定者でもある点を強く見ている。
