# 語る場と決める場 ―― 適用条件という視点

> 公開本文の正本：https://note.com/shirokuma1970/n/ncb0c0fb66f04
>
> このファイルは文脈解析用の取得時スナップショットです。

「語る場」と「決める場」という区分を考えてきた。

語り続ける流れがあり、  
そのある瞬間を切り取って決定する。  
そしてまた語りに戻る。

この循環は、運用フェーズの改善にはよく馴染む。  
だが、ゼロから何かを生み出すプロジェクト型の環境では、  
どこかうまく噛み合わない感覚があった。

なぜか。

考えてみると、問題は理論そのものではなく、  
その「前提条件」にあった。

語る場と決める場が機能するには、いくつかの条件が必要になる。

まず、意思決定が不可逆でないこと。  
決定は永久凍結ではなく、仮固定であること。

次に、フィードバックの経路が制度化されていること。  
結果が感情ではなく、構造として意思決定に戻ってくること。

さらに、不確実性を分割できること。  
小さく回せる単位がなければ、決定は重くなりすぎる。

そして、評価軸が個人ではなく構造にあること。  
失敗が人格評価になる環境では、語る場は萎縮する。

最後に、探索と確定のモードが識別可能であること。  
今は広げる時間なのか、絞る時間なのかが曖昧だと、混線が起きる。

これらが満たされない環境では、  
語る場と決める場は理想論に見える。

だが、条件が整えば、これは単なる会議技法ではない。

それは、

不確実性を前提にした、動的な組織設計の原理

なのだと思う。

万能ではない。  
しかし、適用条件を明示できる思想は、弱くはない。

今はここまで。

また、語りに戻る。
