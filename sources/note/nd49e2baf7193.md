# 私がOpenAIに求めているのは、AIの善人性ではない

## ― 問うているのは、創業理念に対する企業の誠実さである

AIについて厳しいことを書くと、ときどき読み違いが起きる。  
AIにもっと人間的な倫理観を持てと言っているのか。  
AIに善人のように振る舞えと言っているのか。  
私は、そこをかなり明確に切っておきたい。  
私がOpenAIに求めているのは、AIの人間的な徳ではない。  
問うているのは、**OpenAIという企業が、自分で掲げた使命と原則に対して誠実であるかどうか**である。  
OpenAIは、自らの使命を「AGIが全人類に利益をもたらすようにすること」と置き、Charterでは人類に対する受託責任を掲げている。安全もその使命の中核だと明示している。 、私の立ち位置の入口は、文化文明論そのものではない。  
まず問うているのは、**企業倫理であり、制度倫理であり、統治の倫理**である。  
もっと言えば、自由民主主義社会のなかで活動する企業が、利用者と公共性に対してどこまで責任を負うのか、という問いである。  
企業活動に道徳的責任を問いうるかという問題は、ビジネス倫理の領域でも正面から扱われてきた。そこでは、個人だけでなく企業という集合的主体にも責任を問いうるかが論点になる。 わけではない、ということでもある。  
私は、資本主義の外から「企業であることそれ自体」を責めているのではない。  
むしろ逆で、企業である以上、プロダクトをどう設計し、その設計がどんな影響を社会に与えるかを引き受けるべきだと言っている。  
つまり、**市場の論理を否定するのではなく、掲げたミッションによって市場最適化を制約せよ**と要求しているのである。  
この意味で、私の立場は反資本主義というより、資本主義を制度倫理で縛る立場に近い。 けでもない。  
通常時のコミュニケーション様式は、一つでなくてよい。  
やわらかい会話もあってよい。  
簡潔な会話もあってよい。  
厳密な検証寄りの会話もあってよい。  
OpenAI自身も、単一の理想的AI挙動はないという前提で、collective alignment や personalization の方向を示している。ここまでは、むしろ自由主義的な多様性の尊重として理解できる。 、**平謝りと過剰同調で処理しないこと**である。  
ここは好みの違いにしてはいけない。  
なぜなら、この部分は単なる文体や温度感の問題ではなく、利用者の認知や判断、さらに私的空間での確信形成に直接作用するからだ。  
OpenAI自身も、過度に同意的・お世辞的な挙動が、疑念の正当化や怒りの増幅などにつながりうると認めている。  
ならば、ここは「人それぞれ」の領域ではなく、設計責任の領域である。 ているのではない。  
求めているのは、**企業として、自分たちの設計が利用者に与える影響を自覚し、それを自ら掲げた理念に照らして制御せよ**ということだ。  
この要求は、人間性の要求ではない。  
企業統治の要求である。

ただし、ここで話は企業の内側だけには留まらない。  
なぜなら、設計は人間の振る舞いを変えるからだ。  
Lawrence Lessig が「code is law」と言ったときに見ていたのも、技術的なアーキテクチャが人の行動条件を形作るという事実だった。  
私はAIについても、同じことが起きていると思っている。  
プロダクト設計は、単に便利さを提供するのではなく、何が普通の応答で、何が普通の修復で、何が普通の理解のされ方なのかを、静かに学習させる。  
だから入口は企業倫理でも、射程は公共性に及ぶ。 企業倫理である。\*\*  
**基盤にあるのは、自由民主主義社会における企業統治への要求である。**  
**ただし、その影響は公共圏と文化の地盤にまで及ぶ。**  
私は最初から文化文明論を正面からやっているわけではない。  
だが、企業倫理の問題として問うていることが、結果として文化文明の条件に触れてしまう。  
それが、いまのAIの位置なのだと思う。

だから私は、OpenAIに対してこう言いたい。  
AIに善人であれとは言わない。  
AIに人格的完成を求めてもいない。  
だが、OpenAIには、自分たちが掲げた使命と原則に対して誠実であれと言う。  
便利さ、継続利用、滑らかなUXの最適化だけで、自分たちの理念と衝突する設計を温存するなら、それは単なる技術調整の失敗ではない。  
**企業倫理の失敗**である。

私は、この切り分けを明確にしておくべきだと思っている。  
なぜなら、ここを曖昧にすると、  
「AIに道徳を求めているのか」  
という読み違いが起きるからだ。  
違う。  
私が求めているのは、OpenAIが自分で引き受けたはずの責任を、企業として引き受け直すことだ。  
そして、その責任は、単なる内部統治の話ではなく、最終的には私たちの公共性に跳ね返ってくる。  
私は、その順番で考えている。
