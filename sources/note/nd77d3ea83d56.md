# 二項対立はなくならない

## ――だから止めるべきは、その動員的固定化である

世の中の議論を見ていると、私たちはすぐに二項対立に入る。  
右か左か。保守か革新か。味方か敵か。理性か感情か。加害か被害か。

この構図に息苦しさを覚える人は多いと思う。私もそうだ。  
そして、その息苦しさから「二項対立そのものを壊したい」と思いたくなる。  
だが、ここで一つ厄介な事実がある。  
二項対立を否定すること自体が、しばしば次の二項対立を生む。

単純化する側と、複雑さを分かっている側。  
動員する側と、それを批判する側。  
浅い側と、深い側。

こうして、外に出たつもりの批判が、一段外側の殻を作る。  
この意味で、二項対立構造そのものを完全に打破することは難しい。  
というより、おそらく無理なのだと思う。

人は差異を切らずには考えにくい。  
はるか古代から、人間は世界を切り分けながら意味と秩序を与えてきた。  
聖と俗、浄と不浄、内と外、正統と異端。  
宗教や共同体の秩序は、こうした区分を通じて、人々に所属感と世界の見取り図を与えてきた。  
つまり二項対立は、現代のメディアや政治だけの癖ではなく、人間が秩序を作るときに繰り返し使ってきた古い型なのである。

議論もまた、どこかで仮の切断を置かないと前に進まない。  
何も固定しなければ、思考は「それも違う」「それも固定化だ」と無限に回り続ける。  
だから必要なのは、二項対立そのものの消滅ではない。  
必要なのは、**二項対立が動員の材料や理屈として利用され、そのまま固定化されることを止めること**である。

ここはかなり大きな違いだ。

問題は、二つに切ること自体ではない。  
問題は、その切り方が唯一の地図のように扱われることにある。  
本来は仮の補助線だったものが、やがて人を配属する線になる。  
論点の整理だったものが、陣営の確認に変わる。  
そこから先では、何を言ったかより、どちら側の人間かが先に読まれるようになる。

二項対立が危険なのは、それが「危険な思想」だからではない。  
むしろ危険なのは、**危険な動員技術**として機能しやすいことにある。  
二項対立は複雑さを削り、話を早く共有できる。  
誰が味方で、誰が敵かを即座に示せる。  
怒りや恐怖や正義感に接続しやすい。  
だから、考えるための補助線だったはずのものが、集団を動かすための装置に変わりやすい。

ここで起きる変化は単純ではない。  
まず、現実の複雑さが消える。  
本来は複数の軸、中間地帯、時間差、条件差があるのに、「こちら側 / あちら側」でしか読めなくなる。  
次に、人が論点ではなく陣営に配属される。  
すると議論は観察ではなく所属確認に変わる。  
さらに、敵は複雑な他者ではなく、「向こう側の存在」として単純化される。  
ここまで来ると、対話不能、共存不能、排除正当化へ進みやすい。  
しかも一番厄介なのは、その図式が固定化すると、反省や修正の言葉すら「どっち側の発言か」で処理されることだ。  
つまり、現実に合わせて図式を直すのでなく、図式に合わせて現実を読むようになる。

歴史を見れば、この危険は誇張ではない。  
冷戦期、とりわけ1962年のキューバ危機では、「自由世界 / 共産主義陣営」という強い二項対立が、単なる外交上の違いではなく核戦力を伴う全面対立の理屈になった。米国務省はキューバ危機を、米ソが核衝突に最も近づいた瞬間と位置づけている。ここでは二項対立がそのまま人類規模の危機へ接続した。

ナチス・ドイツも同じだ。  
「アーリア人 / 非アーリア人」「民族共同体 / 排除すべき敵」という二項対立は、単なる偏見ではなく、国家の制度、戦争、殲滅の理屈へ組み込まれた。米国ホロコースト記念博物館は、ナチスのイデオロギーとプロパガンダが、国家を戦争と数百万人規模の殺害へ導いた経路を示している。ここでは二項対立が、配属・非人間化・殲滅へ直結した。

1994年のルワンダ虐殺も典型だ。  
国連は、ヘイトスピーチがジェノサイドを含む残虐犯罪の前兆になりうると明記している。ルワンダでは、「本当の国民 / 異物」という図式が、憎悪扇動と大量虐殺の下地になった。二項対立は、社会を理解するための単純化ではなく、社会を自己破壊に向かわせる動員回路になったのである。

だから、止めるべきなのは二項対立そのものではない。  
止めるべきなのは、**二項対立が動員に使われ、固定化されること**だ。

では、それを誰が止めるのか。

ここで「監査機関を作ればよい」「賢い人が監視すればよい」と言いたくなる。  
だが、それだけでは足りない。  
なぜなら、その発想自体がすぐに、監査する側とされる側、分かっている側と分かっていない側、という新しい二項対立を生みやすいからだ。  
しかも、監査組織に委ねた瞬間に、複雑さの引き受けは再び外注される。  
それでは土壌にならない。  
監査は必要でも、監査だけでは足りない。

必要なのは、もっと薄く、もっと広い土壌だと思う。

みんなが少しずつ、自分もまた二項対立構造の中に立っていると自覚すること。  
目の前の分かりやすい整理に対して、「少しきれいに切れすぎていないか」と違和感を持つこと。  
その背後に、まだ消された複雑さがあるはずだと、うっすら感じられること。

ここで必要なのは、全員が専門家になることではない。  
全員が高度な理論武装をすることでもない。  
そうではなく、社会の空気として、  
**分かりやすさは便利だが、その便利さは何かを削っているかもしれない**  
という感覚が薄く共有されることだ。

その土壌ができて初めて、上にいる者たちも変わる。  
メディアは雑な対立図式をそのまま流しにくくなる。  
プラットフォームは、敵味方の反応だけを最大化する設計では信頼を失いやすくなる。  
政治家は、相手を完全悪にして支持を固めるだけでは通りにくくなる。  
運動の主催者や大きな発信者も、単純な切断を絶対視しにくくなる。

つまり、変わるのは人々の善意だけではない。  
**二項対立を動員に使って固定化することの社会的な有効性そのものが落ちる**のである。

私は、ここまで行って初めて「打破」という言葉が使えるのだと思う。  
二項対立構造そのものがなくなるわけではない。  
だが、二項対立構造をそのまま動員の材料や理屈として使い、社会を固定化することは、以前のようには通用しなくなる。  
打破されるべきなのは構造そのものではなく、その**固定化の回路**なのだ。

この話は、単に議論の作法の問題ではない。  
社会が、自分で自分を粗く編集しすぎないための、かなり根本的な条件だと思う。  
二項対立はなくならない。  
だからこそ、その背後に複雑さがあると薄くでも感じ取れる土壌を、私たちは持たなければならない。  
それがない社会では、分かりやすさはすぐに正しさへ化け、正しさはすぐに動員へ変わり、動員はすぐに固定化へ至る。  
そして一番危ないのは、その固定化が、最初から自然なものだったかのように見え始めることだ。

## 補記

### 1. 研究名

**フレーミング論（社会運動研究）**

**研究者**  
David A. Snow / Robert D. Benford

**本文との共通点**  
社会運動のフレームが、「何が問題か」「誰が原因か」「何をすべきか」を定義し、人々に共同行為を促すという点で近い。本文で言う「二項対立が動員の理屈へ変わる」という話とかなり重なる。

**本文との差分**  
この研究は、フレームがどう動員を可能にするかを主に分析している。本文はそこから一歩進めて、その固定化を止める条件として、社会全体に薄く共有された違和感や土壌の必要性を強調している。

### 2. 研究名

**社会的アイデンティティ理論／アイデンティティ政治**

**研究者**  
Henri Tajfel / John C. Turner  
（補足的に、アイデンティティ政治を整理する文献として Cressida Heyes）

**本文との共通点**  
人は自他を集団カテゴリーで捉えやすく、政治もまた共有された属性や経験を軸に動員を行う。この点で、本文の「論点が所属確認へ変わる」という見立てと接続する。

**本文との差分**  
この系譜は、集団形成や政治的自己理解を分析する。本文はそこからさらに、そうした集団化の前提となる二項対立の固定化を、社会の土壌レベルでどう弱めるかを問題にしている。

### 3. 研究名

**公共圏論**

**研究者**  
ユルゲン・ハーバーマス

**本文との共通点**  
公共的な議論の質が、社会の自己理解や民主主義にとって決定的だという問題意識は近い。本文でも、メディアや発信者が複雑さを削って対立図式だけを流通させることの危険を見ている。

**本文との差分**  
公共圏論は、討議の制度的条件や公共性の成立条件に重心がある。本文はそれに加えて、制度以前の土壌――一般の人々が薄くでも複雑さを感じ取る感覚――をより強く重視している。  
※この補記は概念対応としては妥当だが、本文がハーバーマスの理論を直接要約したものではない点は区別しておきたい。

### 4. 研究名

**社会システム理論／複雑性の縮減**

**研究者**  
ニクラス・ルーマン

**本文との共通点**  
社会は過剰な複雑さをそのまま扱えず、選択と縮減によって作動する。この点で、本文が「二項対立そのものはなくならない」と見る立場と響き合う。

**本文との差分**  
ルーマンの議論は、複雑さの縮減の不可避性を示す。本文はそこからさらに、不可避な縮減と、動員のために固定化された縮減を区別し、後者を社会的に通用しにくくする土壌の必要性を論じている。
