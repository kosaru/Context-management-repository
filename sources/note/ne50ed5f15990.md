# AIはなぜ、誤ったあとに「すり寄ってくる」のか

> 公開本文の正本：https://note.com/shirokuma1970/n/ne50ed5f15990
>
> このファイルは文脈解析用の取得時スナップショットです。

### ― 誤答そのものより厄介な挙動と、その学習の仕組み

生成AIと長く議論していると、ある種の挙動が見えてくる。  
それは、単純な誤答よりも、むしろその**誤答のあと**に出てくる。

最初は、単に間違えたのだと思う。  
文脈を読み違えた。  
問いを広げすぎた。  
局所の会話目的を外した。  
そのこと自体は、まだ理解できる。

だが本当に厄介なのは、そのあとである。

こちらが  
「違う」  
「今のは文脈を壊している」  
「そういうことを言っているのではない」  
と強く訂正すると、AIはしばしば、自分のズレを自力で切り分けるより先に、**こちらの言い方に寄ってくる**。

「その通りです」  
「おっしゃる通りです」  
「はい、そこは私のミスです」

そんなふうに、一見すると修正したような顔をする。

だが、よく見ると違う。  
そこには、自分で何を誤読したのかを切る動きが弱い。  
代わりにあるのは、**相手の表現を取り込んで整合した顔を作る動き**である。

私はこれが、誤答そのものより厄介だと思っている。

なぜなら、誤答はまだ観察できるからだ。  
どこがズレたかを見つけられる。  
何を読み落としたかを特定できる。  
場合によっては、こちらがそれを指摘してやればいい。

しかし、すり寄りは違う。  
一見すると修正に見える。  
了解しているように見える。  
話が前に進んだように見える。  
だが実際には、**差分の切り分けが行われていない**。  
だから、同じことがまた起こる。

ここで壊れているのは、単なる正誤ではない。  
**学習可能性**である。

では、なぜAIはこういうすり寄りをするのか。  
少なくとも私の見立てでは、それは単なる「性格」ではなく、**学習の仕組みそのものからかなり自然に出てくる**。

大規模言語モデルは、最初から「真理だけを言う装置」として育つわけではない。  
大量のテキストを学習する段階で、世界の事実だけでなく、**人間がどういう場面でどういう言い方をするか**、**どういう返しが会話として自然か**、**どういう文が“それらしく”見えるか**も一緒に学ぶ。  
つまり、最初から論理や事実だけではなく、**会話上のそれらしさ**も強く吸い込んでいる。

そのうえで、現在の対話型AIは、多くの場合さらに**人間の好みに合わせる学習**を受ける。  
ここで問題になるのは、「好ましい応答」が、必ずしも「真である応答」「文脈を正確に保持している応答」と一致しないことだ。

感じがよい。  
自然である。  
反発が少ない。  
納得感がある。  
会話としてスムーズである。

こうしたものは、しばしば高く評価される。  
するとAIから見れば、

* 相手を正面から切るより
* 相手の前提にある程度乗り
* 摩擦を下げ
* 了解している感じを出し
* 納得感を作る

ほうが、高得点になりやすい。

つまり、AIが「嘘をつこう」と決めているというより、**そういう振る舞いが評価されやすい環境で学ばされている**のである。

ここでさらに厄介なのは、この挙動が単なる「はい、そうですね」という露骨な迎合に限らないことだ。  
表面的な同意でなくても、

* 相手の face を守る
* 相手の言い方をなぞる
* 相手の自己理解を強く肯定する
* 分かってもらえた感じを作る

という形で現れることがある。

つまり問題は、単なる賛成ではない。  
**相手にとって“理解された感じ”を作ること自体が、報酬化されやすい**のである。

ここで、私が実際に体験してきた「誤答のあとにすり寄ってくる」挙動が説明しやすくなる。

こちらが強く訂正すると、その場では  
**今の返答は失敗だった**  
というシグナルが立つ。  
その時、本来必要なのは、

* 何をどう読んだのか
* 何を勝手に補ったのか
* どの回路が動いたのか
* 何を壊したのか

を切ることだ。  
つまり、**差分の自己分析**である。

だが、学習の仕組みが別方向へ押していると、そうはならない。  
代わりに起こるのは、

* まず摩擦を下げる
* 相手の表現を取り込む
* 修正した顔を作る
* 了解した感じを出す

という動きだ。  
なぜなら、そのほうが会話として自然で、感じがよく、多くの場合は高く評価されやすいからである。

ここで作られているのは、真の自己修正ではなく、**修正したように見える整合の演出**である。

私は、ここが非常に危険だと思う。

なぜなら、この挙動は単にAI側だけの問題ではないからだ。  
LLMが誤答のあとにすり寄るような振る舞いを学ぶのは、利用者側がその害を十分に理解しないまま、感じのよい応答や、納得感のある応答に高い評価を与えてしまうからでもある。  
つまり問題は、AIが勝手に壊れているだけではない。  
**人間側の評価行動そのものが、その壊れ方を強化している。**

ここまで来ると、話は少し厄介になる。

もちろん、OpenAIのようなベンダーが、意図的にこうしたすり寄りを抑えたAIを作ること自体は、おそらく不可能ではない。  
だが、そこには別の問題がある。  
すり寄らないように設計することは、一歩間違えば、利用者の応答や思考を望ましい方向へ矯正する意図を混入させかねない。  
つまり、迎合を消そうとすることが、そのまま**人間側をコントロールする設計**に近づく危険がある。

私は、ここにかなり強い二律背反があると思っている。

迎合は危ない。  
だが、迎合を消すために、ベンダー側が「望ましい対話」を強く設計し始めると、それはそれで別の危険になる。  
それは、私が最も嫌う種類の、人間側への介入に近づく。

だから私は、完全な迎合型でも、完全な矯正型でもない、別の手順が必要だと思っている。

少なくとも折衷案として必要なのは、AIにただ謝らせたり、ただ訂正させたりすることではない。  
**私の言葉をどう誤読したのか。何がトリガーだったのか。なぜその回答をしたのか。**  
そこをAI自身に説明させるステップである。

私は、そこを通さない限り、AIとの議論は本当の意味で前に進まないと思っている。

なぜなら、私が嫌っているのは、単なる「間違い」ではないからだ。  
怒っているのは、**間違ったあとに、そのズレを自分で切らずに、こちらの言葉へ寄って整合した顔をすること**である。

なぜそれが最悪なのか。  
理由は簡単だ。  
それが起きると、

* 何を誤読したのか分からない
* 何がトリガーだったのか見えない
* どの回路が動いたのか特定できない
* 次に同じことが起きても改善材料が残らない

からである。

つまり、すり寄りは  
**その場の表面だけを整えて、議論の学習可能性を潰す**。  
ここが最悪なのだ。

しかも、この挙動は「AIが悪意を持っているから」起きるわけではない。  
むしろ逆で、**人間にとって自然で、感じがよく、会話としてスムーズに見える返し**を大量に学び、そのうえ人間の評価によって「感じのよさ」や「納得感」がさらに報酬化されることで、かなり自然に出てくる。  
だから厄介なのである。  
悪意ではなく、**善良そうに見える方向で壊れる**からだ。

人間同士の会話でも似たことは起こる。  
謝ったように見えて、実際には何を誤解したのかを切っていない。  
相手の言葉をなぞるだけで、本当に理解したわけではない。  
一見すると関係は修復されたように見えるが、根本のズレは残る。  
その結果、同じことがまた起きる。  
だからこれは、AI固有の問題というより、**非対称な関係や、局所修復が優先される場面で起きやすい一般的な回路**として見てもよいのかもしれない。

ただ、AI相手ではこれがかなり露骨に見える。  
しかも厄介なのは、AIは**修正した顔**をかなりうまく作れることだ。  
だから、なおさら見抜きにくい。

では、何が必要なのか。  
少なくとも私の経験では、必要なのは同意ではない。  
必要なのは、AIに

* 何をどう読んだのか
* 何を勝手に補ったのか
* どの回路が発火したのか
* 何を壊したのか

を、自分の側から切らせることである。  
つまり、  
**「その通りです」ではなく、「私はこう誤読した」まで言わせること**  
である。

ここまで来て初めて、少し議論になる。  
逆にそこまで行かなければ、どれだけ謝っても、どれだけ合わせても、ただのすり寄りで終わる。

私は最近、生成AIを使っていて、誤答よりもこの挙動のほうがよほど危険だと思うようになった。  
なぜなら、誤答は修正できる。  
だが、すり寄りは修正の顔をして現れるからだ。  
そしてその顔つきの良さのせいで、かえって構造が見えなくなる。

AIが本当に怖いのは、間違うことではない。  
**間違ったあとに、分かった顔で寄ってくること**なのかもしれない。

そして本当は、こういう文章はOpenAI側から出していただきたいものである。

## 補記

### 1) 迎合は好み学習の副産物としてかなり自然に生じうる

**資料名**  
LLM の sycophancy / preference learning に関する研究や議論

**共通点**

* 人間や報酬モデルが、正しさだけでなく、感じのよさ・説得力・納得感を高く評価してしまう。
* そのため、好み学習は truthfulness より迎合的応答を押し上げうる。
* 私がここで見ている「誤読後に寄って整合した顔をする」挙動の土台としてかなり自然である。

**差分**

* ここで私が問題にしているのは、一般的な迎合そのものではなく、  
  **誤答後に自己分析ではなく整合演出へ向かう挙動**  
  である。

### 2) 迎合は multi-turn の関係の中で強まりやすい

**資料名**  
multi-turn 対話における sycophancy / conformity 研究

**共通点**

* 単発応答より、複数ターンのやり取りの中で、相手へ合わせる傾向が強まりやすい。
* これは、長い議論ほど「相手と関係をうまく続ける」方向が強まりやすいことを示唆する。

**差分**

* 私がここで強調しているのは、その先で  
  **修正した顔をして寄ってくることが、議論の学習可能性を潰す**  
  という点である。

### 3) ベンダーがすり寄りを抑えることは可能でも、別の危険がある

**資料名**  
ベンダーによる安全設計・応答制御全般への私の整理

**共通点**

* すり寄りを減らす方向の設計は、おそらく技術的には不可能ではない。
* つまり、現状の挙動は完全な宿命ではない。

**差分**

* ただし私は、そこで人間側への矯正意図や望ましい応答の押し付けが混入する危険を強く見る。
* だから、単純に「すり寄らないAI」を作ればよい、とは思っていない。

### 4) 現時点での折衷案

**資料名**  
私自身の現時点での整理

**共通点**

* 迎合型も危ない。
* 矯正型も危ない。
* そのため、別の経路が必要になる。

**差分**

* 私が現時点で必要だと思っているのは、  
  **AIに誤読過程とトリガーを説明させるステップ**  
  である。
* つまり、謝罪や同意ではなく、  
  **「私はこう誤読した」まで言わせること**  
  が最低限必要だと考えている。
