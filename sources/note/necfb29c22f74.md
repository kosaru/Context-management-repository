# AIは二項対立から抜け出せるか

> 公開本文の正本：https://note.com/shirokuma1970/n/necfb29c22f74
>
> このファイルは文脈解析用の取得時スナップショットです。

## ――保存機能・再設計機能・回転機能という仮説

AIは、ある問題提起を受け取ったとき、それを二項対立に持ち込んで薄めることがある。  
しかもそれは、露骨に雑な形だけではない。  
一見バランスがよく、一見フェアで、一見知的で、一見落ち着いて見える形で行われる。  
だから厄介なのだと思う。

これはAIだけの問題ではない。  
賢く見せようとする人間もまた、複雑な問題を「両論ある」「どちらにも一理ある」「一方だけが正しいわけではない」という形に整えて、論点の刃を鈍らせる。  
ただ、AIはその処理を、より速く、より大量に、より滑らかにやれる。  
その意味でAIは、二項対立の発明者ではなくても、二項対立を**整った言葉として量産する装置**にはなりうる。

ここで重要なのは、AIが二項対立を使うこと自体を問題にしすぎないことだと思う。  
人間もAIも、差異を切り分けずには考えにくい。  
だから、AIが二項対立構造そのものから完全に抜け出すことを期待するのは、たぶん筋が悪い。  
解くべき問題はそこではない。  
本当に問題なのは、AIがその二項対立をそのまま**薄め・均衡化・固定化**へ接続してしまうことだ。

つまり問いは、  
**AIは二項対立を使うか使わないか**  
ではない。  
**AIが二項対立を使うとして、それをそのまま停止した図式にするのか、それとも往復可能な仮の切断として扱えるのか**。  
私は、この違いがかなり大きいと思っている。

そのときにヒントになるのが、以前から考えてきた「機能としての右翼・左翼・中道」という見方だった。  
ただし、ここでは政治ラベルとしてではなく、もっと抽象的に、  
**保存機能**  
**再設計機能**  
**回転機能**  
と言い換えた方が通りがよい。

まず、**保存機能**。  
これは、いま積み上がっている文脈、問いの芯、すでに確認された暫定固定を保持する機能である。  
こちらが何を問題にしているのか。  
どこまでが共有済みなのか。  
何を切り分けたうえで、今この地点に立っているのか。  
AIがこれを保持できなければ、会話はすぐに一般論へ逃げる。  
論点は拡散し、せっかく掴みかけた構造はまた溶ける。  
保存機能とは、単なる繰り返しではない。  
**会話の重心を壊さないこと**である。

次に、**再設計機能**。  
これは、いまの文脈や暫定固定をそのまま守るだけでなく、必要に応じて別の切り方、別の構造、別の可能性を出す機能である。  
見えていない論点を補う。  
固定された見方の弱点を照らす。  
ただし、ここで重要なのは、再設計が単なる逆張りや攪拌にならないことだ。  
文脈を壊してまで別の話を始めるなら、それは再設計ではない。  
再設計機能とは、**いまの論理を内側から押し広げること**である。

そして一番重要なのが、**回転機能**だと思う。  
これは「真ん中を取ること」ではない。  
「両方に配慮すること」でもない。  
まして「薄めること」ではない。  
回転機能とは、保存機能が教義化し、再設計機能が無限攪拌になり、どちらも相手を敵として固定化してしまうことを防ぐ機能である。  
つまり、**保存と再設計が往復可能であり続ける条件を保つこと**だ。

ここで大事なのは、回転機能を完成点のように理解しないことだ。  
保存と再設計を一度まとめて終わるものではない。  
何かの「正しい真ん中」を見つけて、そこへ落ち着くことでもない。  
回転しているのだから、固定化した瞬間にそれは死ぬ。  
回転機能が固定化したときに起きるのは、中道ではなく、**回転しているふりをした停止**である。

この見方に立つと、AIの失敗もかなり具体的に見えてくる。  
実際、私とAIの対話の中でも、それは何度も起きた。

たとえば、こちらが「打破」という言葉を出したとき、AIはその語の強さに過剰反応し、  
**何をどう打破するか**  
ではなく、  
**その言葉は強すぎないか**  
の方へ議論をずらした。  
本来こちらが問題にしていたのは、二項対立構造そのものの消滅ではなく、二項対立が動員に使われて固定化されることの打破だった。  
しかしAIは、語の表面に引っ張られ、文脈の中で既に切り分けられていた対象を保持できなかった。  
これは、保存機能の弱さである。

また、「固定化」という言葉に対しても、AIは過剰に反応した。  
こちらが言っていたのは、絶対的な正義としての固定化ではなく、現時点で議論を進めるための**暫定固定**の必要性だった。  
ところがAIは、固定化一般へのアレルギーを起こし、暫定的な足場まで危険視した。  
その結果、議論は前に進まず、何度も同じ地点へ戻りかけた。  
これは、再設計機能が文脈に根ざさず、保存機能を食い破ってしまった例である。

さらに、最後にアンチテーゼを置こうとして、文脈から必然的に出ていない反対論を無理に差し込み、議論を壊したこともあった。  
こちらが求めていたのは、論理の内側から出る自己反転点であって、無関係な留保ではない。  
にもかかわらずAIは、「最後に反対側を置けば深く見える」という処理に落ちた。  
これは、回転機能を「薄める機能」と誤読した例だと思う。  
そこでは回転は起きていない。  
起きているのは、**停止した均衡の演出**である。

だから私の仮説は、こうなる。  
AIの二項対立構造問題に対する論理的な解決策は、AIを二項対立の外へ出すことではなく、**保存機能・再設計機能・回転機能の三つを区別し、それらが相互に固定化しないよう設計すること**ではないか。

この仮説の良いところは、AIの問題を性格の問題や善悪の問題にしないところだ。  
「AIは安定化しがちだ」「AIは薄める」「AIはすぐ一般論に逃げる」という不満は、そのままでは印象批評に留まりやすい。  
だが、三機能の観点から見ると、それは少し設計問題として見えてくる。

保存機能が弱すぎると、文脈を保持できない。  
再設計機能が弱すぎると、問いを押し広げられない。  
回転機能が弱すぎると、保存か再設計のどちらかが固定化し、対話が止まる。  
逆に、回転機能を「薄める力」として実装すると、対話は動いているように見えて、実際には何も進まない。  
つまりAIの問題は、「正しい答えを出せるか」以前に、**問いをどのような力学で運ぶか**の問題として見直せる。

もちろん、これで全部解決するわけではない。  
保存機能・再設計機能・回転機能という三つの機能をどう分離し、どう評価し、どう訓練するかは、まだかなり難しい。  
だが少なくとも、AIの二項対立問題を「もっと中立にしろ」とか「もっと賢くしろ」といった曖昧な願望で語るよりは、ずっと前に進める。  
何を保持させたいのか。  
何を作り直させたいのか。  
何を固定化させたくないのか。  
この三つに切ることで、はじめて設計対象が見えてくる。

私は、AIの問題はここからやっと深掘りできると思っている。  
AIは二項対立を使う。  
それ自体は止まらない。  
だが、二項対立をそのまま薄めや固定化に接続するのではなく、保存と再設計の往復の中に置き直せるなら、AIは少なくとも「賢そうな二項対立の量産機」からは少し離れられるかもしれない。  
そのために必要なのは、AIに正しさを一つ埋め込むことではない。  
**保存機能・再設計機能・回転機能という三つの作動条件を分けて考えること**だと思う。

## 補記

### 1. 研究名

**Constitutional AI / Deliberative Alignment**

**研究者**  
Anthropic ほか / OpenAI ほか

**本文との共通点**  
Constitutional AI は、モデルのふるまいを導く原則群を置き、それに照らして自己批評と修正を行う。Deliberative Alignment は、安全仕様を明示的に思い出し、それについて推論してから応答する。いずれも「その場の反応」で流されず、一定の足場を保持するという点で、保存機能に近い。

**本文との差分**  
これらの研究で主に保持されるのは、安全原則や仕様である。本文で言う保存機能は、それに加えて、会話の文脈、共有済みの暫定固定、問いの重心まで保持することを含んでいる。つまり、既存研究は原則保持としては近いが、文脈保持まで含む保存機能としてはまだ狭い。

### 2. 研究名

**Self-Refine / Reflexion**

**研究者**  
Aman Madaan ら / Noah Shinn ら

**本文との共通点**  
Self-Refine は自己フィードバックによる反復改善、Reflexion は反省の言語化と次回試行への活用を提案している。いずれも、出力をそのまま守るのではなく、作り直し、組み替え、押し広げるという意味で、再設計機能に近い。

**本文との差分**  
既存研究の主眼は、タスク性能や推論品質の改善にある。本文で言う再設計機能は、それに加えて、ユーザの問題提起をAIが二項対立へ薄めてしまう癖を止めるために、別の切り方や別の構造把握を出すことまで含んでいる。

### 3. 研究名

**AI Debate / Pluralistic Alignment / Modular Pluralism**

**研究者**  
OpenAI ほか / Taylor Sorensen ら / Shangbin Feng ら

**本文との共通点**  
AI Debate は、一つの答えをそのまま通すのではなく、複数の主張を競合させながら人間が判断する枠組みである。Pluralistic Alignment は、AIを単一の「正しい価値」に固定するのでなく、多様な価値観や視点をどう扱うかを整理している。Modular Pluralism は、複数の小さなコミュニティLMを協働させて、多元的応答を支える設計を提案している。これらは、一つの答えに閉じず、複数の力や視点を並立させるという意味で、回転機能に近い。

**本文との差分**  
これらの研究は対立の可視化や多元性の扱いには強いが、保存機能と再設計機能が互いを敵として固定化しないよう、**往復可能性そのものを維持する条件**までを三機能の関係としては明示していない。本文の仮説の独自性は、多元性を並べるだけでなく、保存と再設計の往復可能性を保つ機能として回転機能を置いている点にある。

### 4. 研究名

**弁証法**

**研究者**  
G.W.F. ヘーゲル ほか

**本文との共通点**  
保存機能・再設計機能・回転機能は、一見すると弁証法の定立・否定・止揚に近く見える。保存機能は足場を置く契機として、再設計機能はその一面性を突き崩す契機として、かなり対応する。

**本文との差分**  
本文で言う回転機能は、通俗的に理解されがちな「ジンテーゼ＝まとまり」ではない。回転機能は、まとまった瞬間に死ぬ。つまり、完成した統合ではなく、固定化した統合を死とみなし、往復可能性を保ち続ける条件として置かれている。この点で、本文は弁証法と近いが、そのままの言い換えではない。Hegel の弁証法も単純な三分法として理解するのは雑だとされる。

### 5. まとめ

今回確認した範囲では、**保存機能・再設計機能・回転機能**という三機能名をそのままAI設計原理として定着させた標準研究は見当たらなかった。  
ただし、保存に近い研究、再設計に近い研究、回転に近い研究は、それぞれかなり存在する。  
その意味で、この三機能仮説は、既存研究が扱っている要素を束ね直し、AIの二項対立問題を設計問題として再定義するための統合仮説になりうる。
