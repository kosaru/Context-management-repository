# 目的論は刃物だ。素人が他人に振るな

> 公開本文の正本：https://note.com/shirokuma1970/n/nf08324afe91b
>
> このファイルは文脈解析用の取得時スナップショットです。

* アドラーの目的論は**当たる**。だから危険。
* 他人に向けて当てると、**図星ほど関係が壊れる**。
* このレベルで刺した場合、**崩れた信頼が戻るかどうかは相手次第**。
* だから目的論は「便利な解説」ではなく、**最終手段**として扱うべき。
* 空手と同じ。

  + 技は人を傷つけ得る
  + 効果と副作用を知った上で「最後に使う」
  + 普段は使わない。使うなら引き受ける
* 結論：

  + 目的論は基本 **自分に使え**
  + 他人に当てるなら **最終手段**
  + そして **引き受けろ**

## 目的論パンチへの汎用カウンター（通常運用）

> 「いまのは“動機の断言”だよね。そこには乗らない。  
> 話すなら、事実と次の行動だけ。  
> それ以外なら、ここで終わる。」

（しつこい場合は最後の一文だけ繰り返す：**「それ以外なら、終わり。」**）

## 最終手段（目的論を返す）

使うポイント：**関係を切りたいという覚悟がある時。**  
※このレベルで刺した場合、崩れた信頼が戻るかどうかは相手次第。

使い方：**一撃で終わらせる。追撃しない。議論しない。**

> 「それ、結局“支配”で押し切りたいだけだよね。  
> 私はその形には乗らない。ここで終わり。」

（※ここで会話を切る。それがセット。）
