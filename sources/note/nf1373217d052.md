# アドラー心理学と用量用法

> 公開本文の正本：https://note.com/shirokuma1970/n/nf1373217d052
>
> このファイルは文脈解析用の取得時スナップショットです。

アドラー心理学は、人間の劣等感を否定しない。  
むしろそれを、向上心のエンジンと見なす。

共同体感覚もまた、人が他者とつながる方向を示す概念として提示されている。

けれども、現在の社会は少し事情が違う。

SNSは、比較を拡張し、成功を強調し、承認を数値化する。  
劣等感は自然発生するものというより、増幅されるものになった。

この環境のなかで  
「劣等感を成長の燃料にせよ」  
「共同体感覚を持て」  
と受け取ると、それは静かな圧力になり得る。

努力が足りないのではないか。  
貢献が足りないのではないか。  
成熟していないのではないか。

思想は本来、方向を示す灯りであって、  
常時照らし続けるサーチライトではない。

アドラー心理学が悪いのではない。  
SNSが悪いと単純化することもできない。

ただ、現在はその前提を増幅させる装置が強い。

薬にも用量用法があるように、  
思想にも用量用法がある。

勇気を出すために使うのか。  
自分を追い込むために使っていないか。

少し立ち止まって確かめる必要がある。

思想は人を支えることもあれば、  
状況によっては人を追い詰めることもある。

その違いは、  
思想そのものよりも、  
それを取り巻く環境と、  
自分の現在地にあるのかもしれない。
