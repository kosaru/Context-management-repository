# 歴史観は「語る場と決める場」を支える必要条件である

> 公開本文の正本：https://note.com/shirokuma1970/n/nf50490e7fe22
>
> このファイルは文脈解析用の取得時スナップショットです。

私がこれまで述べてきた「語る場」と「決める場」を分離した民主主義の構想は、制度設計の問題である。しかし制度は、理念だけでは動かない。それを支える前提認識が必要になる。

その一つが歴史観である。

ここで言う歴史観とは、特定の歴史解釈を指すのではない。正しい歴史像を共有せよ、という話でもない。むしろ逆である。

必要なのは、

* 歴史は継続的であるという感覚
* 決定は常に暫定であるという理解
* 現在もまた過程の一部であるという時間認識

この認識である。

もし歴史が「勝者の物語」や「確定した正義の連続」として理解されているなら、語る場は成立しない。議論は正義の再確認に堕し、対立は終局戦争化する。決める場もまた、暫定的合意ではなく最終決着の場へと変質する。

しかし、歴史が継続的であると理解されていれば、決定は必然的に暫定的なものになる。敗者もまた歴史の流れの中に位置づけられ、再び語る場へ戻ることができる。ここで初めて、語る場と決める場の循環が機能する。

もちろん、歴史観だけが必要条件ではない。民主主義を成立させる要素は他にもある。しかし、この時間認識が欠けていれば、制度は形だけ残り、運動原理を失う。

完全な共有は不可能である。全員が同じ歴史観を持つ必要もない。ただ、「歴史は単純ではない」「決定は固定されない」という雰囲気が社会に存在すればよい。それが制度を静かに支える。

語る場と決める場を持った民主主義を成立させるためには、制度の整備だけでなく、この歴史観という土壌が必要である。

それが今回の到達点である。
