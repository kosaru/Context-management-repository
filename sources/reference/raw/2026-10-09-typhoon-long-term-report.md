# 本土に来た台風の数と勢力――1877年以降の記録を調べる

調査日：2026年10月9日。気象庁の通年比較は2025年で区切る。歴史復元資料は1877～2020年を対象とする。

本土への接近数・上陸数には、最初と最近の30年間を比べて大きな増加は出なかった。勢力については、上陸近傍の観測所で960hPa未満を記録した事例は増えている。1930～1960年代にも強い事例があり、閾値と比較期間で結果は異なった。来襲時の勢力を、個別台風の生涯最大勢力と区別して調べた。

## 1．今回数えた「本土への来襲」

本土は北海道・本州・四国・九州とする。沖縄・奄美への接近数を混ぜない。

- **気象庁の上陸数**：中心が本土4島の海岸線に達した台風。小さな島・半島を短時間で横切る「通過」は除く。同一台風の再上陸を追加計上しない。
- **気象庁の本土接近数**：本土の対象気象官署等のいずれかから、台風中心が300km以内に入った台風。上陸台風も含むため、接近数と上陸数を足さない。年間欄を使い、複数月にまたがる台風を重複計上しない。[1][2]
- **歴史復元資料の上陸事例**：上陸地点近くの気象台・灯台の低い海面気圧と、経路の左右で逆向きになる風向変化を使って復元した事例。気象庁の現在の上陸判定と同じ系列ではない。[3][4]

風速については最大持続風速を扱い、最大瞬間風速とは区別する。

## 2．1951～2025年：本土に来る数

気象庁の公開CSVの年間欄から集計した。[1][2]

| 指標 | 1951～1980年・30年間合計 | 年平均 | 1996～2025年・30年間合計 | 年平均 | 最近／最初 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 本土への接近 | 163個 | 5.43個 | 171個 | 5.70個 | 約1.05倍 |
| 本土への上陸 | 89個 | 2.97個 | 87個 | 2.90個 | 約0.98倍 |

比較期間を別の30年間にすると、次のようになる。

| 期間 | 接近数の年平均 | 上陸数の年平均 |
| --- | ---: | ---: |
| 1961～1990年 | 5.30個 | 2.77個 |
| 1991～2020年 | 5.80個 | 3.03個 |

この比較では、本土への来襲数が倍増したという実績はない。1951～2025年全体では、接近420個、上陸218個である。ここでは差の統計的有意性を独自に検定していない。

2026年は未完の年なので、通年比較に混ぜない。気象庁ページの2026年10月5日現在の速報値は、接近7個・上陸3個。[1][2]

## 3．1877～2020年：歴史復元資料の上陸数

Kubotaら（2021）の研究に関連するJCDP公開CSVを取得して数えた。[3][4]

資料の公称範囲は1877～2020年。掲載された上陸事例は438件で、最終の掲載事例は2019年。2020年は0件である。比較は、論文が記録の品質を比較的揃えられるとする1900年以降を中心にした。

| 期間 | 掲載された上陸事例数 | 年平均 |
| --- | ---: | ---: |
| 1901～1930年 | 92件 | 3.07件 |
| 1931～1960年 | 102件 | 3.40件 |
| 1961～1990年 | 81件 | 2.70件 |
| 1991～2020年 | 89件 | 2.97件 |

19世紀の1877～1900年には74件、年平均3.08件が掲載されている。ただし論文本文は、19世紀の観測地点数・観測間隔による品質低下も指摘している。定義を統一したことと、観測条件が全期間同一であることを混同しない。[4]

また、この資料は大雨の分析で用いた「全国51地点を固定する」方法とは異なる。2021年論文は、上陸数に全期間の明確な増減傾向を検出していないと報告している。[4]

**この歴史系列の2020年の後ろに、気象庁の2021～2025年の数を継ぎ足してはいない。**

## 4．100年以上の勢力比較：上陸近傍の観測気圧

JCDPの気圧は、上陸地点に近い観測所の最低海面気圧である。台風の解析中心気圧ではない。以下の閾値も、気象庁の「強い」「非常に強い」などの公式区分を表すものではない。

公開CSVから今回集計した。気圧の明白な異常表記1件は、気象庁の日別観測で確認して修正した。詳細は後述する。

| 期間 | 全上陸事例 | 観測気圧980hPa未満 | 960hPa未満 | 940hPa未満 | 観測気圧の事例平均 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1901～1930年 | 92件 | 47件 | 5件 | 0件 | 979.4hPa |
| 1931～1960年 | 102件 | 51件 | 17件 | 3件 | 977.1hPa |
| 1961～1990年 | 81件 | 43件 | 10件 | 1件 | 977.2hPa |
| 1991～2020年 | 89件 | 61件 | 17件 | 1件 | 973.5hPa |

1901～1930年と1991～2020年の比較では、全上陸事例が92件から89件である一方、980hPa未満は47件から61件、960hPa未満は5件から17件へ増えている。気圧の事例平均も約5.9hPa低い。

960hPa未満の件数だけを比べると約3.4倍になる。ただし、途中の1931～1960年にも17件ある。940hPa未満は同期間に3件、1991～2020年には1件である。

低い気圧の事例が増えた部分は確認できる。今回の実績から「台風の勢力は以前と同じ」と一括することもできない。

ただし、気圧の観測地点は事例ごとに変わる。上陸場所の変化、観測地点数、観測間隔の影響を、この独自集計では分離していない。台風中心の風速が何％強くなったか、温暖化が何％を説明するかに、そのまま置き換えることはできない。

## 5．1991～2025年：上陸時の中心気圧と最大持続風速

気象庁の最新ベストトラックには1991年以降、上陸・通過が解析時刻から1時間以内に起きたことを示す符号がある。[5][6]

デジタル台風の上陸日時・地点を照合用に使い、気象庁ベストトラックから本土での最初の上陸に対応する解析値を抽出した。同一台風の再上陸と沖縄などでの先行する通過は追加計上しない。1991～2025年の103個を抽出し、年別の個数が気象庁の上陸数と全て一致することを確認した。

比較できる最初と最近の各15年間は、次の結果となった。35年間の中央5年間を含む全103個の個別値も検証データに収録した。

| 指標 | 1991～2005年 | 2011～2025年 |
| --- | ---: | ---: |
| 上陸台風数 | 48個 | 47個 |
| 上陸に対応する中心気圧の平均 | 971.3hPa | 975.4hPa |
| 中心気圧950hPa以下 | 8個 | 4個 |
| 中心気圧960hPa以下 | 15個 | 12個 |
| 最大持続風速の平均・ktから換算 | 31.3m/s | 30.2m/s |
| 最大持続風速65kt以上・約33.4m/s以上 | 22個 | 22個 |
| 最大持続風速85kt以上・約43.7m/s以上 | 2個 | 2個 |

この15年対15年の比較では、最近の方が上陸時の中心気圧が低い、最大持続風速が高い、という結果にはならなかった。100年以上の観測所気圧の比較とは、期間と測っている気圧の種類が異なる。

風速は1kt＝1852/3600m/sで換算した。気象庁の日本語資料に載る丸められたm/s値と完全には一致しない。瞬間風速ではない。衛星等を用いた解析方法の変化を、今回独自に均質化したわけではない。

日時照合は「頃」「前」「過ぎ」などの幅を持つ表記と、上陸・通過符号の1時間区間を照合している。古いデータベースの風速値をそのまま集計したものではない。方法と採用時刻は集計スクリプト・個別CSVに保存した。

## 6．特に低い中心気圧で上陸した台風

気象庁の現行の順位表で確認できる記録。[7]

| 台風 | 上陸時・直前の中心気圧 |
| --- | ---: |
| 1961年・第二室戸台風 | 925hPa |
| 1959年・伊勢湾台風 | 929hPa |
| 1993年・台風13号 | 930hPa |
| 1951年・台風15号 | 935hPa |
| 2022年・台風14号 | 940hPa |

2022年の940hPaは5位タイで、1991年・1971年・1965年・1964年・1955年にも940hPaの上陸記録がある。

統計開始前の参考記録として、1934年の室戸岬で911.6hPa、1945年の枕崎で916.1hPaも掲載されている。こちらは観測所の実測値なので、上表の解析中心気圧と同一系列の順位として扱わない。

これらは極端な個別事例の比較である。順位だけで強い台風全体の頻度変化を決めてはいない。

## 7．既存研究でどこまで分かっているか

今回の問いに直接近いのは、Kubotaら（2021）の1877～2019年の研究である。[4]

同論文は、全期間の上陸数に明確な増減傾向を認めない。一方、上陸時の気圧から風速を推定して、その3乗を年ごとに合計するAPDIという指標では、1977～2019年に統計的に有意な増加を報告している。

これは台風ごとの風速の単純平均ではなく、台風数と強さの両方を反映する年合計の指標である。観測地点数を20地点、観測間隔を12時間へ減らす検証でも、同期間の増加を確認している。

ただし、約1900年、1910年代、1930～1960年代にもAPDIが高い時期がある。同論文自身が、最近40～50年の変化のうち、人為的温暖化に由来する部分がどれだけかは、さらに議論が必要としている。19世紀の資料品質が低いことも本文で明記している。

この研究の「最近約40年間で増加」と、今回の「1991年以降の最初・最近の15年間で増加が出ない」は、期間と指標が違う結果である。どちらかを消して同じ結論に揃えてはいない。

## 8．1877年より前の資料

1853年・1863年の船舶記録から台風を復元した個別研究は確認できた。しかし、これだけで当時の本土への年間来襲数を数えられるわけではない。[4]

古文書を用いた2009年の大会要旨では、1880年代の上陸・接近を39事例復元している。検出範囲が現在の「官署から300km以内」と同じではなく、強さも現在と同じ精度で揃えていない。この39件を現在の接近数との倍率計算には使わなかった。[8]

また、水越允治による「過去千年間に中央日本に襲来した台風」（2002）の書誌と要旨も確認した。11～20世紀の古文書と近代記録を使った中央日本の研究である。本土4島全体の気圧・風速付きの連続系列とは異なる。今回、原資料の事例一覧を取得して再集計するところまではできていない。[9]

**産業革命期から現代まで、本土全域の来襲数と来襲時の勢力を同じ精度で比較できる連続系列は、今回の調査では取得できていない。**

## 9．データの照合で見つかった問題

1. **古い上陸一覧の値と現行値の違い**：デジタル台風の完全版は、旧資料に基づくため最新の気象庁値と異なることがあると明記している。例として、伊勢湾台風の一覧値920hPaに対し、気象庁現行順位表は929hPa。1951年15号も一覧値952hPaに対して現行順位表は935hPa。歴史の中心気圧を旧一覧の値だけで一括集計しなかった。[7][10]
2. **復元CSVの気圧の異常表記**：2002年10月1日・石廊崎の欄は9602.00hPaとなっていた。気象庁の日別観測で最低海面気圧960.2hPaを確認し、集計では960.2を採用した。元の値と修正理由・根拠URLは残した。[11]
3. **復元CSVの風速の異常表記**：1907年の10..8、2015年の14.l5という2件を確認した。根拠のない自動修正はせず、数値としては欠測扱いとした。地上観測風速の長期増加率は今回算出していない。
4. **論文と公開CSVの平均の差**：2021年論文の1877～2019年の年平均は3.09。一方、取得した公表CSVの掲載438件から計算すると3.063となる。差の原因は未確認。このCSV集計を、論文の全計算を完全再現したものとは呼ばない。
5. **閾値ちょうどの記録**：公開CSVには1957年8月24日・室戸岬の1000.00hPaがある。全事例数は公開CSVの掲載行を維持し、980・960・940hPa未満の集計ではそれぞれの数値条件を適用した。

## 10．現時点で残る問い

数の長期実績と、勢力の変化を一つにまとめることはできない。

今回の本土接近数・上陸数の30年比較では、大きな増加は出なかった。100年以上の観測所気圧の比較では、960hPa未満の事例が増えていた。しかし途中にも同程度に多い時期があり、極端に低い気圧の事例は過去にもある。1991年以降の来襲時中心気圧・風速の15年比較では、最近の増加は出なかった。

これらの変化のうち温暖化がどれだけを説明するのかは、今回の集計では推定していない。観測・復元された実績、指標による集計、因果の推定を区別したまま残す。
